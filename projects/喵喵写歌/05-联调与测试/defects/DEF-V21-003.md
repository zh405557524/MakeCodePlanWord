# DEF-V21-003 首页热门案例空数据时展示不可点击的演示卡

- 状态：`open`；严重度：`P1`；发现时间：2026-09-20；关联：第 15 步 V2.1 双端功能测试。
- 触发版本：Android 真机，当前源码 Debug 包 `1.3.0`，连接测试环境；iOS 同版包也曾显示相同演示标题，但尚未独立复测点击。

## 复现

1. 测试环境未配置可展示的首页热门案例歌曲，进入首页并滚动到「热门案例」。
2. 页面出现「送给你的一首歌」「夏夜的风」等卡片。
3. 点击第一张卡片。

**实际**：卡片无点击反馈、无播放或详情跳转；可见内容来自 App 本地 `_HomeDemoCaseGrid`，不对应真实歌曲资源。

**预期**：当前 PRD `01-需求/requirements.md` 第 158 行要求「案例为空显示空分区，不伪造示例」。若后台配置了案例，卡片才应可播放或进入对应作品；空数据不得展示仿真运营内容。

## 定位与证据

- Flutter `lib/pages/home/view.dart` 的 `_HomeCaseArea` 在 `hotSongs.isEmpty` 时直接返回 `_HomeDemoCaseGrid`。本地卡片只设置封面和标题，未设置 `onTap`；真实 `_HomePopularGrid` 才调用 `controller.playHotSong`。
- [Android 首页截图](</Users/soul/code/lxwx/test/catsinger/artifacts/v21-auto-20260920-190503/android/19-home-before-example.png>)；点击后页面未变化。测试环境案例配置仍需由 Admin 再核对，不把「接口失败」与「后台确实为空」混为已证实原因。

## 回归要求

- 后台无可展示案例或请求失败时，不出现本地演示歌曲；按 PRD 显示空分区或清晰错误态。
- 后台添加真实案例后，双端展示真实标题/封面，点击可进入作品并连续播放至少 5 秒。
- 本轮只登记缺陷，不改业务代码；修复需另立 CHG。
