# 03 - 首页与作品创建开发计划

> 覆盖任务：F-011 ~ F-013  
> 状态：`pending`  
> 依赖：F-001 ~ F-010  
> Figma：`AI漫剧 / 01-首页`、`AI漫剧 / 02-故事输入`

## 目标

实现首页作品列表、作品创建页和同步文本解析链路。点击「开始解析」前没有正式 `workId`；解析接口成功后才进入角色生成页。

## 任务拆分

| ID | 任务 | 输出 | 接口 / 存储 |
| --- | --- | --- | --- |
| F-011 | 首页与作品列表 | 首页、作品卡、空态、续作路由 | `GET /api/v1/works`、`works_cache` |
| F-012 | 作品创建页 | 故事文本输入、草稿保存、按钮状态 | `story_drafts` |
| F-013 | 同步解析链路 | 创建作品、同步解析、保存 `workId`、进入角色页 | `POST /api/v1/works/parse` |

## 首页业务

- 首页「开始创作」进入作品创建页。
- 作品列表「新建漫剧」也进入作品创建页。
- 点击已有作品按 `currentStep` 路由：
  - `draft` -> 作品创建页
  - `characters` -> 角色生成页
  - `scenes` -> 场景生成页
  - `storyboards` -> 分镜处理页
  - `preview / completed` -> 视频预览页

## 同步解析业务

流程：

1. 用户输入故事文本。
2. 前端本地 debounce 保存草稿。
3. 点击「开始解析」后调用 `POST /api/v1/works/parse`。
4. 接口同步创建作品、解析文本并返回 `workId + characters`。
5. 前端缓存角色步骤数据并跳转 `/create/characters?workId=...`。

错误处理：

- 解析失败：停留当前页，保留文本草稿。
- 网络失败：保留本地草稿，可重试。
- 未解析成功：不进入作品列表正式作品续作。

## 验收

- 作品创建页不出现任务轮询逻辑。
- 「开始解析」成功后才产生 `workId`。
- 首页续作路由与后端 `currentStep` 一致。
- 页面按 Figma 375 x 812 对齐。
