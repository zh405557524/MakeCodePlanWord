# 04 选择音色步骤模块

- 版本：v1.1-ai-cover
- 对应任务：F-COVER-04
- 状态：done
- 影响工程：`/Users/soul/code/lxwx/catsinger`

## 1. 功能定位

选择音色页是 AI 翻唱第 2 步。用户从运营配置的音色列表中选择目标音色，可试听后进入高级设置。

## 2. 数据来源

- 接口：`GET /api/song-cover/voices`
- 后端按 `X-App-Code: catsinger` 返回启用的音色配置。
- 空数据时展示空态，不使用生产假数据。

## 3. 页面结构

- 顶部：返回按钮 + 标题 `选择音色`。
- 进度：第 2 步，共 3 步。
- 分组 Tab：男声、女声、二次元、特色。
- 音色卡列表：头像/图标、名称、标签、试听按钮、选中态。
- 底部按钮：`下一步`。

## 4. 交互规则

| 操作 | 规则 |
| --- | --- |
| 切换分组 | 只切换当前列表，不清空已选音色 |
| 点击音色卡 | 设置为当前选中音色 |
| 点击试听 | 播放试听音频，再点停止 |
| 点击下一步 | 已选音色后进入高级设置 |
| 返回 | 回上传页，保留源音频 |

## 5. UI 状态

- 选中态：绿色描边或主色背景，右上角勾选。
- 禁用态：灰色蒙层，无法点击。
- 试听中：按钮显示暂停图标。
- 加载失败：展示重试按钮。

## 6. 实现步骤

1. 新增 `pages/song_cover_voice/`。
2. Controller 初始化时读取 `SongCoverStore.voices`，没有则请求接口。
3. 增加试听播放控制，优先复用现有音频播放器能力。
4. 选中音色写入 `SongCoverStore.coverDraft.coverVoiceCode`。
5. 下一步跳 `/song-cover/settings`。

## 7. 验收标准

- 音色分组按后端排序展示。
- 同一时间只能试听一个音色。
- 未选择音色时底部按钮置灰。
- 接口空列表时能返回上一页或重试，不白屏。
