## 4. 视觉参考与设计稿分析

参考当前 Figma Frame：`首页` / `97:102`。

从上到下区块：

1. 375 x 812 深色背景，上方蓝色渐变/光斑氛围。
2. 右上角 `开通会员` 胶囊入口。
3. 首屏功能入口：左侧 `AI漫剧`、说明 `创作漫剧视频`；右侧 `资产库`。
4. `热门案例` 标题。
5. 分类 Tab：`热门`、`短剧解说`、`漫剧解说`、`电影解说`、`电视剧解说`。
6. 双列案例卡片，卡片内有封面、播放标识、时长 `15:16` 和 `视频名称`。
7. 底部导航：`创作`、`作品`、`我的`。

状态要求来自 `figma-design-plan.md` 5.1：默认、分类切换、加载、空态、错误、入口点击反馈。

## 6. 业务内容与数据流

```text
HomePage
  -> HomeController.categories / cases
  -> 分类区 + 案例区
  -> AI 漫剧入口跳占位
  -> 资产库入口跳 /assets
```

首页会员入口保持空白页，不进入真实支付；我的页内部会员入口按旧 `AccountPage` 完整复用。AI 漫剧入口本期进入空白页，不按 `AI 漫剧` Frame 细化实现。
