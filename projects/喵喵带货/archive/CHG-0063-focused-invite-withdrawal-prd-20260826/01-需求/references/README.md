## 使用原则

- 需求判断优先级为：用户本轮明确要求 → 当前参考代码 → 本版 PRD → 图片视觉参考。10 张原始素材用于移动端信息层级、橙红主色和卡片化布局；主流程以 PRD 的“首页/作品/我的 + 五阶段作品流程 + 按状态恢复业务”为准。
- “我的”页使用当前代码骨架：“用户头部 → 会员卡 → 积分福利/积分充值 → 订单列表/兑换码/意见反馈/联系客服/更多设置 → 三个底部 Tab”。其中兑换码为用户明确要求的新增入口。
- P16 静态内容、P17 意见反馈和 P18 更多设置按当前代码允许游客访问；P18 的账号与安全、退出登录只在登录后显示。其他账户/资产业务沿用现有登录门禁。
- 任务中心只承载总积分、连续签到和每日任务（当前代码首版为邀请好友）；视频生成任务由“作品”页面承载。带货形象仅在生成流程的选择弹层内管理，不进入“我的”页。
- 跨项目截图中的“创作歌曲、今日剩余、已下载、WAV 下载、邀请送积分、四 Tab”和具体价格不属于喵喵带货需求；会员/积分/订单/兑换码必须使用真实业务数据。
- 素材中的进度条需按五个作品主阶段表达：“草稿/填写信息、内容生成、编辑脚本、视频生成、视频完成”；内容生成内部依次包含脚本和分镜图片生成。
- 同一能力的命名在素材中存在“一键生成带货视频 / AI 带货视频”等差异，PRD 统一使用“AI 带货视频”，按钮使用“立即生成 / 生成内容 / 确认并生成视频”。
- 最终视频由视频模型基于用户确认的脚本与分镜图片生成，本版不设置独立配音/TTS 任务。原图中的“生成配音”“字幕配音”“添加字幕”“合成画面”和“取消生成”等文案/按钮全部废弃，仅保留版式参考价值。
- 首页和 P20 案例列表由后台配置；“更多案例”进入 P20，“生成同款”下一版本开放。P05 作品和 P20 案例列表均不提供筛选。首版不提供任务通知，用户通过作品页查看状态。
- AI 生成的分镜图片、达人形象和视频成片均需展示 AI 生成水印或标识。
- 素材中的示例商品、人物、文案、点赞评论数据均为演示内容，不作为固定业务数据。
- 若后续设计稿与本 PRD 冲突，应先更新需求主文档并登记变更，再进入实现。
- Figma 中的银行预留手机号短信验证码不属于当前工猫公开 API 链路；本期统一替换为工猫 H5 刷脸核身和电签，不得按截图恢复短信步骤。
- 提现结果原型中的“1～3 个工作日”从人工审核通过并提交银行后计算；人工审核本身不承诺完成时间。
