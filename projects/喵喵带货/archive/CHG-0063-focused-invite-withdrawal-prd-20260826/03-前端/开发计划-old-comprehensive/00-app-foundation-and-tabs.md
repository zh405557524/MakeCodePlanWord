## 1. 功能定位与边界

本模块把移动端一级结构调整为“首页、作品、我的”三个 Tab，并建立后续带货页面统一使用的路由和登录回跳基础。

本模块完成：

- 首页、作品、我的三个一级页面可以直接切换。
- 三个一级页面均允许游客进入，不因切换 Tab 自动弹登录。
- 点击填写信息、作品详情、会员、积分等二级业务时才进入登录流程。
- 登录成功后回到用户原来要进入的二级页面；取消登录后停留在原一级页面。
- 三个 Tab 使用常驻页面容器，保留列表、滚动位置和已加载状态。
- 移除主框架中的写歌作品页、音频迷你播放器和写歌创作入口依赖。
- 为后续首页、作品和“我的”模块保留明确的页面挂载位置。

本模块不完成：

- 不实现首页具体卡片和案例数据，归入 `02-home-and-cases.md`。
- 不实现作品列表和状态跳转，归入 `05-works-and-state-routing.md`。
- 不改写会员、积分、充值等复用页面，归入 `08-account-reuse.md`。
- 不实现填写信息、脚本、分镜图片或视频业务。
- 不删除仍被公共登录、支付或复用页面依赖的旧文件。

## 6. 业务内容与数据流

### 6.1 Tab 切换

```text
用户点击底部 Tab
  → 校验索引范围
  → 不做登录判断
  → 更新 currentIndex
  → IndexedStack 显示对应一级页
  → 通知新页面可见
  → 重复点击当前 Tab 时触发该页约定的刷新/回顶行为
```

三个一级页必须常驻，不能因切换 Tab 重建整个页面。

### 6.2 二级业务登录

```text
游客点击二级业务
  → 检查隐私同意
  → 记录目标路由、path/query 参数和必要 extra 标识
  → 打开登录页
      ├─ 登录成功：替换登录页并进入原目标
      └─ 取消登录：返回原一级页，不再次弹出
```

目标路由只能保存客户端可识别的内部路由，不接受外部传入任意 URL。登录完成后必须清除一次性目标，防止下次登录误跳转。

### 6.3 登录态变化

- 登录成功后刷新“我的”用户摘要；作品列表由作品模块决定是否加载。
- 退出登录后保持当前一级页可用，清除用户私有列表和详情缓存。
- 退出登录不得强制跳出首页或“我的”游客框架。
- 支付成功后仍可调用 `showAccountTab()`，但不得依赖写歌 Store。

## 13. CHG-0058 登录统一隐私协议前置

- `CustomRouter.openLogin` 是所有主动登录跳转的唯一公共入口，进入命名登录路由前必须完成全局隐私确认。
- 登录命名路由使用 `AuthPrivacyGate` 二次兜底，覆盖路由鉴权同步重定向、直接 `/login`、Deep Link 及遗漏的直接命名跳转；未同意时不得构建 `AuthPage` 或初始化号码认证等受保护能力。
- 同意后初始化受保护服务并继续原登录动作；拒绝时保留原页面，有历史栈则退出登录路由，无历史栈则回主页面。
- 作品 Tab、账户入口、`LoginService.ensureLoggedIn` 和接口 401 回跳均复用公共入口，不在业务模块重复隐私逻辑。
