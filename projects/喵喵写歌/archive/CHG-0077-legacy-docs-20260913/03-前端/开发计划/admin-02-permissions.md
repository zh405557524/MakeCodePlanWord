# Admin 权限管理块模块开发文档

> 关联任务：T-A002  
> 工程：`/Users/soul/code/lxwx/lxwx_admin`  
> 状态：waiting_review

## 1. 功能定位与边界

支持超级管理员为角色分配后台管理块权限，并按权限过滤导航。

- 包含：角色列表、管理块勾选、保存权限、导航过滤、无权限提示。
- 不包含：字段级权限、操作级复杂审批。

## 2. 入口、路由与页面文件

| 类型 | 建议文件 |
|------|----------|
| 页面 | `lib/pages/system/role_permissions_page.dart` |
| Model | `admin_role.dart`, `admin_permission.dart` |
| Repository | `AdminRepository` 权限方法 |

## 3. 依赖前置

- 后端 T-B009：`GET /api/admin/roles`、`POST /api/admin/roles/{id}/permissions`。
- T-A001 App 切换上下文。

## 4. 视觉参考与设计稿分析

后台无截图参考，沿用现有系统设置页表格/表单风格。管理块建议使用复选框矩阵或分组列表。

## 5. 涉及模块与类

| 类 | 职责 |
|----|------|
| `RolePermissionsPage` | 角色和权限配置 |
| `AdminRepository` | 查询/保存权限 |
| `ShellPage` | 根据权限过滤导航 |

## 6. 业务内容与数据流

1. 超管进入权限页。
2. 选择角色。
3. 勾选管理块和动作。
4. 保存后更新导航权限缓存。
5. 普通角色看不到无权限模块。
