# T-19 固定图片版本：真实私有 OSS 与普通 iOS 联验

2026-10-19。普通 `main.dart` App、实际 Servlet/JWT/隔离 PostgreSQL；两张自行制作的蓝 V1 / 绿 V2 PNG 经公共直传 API 实际上传私有 OSS。本轮不调用外部模型、不生图、不生成视频；仅建稿文本替身准备两集和一项未引用道具，生产调度关闭。本次验证素材管理，不代表制作设置、分析或 AI 生成整链已验收。

## 已验证

1. 选择蓝 V1 后通过返回取消，后台确认没有新增导入绑定；再次主动确认才导入一次。
2. 源资产改选绿 V2 后，本集固定引用蓝 V1。实际终止重启普通 App，进程 **82551 → 83371**；重进作品仍显示蓝 V1。
3. 归档后从当前清单消失，查看归档仍有蓝 V1，恢复后当前清单重新显示。具体版本、resourceId、原成功时间及 30 天截止保持，无媒体复制或重新续期。
4. 引用期间删除源资产被拒绝；最终 API 删除测试作品后，源资产及其当前 V2 保留且可删除。错误类型导入已被 API 拒绝。该删除阶段为后台断言，未声称手机操作删除。
5. 签名 GET 200，读取字节 SHA256 与上传原图一致；无签名读取 403。最终两项绑定、三条图片版本、两个资源、一条建稿任务，可用 30 / 冻结 0 / 扣费订单 0。

## 发现和修复

实际归档、恢复成功后仍显示“本集素材已保存＋重试”。根因是成功与错误共用提示字段，View 给全部消息附加重试。App dev **b2f864f** 分开成功回执，成功提示不带重试；后续刷新失败仍保留错误与读取重试。新增两项回归，素材清单和共享素材 **57 项自动测试通过，analyze 无问题**。本轮没有重新构建或在普通 App 复验此提示修复；截图保留修复前事实，不能当作修后设备证据。

后台 dev **2fec83c6** 仅增加一个完整联验方法。自动 API 运行 run-01、普通 App 运行 run-03 均通过；是同一方法的两次执行，不计成两个独立方法。接口、表结构、共享配置与运行中的 8080 未改。

## 边界与未完成

- 普通 App 来自 **2dbf40b**，默认入口、环境 1、仅测试构建的 loopback 地址 56200。安装四项摘要核对沿本专用模拟器记录，未安装到用户手机。
- 专用模拟器未清缓存，两次手机运行使用相同 resourceId 和确定性图片字节；截图证明版本显示，不能单独证明首次网络下载。真实云对象读取由上述独立后台断言证明。
- 正式 TC-11-04 仍部分验证，控机 UI-01 记录 blocked / 原用例 not_assessed；过期来源、真实上传失败/取消、Android、物理设备与完整 Figma 仍待。47 项仍 **7 完成 / 40 未完成**，正式 186 条仍 **12 通过 / 171 部分 / 3 未执行**。
- 首次手机 run-02 因执行者误认为“确认导入”会打开第二个确认弹框，没有先返回取消而主动中止。保留失败与截图，不归因 App，不伪造取消信号。新独立数据 run-03 才完成上述流程。
- 三次共六个自有云对象均删除并确认不存在；成功运行 schema 已清理，失败运行数据保留，三套自有 PG 均停止。手机控制会话已关闭，不发布凭证、签名 URL、云对象 key 或私密原始日志。
