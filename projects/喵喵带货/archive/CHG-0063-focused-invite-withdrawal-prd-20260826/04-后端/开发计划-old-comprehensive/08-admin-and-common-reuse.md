# Java 模块开发文档：运营后台与公共功能复用

> 版本：`v1.1`｜状态：已完成

## 1. 功能定位与边界

提供 catseller 案例、业务/计费配置、作品和任务查询后台接口，并确保登录、会员、积分、充值、订单、任务中心、兑换码、反馈、设置和邀请等公共接口在 catseller schema 下正常复用。本模块不重复建立公共业务接口。

## 2. 类清单

后台接口由 `AdminCatsellerController` 和 `AdminCatsellerService` 对外提供；案例、作品、任务、步骤和事件查询复用 catseller Repository，素材上传复用公共 `IResourceService`，用户脱敏信息复用公共用户表。公共模块继续使用现有登录、用户、会员、积分、支付、任务中心、兑换码、邀请和反馈能力。

## 3. 接口契约

对应 Flutter Web：`09-admin-catseller.md`；移动端：`08-account-reuse.md`。

| 方法与路径 | 请求 | 响应 | 权限/错误 |
|------------|------|------|-----------|
| `GET/POST/PUT/DELETE /api/admin/catseller/cases` | 案例资源、排序、上下线和 AI 标记 | 案例分页或保存结果 | 复用现有管理员鉴权 |
| `POST /api/admin/catseller/cases/covers` | 图片文件，最大 8MB | 资源 ID、地址、文件名、大小、类型 | 只接受图片 |
| `POST /api/admin/catseller/cases/videos` | 常见视频文件，最大 500MB | 资源 ID、地址、文件名、大小、类型 | 校验视频扩展名 |
| `GET/PUT /api/admin/catseller/configs/business` | 图片、视频类型、比例/时长、清晰度、默认参数、保留期、轮询和功能开关 | 当前业务配置 | 校验失败不生效 |
| `GET/PUT /api/admin/catseller/configs/billing` | 单图积分、计费版本、报价有效期和失败策略 | 当前计费配置 | 禁止修改历史报价 |
| `GET /api/admin/catseller/works` | 作品编号、标题、状态和分页 | 作品脱敏摘要 | 只读 |
| `GET /api/admin/catseller/works/{workId}` | 作品编号 | 用户脱敏信息、填写信息、商品图、脚本分镜、审核和视频 | 只读 |
| `GET /api/admin/catseller/tasks` | 任务编号、作品编号、任务类型、状态和分页 | 任务脱敏摘要 | 只读 |
| `GET /api/admin/catseller/tasks/{taskId}` | 任务编号 | 进度、步骤、失败原因和脱敏 trace | 不返回 Prompt、Provider 原文、密钥或 Token |

AI 模型配置继续使用现有通用 Admin API，只新增 catseller 场景配置数据，不新增平行路径。移动端公共接口路径保持现状。

## 4. 数据表与迁移

- Admin 直接在选定 catseller schema 查询 `catseller_cases/works/generation_tasks` 和公共配置。
- 计费/业务配置使用版本化 AppConfig 或已确认配置结构；真实密钥不入 service-data 响应。
- 后台继续使用现有管理员认证和 App 切换，不新增角色、菜单权限表或第二套管理员表。
- 公共用户、积分、支付等表由 common 迁移在 catseller schema 提供。

## 5. 业务规则与状态

- 管理员请求由现有后台会话控制，并显式选择 catseller；App 不一致时不返回其他 Schema 数据。
- 案例上下线影响首页/更多案例，不删除已生成作品。
- 配置保存先完整校验再原子切换版本；历史报价/任务绑定旧版本。
- 作品/任务查询只读，首版不允许手工改状态、脚本、积分或终态。
- 查询响应脱敏用户、Prompt、Provider 返回、媒体签名 URL和 Token。
- 公共业务逻辑与喵喵写歌一致；只有积分消费场景和 App 配置不同。

## 6. 异常与日志

配置非法、版本冲突、资源归属错误和权限不足有统一响应。所有后台写操作记录管理员、App、旧新版本、原因和 traceId；不记录密钥明文。跨 App 查询尝试记录安全告警。

## 7. 依赖前置

依赖基础 schema/权限、案例、配置、计费、作品/任务和全部公共模块。Flutter Web App 切换必须传 `X-App-Code: catseller`。

## 8. 建议实现步骤

1. 注册 catseller Admin App 和业务菜单，沿用现有管理员权限。
2. 实现案例 CRUD、排序和资源校验。
3. 实现业务/计费配置读取、校验和版本切换。
4. 扩展通用 AI 配置 catseller 场景。
5. 实现作品/任务只读查询和脱敏。
6. 回归全部公共接口和其他 App。

## 10. 测试要求

每个 Admin 接口正常+无权限/冲突；App 切换不串数据；配置非法/版本变化；查询脱敏；公共登录、会员、积分、充值、订单、任务、兑换码和邀请集成回归；其他 App 关键接口回归。

## 11. 验收标准

后台可配置和查询但不能非法改终态；计费版本可审计；公共业务在 catseller 下可用；无资产统计专属接口；所有敏感数据脱敏；其他 App 无回归。

## 12. 编码注意事项

不新建公共能力副本，不让 Admin 默认 App 误查 narrate，不回显密钥，不开放状态修复按钮，不把用户完整手机号作为查询结果。
