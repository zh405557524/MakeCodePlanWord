## 实现范围

`DramaMarkdownContentReader` 的“引用素材”和“声音引用”共用引用字段解析：先识别列表结构、提取值，再核对注册身份与唯一性。没有新增依赖。

```text
引用字段 := 空引用 | 引用列表
空引用   := [列表前缀 空白] 无
引用列表 := 列表项 (换行或空行 列表项)*
列表项   := 列表前缀 空白 素材标记
列表前缀 := - | * | + | 数字. | 数字)
```

允许缩进、多个横向空白、CRLF/LF 和空白行；空引用允许单独的 `无` 或单个列表项，例如 `- 无`、`* 无`、`1. 无`。编号只承担列表语法，不作为素材身份。

保留已有语义边界：注册标记先精确命中，再接受额外一层方括号；未知标记、重复身份、混合“无”和引用、缺少字段内容以及附带无法识别文字的引用仍拒绝。没有依据名称猜测身份，角色/场景声音类型仍由原业务校验处理。

原始输出、剧本正文、视频描述、原文锚点和引用顺序不改写。本切片仅调整引用字段，整篇文档的标题、段落顺序和时长规则未改。
