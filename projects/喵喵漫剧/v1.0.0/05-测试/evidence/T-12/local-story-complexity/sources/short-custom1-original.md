# 故事草案
## 故事梗概
厨房里只有秒针轻响。一只会说话的小猫跳上餐椅，凑近桌沿嗅闻刚倒好的水杯。它尾巴一甩，水杯“哐”地翻倒，清水漫过桌面，沿着桌边滴落。小猫吓得耳朵贴平，小声嘀咕：“糟了，糟了。”它慌忙抽起桌上的纸巾，先用爪子按住水流，再一张张铺开吸水，踩着纸团来回擦拭桌沿，连杯底的水圈也不放过。短短几十秒里，它把湿纸巾团成一团丢进垃圾桶，又把水杯扶正，端端正正坐在桌边，尾巴却还紧张地绕住椅腿。主人推门回到厨房，一眼看见桌面被擦得半干、垃圾桶里露出的湿纸团，再看看小猫湿漉漉的爪尖和故作镇定的模样，立刻明白发生了什么。主人没有责备，从料理台边取出一朵小红花贴纸，轻轻贴在小猫耳侧。小猫眨了眨眼，小声问：“不生气吗？”主人笑着揉了揉它的头。一分钟不到，厨房里那点慌乱便被一朵小红花收好了。

## 第1集：水杯翻了以后
本集剧情方向：厨房内，秒针刚走过一格，小猫跳上餐椅，尾巴无意间扫翻桌沿的水杯。水迅速漫开，它先愣住，随即小声说“糟了”，慌乱地抽纸巾、按水、擦桌、扶杯，把湿纸团丢进垃圾桶，又努力坐直装作无事发生。主人回到厨房，看见半干的桌面、湿纸团和小猫湿漉漉的爪尖，明白它主动收拾了残局。主人从料理台边取出一朵小红花贴纸，贴在小猫耳侧。小猫由紧张到放松，小声问“不生气吗”，主人笑着揉头。整个过程不超过一分钟，所有动作都集中在厨房这一场景内，不增加其他角色或支线。
