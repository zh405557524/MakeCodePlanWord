# 07 作品列表与详情集成模块

- 版本：v1.1-ai-cover
- 对应任务：F-COVER-07
- 状态：done
- 影响工程：`/Users/soul/code/lxwx/catsinger`

## 1. 功能定位

本模块把翻唱作品纳入已有作品体系，避免 AI 翻唱形成独立孤岛。

## 2. 列表改动

- 作品列表增加类型标签：
  - `原创`
  - `翻唱`
  - `纯音乐`
- 翻唱作品展示目标音色和来源标题。
- 筛选项后续可扩展，本轮先支持接口字段和 UI 标签。

## 3. 详情改动

- 翻唱作品详情展示：
  - 来源歌曲。
  - 目标音色。
  - 翻唱参数摘要。
  - 原版/翻唱版切换播放。
- 操作栏增加 `重新翻唱`。

## 4. 数据字段

| 字段 | 用途 |
| --- | --- |
| `songType` | 控制标签和详情展示 |
| `sourceWorkId` | 跳来源作品 |
| `sourceTitle` | 列表展示 |
| `coverVoiceName` | 展示目标音色 |
| `originalAudioUrl` | 原版播放 |
| `coverAudioUrl` | 翻唱版播放 |

## 5. 交互规则

- 点击翻唱作品列表项：进入结果/详情页。
- 点击来源歌曲：若有权限进入来源作品详情；没有权限时只展示标题。
- 点击重新翻唱：带当前作品进入上传页。
- 删除翻唱作品：只隐藏当前翻唱作品，不影响来源作品。
- 作品 Tab 可见、用户已登录且列表存在生成中作品时，每 1 分钟静默刷新；离开 Tab、退出登录、全部作品进入终态或 Controller 销毁时停止。
- 返回作品 Tab 且仍有生成中作品时先静默刷新一次；自动刷新失败保留当前列表并等待下一周期。
- 灵感、专业、情景、AI 翻唱以及播放器/详情重新生成任务创建成功后，发送既有 `SongWorksRefreshRequested` 立即刷新一次。
- 详情弹层、独立详情页和播放器 Controller 的“重新生成”共用同一流程：精确匹配原作品 provider/model 当前模型积分，先确认后提交；播放器不新增可见入口。
- 重新生成接口返回的新 task 继续关联原 `workId`；提交成功后同一列表项必须刷新为 `GENERATING` 并用新 `generationTaskId` 跟踪进度，不追加或解释为新的作品列表项。
- 详情或模型配置需网络读取时显示“正在获取积分信息...”；确认后显示阻断式“正在提交重新生成任务...”，其间禁止重复提交。
- 积分不足沿用会员权益弹框；模型配置缺失、停用或积分无效时停止提交；取消、校验失败或接口失败均不刷新列表。
- 详情弹层请求期间保持显示；有效 taskId 创建成功后先关闭 Loading 和弹层，再从弹层外进入生成进度页，并仅发送一次作品刷新事件。
- 定时、下拉和创建事件刷新统一串行执行；创建事件撞上在途请求时保留一次补发，避免事件丢失和并发堆叠。
- 作品更多菜单“查看详情”的固定 Sliver 头部高度对齐到整数逻辑像素，避免非整数 ScreenUtil 缩放值触发 Flutter 几何断言。

## 7. 验收标准

- 原创、翻唱、纯音乐标签准确。
- 翻唱作品详情能重新翻唱。
- 删除翻唱作品不删除来源作品。
- 生成中作品只在作品 Tab 可见且登录时每分钟刷新一次，所有终止条件均停止请求。
- 自动刷新失败不清空列表，创建成功事件可在在途请求结束后补发一次。
- 1080×2408@3x 等产生小数适配高度的设备上，详情弹层正常显示标题、操作区、基础信息、Prompt 和歌词，不得只显示黑色空容器。
- 点击“重新生成”先显示原作品当前模型价格的积分确认；取消不请求、不刷新，确认提交期间有阻断 Loading 且无重复请求。
- 接口成功仅对非空 taskId 导航；详情弹层已关闭、生成进度页可见，且 `SongWorksRefreshRequested` 只发送一次；失败、积分不足和空 taskId 无残留 Loading 或错误导航。
- 重新生成提交后作品列表不增加条目且原条目立即显示生成中；任务成功后同一 `workId` 展示新结果并回到完成态，失败时恢复原任务关联和完成态且原作品仍可播放。
