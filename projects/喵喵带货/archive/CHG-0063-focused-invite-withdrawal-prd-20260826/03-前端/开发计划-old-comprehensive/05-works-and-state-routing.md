# Flutter 模块开发文档：作品列表与状态入口

> 版本：`v1.0`｜状态：待评审｜任务：`T-F007 作品列表`

## 1. 功能定位与边界

实现无筛选作品列表，并保证每次点击作品都先获取最新聚合详情，再进入草稿、内容生成、编辑脚本、视频生成、视频完成或失败对应页面。列表卡片只展示摘要，不能决定最终路由。

## 2. 入口、路由与页面文件

- 作品 Tab：`lib/pages/works/{index,controller,view}.dart`，游客可进入。
- 作品状态页：`/seller/works/:workId`，登录后进入。
- `SellerWorksController` 负责列表；`SellerWorkDetailController` 按 workId 管理聚合详情和状态组件。

## 3. 依赖前置

- 依赖主框架、SellerAPI/Model。
- Java：`GET /api/catseller/works`、`GET /api/catseller/works/{workId}`、`DELETE /api/catseller/works/{workId}`。
- 开发依赖作品列表 UI；视频完成态暂无专属 UI，先按 PRD 信息结构实现。

## 4. 视觉参考与设计稿分析

没有独立作品列表原图。列表视觉使用最新 UI；状态内容参考图 02、06、07、09、10。列表不显示筛选栏；卡片至少包含封面、名称、状态、更新时间/有效期和失败摘要。隐藏/删除项不伪装成普通失败。

## 5. 涉及模块与类

| 类 | 职责 |
|----|------|
| `SellerWorksController` | 游标分页、下拉刷新、登录引导、详情返回刷新 |
| `SellerWorkDetailController` | 最新聚合详情、状态组件、前台轮询和操作权限 |
| `SellerWorkSummary/Detail` | 摘要与真源详情 |
| `SellerWorkStateView` | 草稿/运行/编辑/完成/失败/隐藏视图分发 |

## 6. 业务内容与数据流

```text
进入作品 Tab
  ├─ 未登录：展示空框架和登录按钮
  └─ 已登录：加载无筛选列表

点击卡片 → GET 最新详情
  ├─ DRAFT → 填写信息
  ├─ CONTENT_RUNNING → 内容生成
  ├─ EDITING → 编辑脚本
  ├─ VIDEO_RUNNING → 视频生成
  ├─ COMPLETED → 视频完成
  ├─ FAILED → 按 failedStage/resumeState 展示恢复入口
  └─ HIDDEN/DELETED → 生命周期说明
```

- 列表只在进入、下拉刷新、分页和详情返回状态变化时刷新，不常驻轮询。
- 运行中详情按 `nextPollAfterMs` 轮询，后台/离开/终态停止。
- 运行中不显示取消和删除；草稿、编辑、完成按后端 `actions` 显示可执行操作。
- 7 天隐藏、30 天删除使用服务端时间和状态，不用本机时间决定。

- 七种状态入口逐一测试通过。
- 列表缓存过期时不会进入错误页面。

- 游客可看作品 Tab 框架，详情登录后回原作品。

## CHG-0044 完成态详情编辑

- 完成态详情仍停留在原作品路由；标题和当前分镜文本通过 `DETAIL_EDIT` 保存，禁止调用填写页 `INPUT_EDIT` 参数。
- 商品脚本直接展示 `draft.storyboardScript.shots` 的画面与口播，不展示商品卖点，也不支持镜头结构修改。默认只读，右上角铅笔进入统一编辑态；失焦不保存，底部“取消 / 确定”负责整轮还原或批量提交变化分镜。
- 标题使用 Figma `32:268` 底部弹框；横竖屏详情分别对齐 `31:96`、`37:95`；底部按钮始终保留 36px 安全间隙。
- 验收门禁：保存前后 `status`、任务进度、脚本指针和视频结果不变；失败保留本地输入和编辑态；取消不请求；无脚本不可编辑。
- 完成态点击“重新生成”不经过 `DETAIL_EDIT`：新建视频报价、显示积分确认、确认后复检余额、提交带幂等键的视频任务并进入合成等待页。重新生成再次计费，但不得先把作品改为草稿。

## CHG-0058 登录统一隐私协议前置（作品入口）

- 未登录用户点击底部“作品”时，`MainController.changeTab` 只调用统一的 `CustomRouter.openLogin`；不得在作品模块重复实现隐私判断或直接展示登录页。
- 用户同意后完成受保护服务初始化，再进入登录页；用户拒绝、关闭失败或原页面上下文失效时停留主页面，作品 Tab 仍保持未选中。
- 登录公共入口和登录路由门禁负责隐私校验；已登录用户进入作品 Tab 的行为不变，登录页内部提交登录前的页面级协议勾选继续保留。
- 自动化覆盖同意后进入登录页、拒绝后不跳转，并与直接登录、鉴权重定向、账户入口及 401 回跳共用同一套门禁回归。
