# CHG-0030 首页歌曲二级页返回与播放状态同步开发计划

> 路径恢复：2026-07-31 从错误工作区别名 `catsinger` 迁入；本文 CHG 已按 `旧编号 + 14` 重编号，原文保存在 `archive/path-recovery-20260731/`。

## 范围

- SongHomeListPage 返回按钮直接复用 SongWorkDetailPage 当前使用的圆形按钮组件。
- SongPlayerController 的配置歌曲模式在进入自身播放会话后，与 MusicPlayService 当前歌曲、详情、进度、时长和播放状态保持一致。
- 不修改接口、路由地址、首页编排、作品所有者操作和原生工程。

## 状态边界

1. 页面初次打开时仍显示用户点击的配置歌曲，不跟随无关的旧播放会话。
2. 当前配置歌曲开始播放，或用户在播放器执行上一首/下一首后，控制器绑定全局播放会话。
3. 绑定后当前歌曲变化必须同时更新活动 ID、详情、时长、进度和播放态。
4. 页面销毁时释放 GetX Worker，不继续持有页面状态订阅。

- 配置歌曲播放器从第一首切到第二首后，页面标题和 Controller 当前 ID 同步更新。
- 相关 Widget 测试、生产代码分析和差异检查通过。
