### TC-M01-01 `X-OS-Type` 新值被接受、非法值被拒
- 关联：AC-06-1、AC-01-2　优先级：P0　层：自动
- 步骤：分别带 `web`、`WINDOWS`、`mac`、`ios`、`linux` 请求 `GET /api/drama/config`
- 预期（界面）：无
- 预期（数据）：前四个返回 200；`linux` 返回 HTTP 400 + `{"code":-400,"message":"Unsupported X-OS-Type"}`
- 验证方式：B-01 测试

### TC-M01-02 密码表结构正确
- 关联：AC-11-4　优先级：P1　层：自动
- 预期（数据）：`user_password_credentials` 字段、`UNIQUE (user_id)`、外键与 data-model.md 一致
- 验证方式：B-02 测试 + Flyway 日志

### TC-M01-03 密码登录成功 / 密码错误
- 关联：AC-11-2　优先级：P0　层：自动 + 人工
- 前置：账号已设密码 `Miao2026!`
- 步骤：1. 正确密码登录。2. 错误密码登录。
- 预期（界面）：1 登录成功；2 红字“手机号或密码错误”
- 预期（数据）：1 返回 api.md §3.2 成功样例结构；2 返回 -1309、HTTP 400；`auth:pwd-fail:catdrama:{userId}` = 1
- 验证方式：B-03 测试；F-03 截图

### TC-M01-04 未设密码 / 无账号用密码登录
- 关联：AC-11-3　优先级：P1　层：自动 + 人工

- 验证方式：B-03 测试；F-03 截图

### TC-M01-05 无密码老账号注册 = 给原账号设密码
- 关联：AC-11-5、AC-11-4　优先级：P0　层：数据链路
