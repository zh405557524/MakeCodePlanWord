## 1. 功能定位与边界

本模块负责视频解说创建流程的前端闭环：用户进入视频解说创建页，上传或选择视频素材，配置解说风格、配音角色、语速和更多设置，点击立即生成前完成本地校验，并进入积分消耗确认或权益不足提示。

本模块包含：

- 视频解说创建默认态。
- 已选择视频后的创建态。
- 上传 / 选择已上传视频弹层。
- 删除素材二次确认。
- 视频解说 / 视频精剪风格选择弹层。
- 配音角色、试听、情绪标签弹层。
- 创作更多设置弹层。
- 多样版本开关、背景音乐入口占位。
- 生成前本地校验与积分预估 mock。
- 积分消耗确认弹窗、权益不足弹窗的触发与承接。

本模块不包含：

- 真实视频上传到云存储。
- 真实素材解析。
- 真实生成任务创建。
- 真实积分扣减。
- 背景音乐完整选择页；当前只保留入口和状态字段。
- 作品列表与作品详情；生成结果展示由作品模块负责。

## 6. 业务内容与数据流

### 6.1 创建页主数据流

```text

CreationView
  -> CreationController.onInit()
  -> CreationStore.restoreDraft()
  -> CreationApi.fetchUploadedMaterials(mock)
  -> 用户选择素材 / 参数
  -> CreationStore.saveDraft()
  -> 点击立即生成
  -> local validate
  -> CreationApi.estimate(mock)
  -> points confirm or entitlement dialog

```

### 6.2 素材规则

- 至少选择 1 个视频。
- 单视频建议限制：不少于 10 秒，不超过 30 分钟。
- 最多选择 10 个视频。
- 多视频时展示已选数量和总时长。
- 删除素材必须二次确认。
- 素材解析失败时不可进入生成。

### 6.3 参数规则

- 默认风格：按 PRD 选择视频解说默认项，具体文案以 Figma 为准。
- 风格分为视频解说和视频精剪两类。
- 配音角色支持试听，试听不改变已选角色。
- 语速可先用固定选项，选中值写入草稿。
- 多样版本开关写入草稿。
- 背景音乐入口先做可点击占位，后续补完整页面。

### 6.4 生成前规则

```text

点击立即生成
  -> 校验登录
  -> 校验素材
  -> 校验素材时长和数量
  -> 校验参数完整
  -> 请求 / mock 积分预估
  -> 积分足够：弹出积分确认
  -> 权益不足：弹出权益不足
  -> 确认生成：mock 创建任务
  -> 进入作品列表或作品详情

```

真实接口待确定期间，积分预估可按“总原视频时长每分钟 20 积分”的 PRD 规则做 mock，但需标注取整规则待确认。

## 10. 验收标准

- 从创作首页点击创建项目可进入视频解说创建页。
- 创建默认态展示上传入口、计费提示、参数区和立即生成按钮。
- 选择素材后页面切换为已选视频态，展示数量、总时长、缩略图和删除入口。
- 风格弹层可切换视频解说 / 视频精剪，并把选择回填到创建页。
- 配音弹层可试听、选择角色、选择情绪，取消不保存，确定保存。
- 更多设置弹层可切换多样版本，背景音乐入口可点击。
- 已上传视频弹层可选择素材并回填。
- 删除素材必须二次确认。
- 未选择素材、时长不合法、超过数量、预估失败、权益不足都有明确反馈。
- 积分确认后能 mock 创建任务并跳转作品相关路由。
- `flutter analyze` 无新增错误。

## 11. 编码注意事项

- 页面层不得直接调用真实上传、支付、生成接口。
- 生成前按钮必须有 `submitting` 防重复点击。
- 所有弹层关闭行为要明确：取消不保存，确定才写入草稿。
- 试听音频需要处理切换角色时停止旧音频；真实音频 SDK 未确认前先做占位。
- 背景音乐完整流程待确认，不要在本模块硬造复杂音乐库。
- 积分预估 mock 只能作为前端占位，不要写成最终计费逻辑。
- 删除确认文案中“分镜 / 素材”的称呼需要按最终 UI 文案统一。
