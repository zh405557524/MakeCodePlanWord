## 1. 定位与边界

### 1.1 为什么需要这一份

三种练习方式分散在两个分册里（和弦在 `C`，手机与钢琴在 `S`），各自写得都对，但有三个问题只有放在一起才看得出来：

1. **同一个「同时按下的音组」概念，两处用了不同的容差**——和弦练习 720ms，歌曲钢琴模式 280ms，相差 2.5 倍，而总纲 8.4 明确写着「本文档不预设数值」。
2. **「答错之后怎么办」需要统一**：三页均停在当前目标，订正正确后再前进，正确率仍按首次尝试计。
3. **总纲 8.4 与 8.7 里有若干条规范，当前实现并没有落地**（节奏模式分级判定、手别的页内切换、手机模式的左 1/3 预读），继续按现状开发会让文档和代码越走越远。

### 1.2 本文件包含

- 三种练习方式的范式归类、输入、判定、前进、结算对照。
- 判定触发时机与容差的统一口径（含代码实测值）。
- 答错后的前进策略定义。
- 规范与当前实现的差异清单及处理建议。
- 三者共用的状态色与控件规范。

### 1.3 本文件不包含

- 页面结构与页面级验收 → 见 04 / 05 分册。
- 识谱练习 N-01 / 视奏挑战 N-03 → 那是出题式的另一支，见 03 分册。
- 个人曲谱练习 I-08 → 复用 S-04 页面语义，规则随 S-04。
- 曲库解锁、会员权益、曲谱导入 → 见对应分册。

## 3. 判定与前进规则

### 3.1 判定触发与容差

总纲 8.4 写的是「时间窗口与音组容差阈值需由真实设备验证后确定，本文档不预设数值」。当前代码里已经存在实测值，先登记下来，再统一。

| 常量 | 位置 | 当前值 | 作用 |
| --- | --- | --- | --- |
| 和弦自动提交延时 | `chord/controller.dart` `_autoSubmitDelay` | **720ms** | 末次 Note On 后无新音即提交整组 |
| 和弦反馈停留 | 同上 `_feedbackHoldDuration` | 1100ms | 错答反馈后留题，答对反馈后进入下一题 |
| 钢琴音组聚合窗口 | `piano/controller.dart` `_midiChordWindow` | **280ms** | 首音后收拢同拍点的音 |
| 钢琴正确反馈 | 同上 `_midiCorrectFeedbackDuration` | 120ms | 闪一下即前进 |
| 钢琴错误反馈 | 同上 `_midiWrongFeedbackDuration` | 450ms | 反馈后停在原目标 |

**需要定的规则：**

- 两个窗口服务的是同一件事——「判断用户想同时按下哪几个音」——**应当收敛成同一个口径**。当前 720ms 与 280ms 的差距不是有意设计，是两处各写各的。
- 和弦练习是出题式、不赶时间，容差可以更宽；歌曲钢琴模式在片段里连续弹奏，窗口过宽会把下一拍的音吃进来。因此**允许分档，但必须是同一个命名参数的两个取值，并写进总纲 8.4**，而不是两个互不相干的常量。
- 和弦练习的判定由 **Note On 触发的定时器**驱动，不是松手判定：用户按住不放也会在 720ms 后被提交。这一点要在 C-01 的交互说明里写明，否则容易被实现成松手判定。

### 3.2 答错之后怎么走（本文件的核心决策点）

三页均先显示谱面，让用户读谱作答；开题不直接高亮目标键。设置 `hintDelay` 控制预先提示：默认 3 秒，`5s` / `10s` / `30s` 按设置延时，`none` 不预先提示，旧值 `instant` 在这三页按最短 3 秒处理。和弦名称始终可见，组成音与目标键一同延时出现。换题、重试、暂停、断连或退出取消旧倒计时；恢复可答题时重新计时。答错后的正误反馈不受预先提示设置影响。

| | 答错后 | 答对后 |
| --- | --- | --- |
| C-01 和弦练习 | 反馈后留在本题 | 推进下一题 |
| S-03 手机模式 | 屏幕与 MIDI 反馈后留在本音 | 记录首次结果，寻找下一未通过音 |
| S-04 钢琴模式 | 反馈后留在本目标 | 推进下一目标 |

手机模式的手动跳小节只移动视图和当前待弹位置，不把跳过的音算通过。三页正确率按首次尝试计；先错后对仍计错。
续练点保存明确已通过的目标及首次错误状态；旧续练点只有位置时，位置之前无法确认通过的目标仍需补练。完整结果先在本机落盘，再由现有队列同步。

### 3.3 正确率与错题口径

- 正确率 = 首次作答正确数 ÷ 已通过目标数。练习中未通过的错音不增加完成度；「先错、后对」计为错。
- 错题以**小节**为单位汇总（和弦练习以**题号**为单位），供结算页的「仅重练错题」使用。
- 练习过程中**不显示正确率**（总纲 8.7 共性约束 2：练习中只显示进度）。这一条当前设计稿有违反，见 5.4。

## 5. 改版要求

> 配套 UI 稿：三个横屏练习页与设计规范板（920×424 基准）。以下只写需求，视觉细节以设计稿为准。

### 5.1 三页共用的横屏骨架

横屏最稀缺的是纵向空间，而三页目前都把功能按钮堆在顶部，挤压谱面。改为：

- **左右两条 56pt 竖栏承载功能按钮**，左栏放导航类（返回、暂停、重来 / 试听），右栏放练习动作类（上下小节 / 循环 / 重试 / 跳过）。
- **顶部只保留曲名（或题序）、进度、设备状态**，高度不超过 50pt。
- **谱面拿走剩余的最大一块**，这是总纲 8.7 共性约束 1 的直接落地。
- 图标按钮统一 44×44pt，**下方带中文小标**——纯图标是当前「不够友好」的主要来源之一。
- 键盘区底色用浅蓝灰而非白，否则白键在白卡片上没有边界。

### 5.2 C-01 和弦练习

1. 当前阶段（`basic` / `inversion`）与达标条件常驻顶部，升档时给出明确反馈。
2. 接入错题重练：本轮答错的题在结算页可单独重练。
3. 开题保留和弦名与谱面，组成音和目标键按 `hintDelay` 延时显示。
4. 漏按 / 多按 / 错按三色反馈配常驻图例——反馈本身已实现，缺的是用户看不懂颜色含义。
5. 交互说明中写明判定由静默 720ms 自动触发，不是松手判定。
6. 无 MIDI 时使用屏幕琴键作答，仍执行同一套判题与首次计分。

### 5.3 S-03 歌曲手机模式

1. 屏幕与 MIDI 均执行错答停留、订正后推进；手动跳小节不计通过。
2. 白键标注音名——手机模式面向的正是没有钢琴、也不熟悉键位的用户。
3. 进度条上标出错过的小节，与结算页的「仅重练错题」形成闭环。
4. 页面结构不列速度控件（差异清单 #6 已修订）。
5. 预读问题（差异清单 #5）单独决策，不在本次改版范围内。

### 5.4 S-04 歌曲钢琴模式

1. 本期页内提供**播放 / 练习**两个互斥模式。播放用曲谱的真实 MIDI 音频，播放线随音频移动；屏幕琴键只发声。
2. 练习显式开始 / 结束，只由外接 MIDI 作答；正确键绿色并前进，错误键红色、线变红并停在目标，弹对后继续。
3. 练习明细保存每次目标与实际 MIDI 音高、正误、时间和范围；播放不记练习。结果页只展示真实统计，音符识别与熟悉度指导后续提供。
4. 手别页内切换、A–B 循环与更细的和弦缺音提示保留为后续改进，不作为本期两模式交互的验收条件。

### 5.5 统一的状态色语言

五个状态，全局唯一，三个练习页与曲谱导入审核页共用：

| 状态 | 主色 | 浅底 | 深字 | 用途 |
| --- | --- | --- | --- | --- |
| 正确 / 已弹对 | `#18BF82` | `#E4F7EF` | `#076B45` | 已答对的音、按对的键 |
| 缺失 / 提示 | `#FFA51F` | `#FFF2DC` | `#8A5209` | 和弦里还没按的音、提示态 |
| 错误 | `#FF5058` | `#FFE9EA` | `#B32028` | 弹错、整组判错 |
| 多余音 | `#6555FF` | `#EFEAFF` | `#4B3BAF` | 多按的键、A–B 循环区段 |
| 待弹 / 未到 | `#9BA8CE` | — | — | 后续音符，只描边不填充 |

规则：

- 饱和色只用于填充与音符，**不承载小字**；需要文字时用「浅底 + 深字」那一对。
- **红压过蓝**：一个音同时是「当前目标」和「有问题」时显示红色。
- 一屏只允许一个主色填充块（当前目标）。

### 5.6 设计稿与总纲的一处冲突（需裁决）

配套 UI 稿在顶部信息条放了**正确率与连对次数**，这与总纲 8.7 共性约束 2「练习中弱化统计，准确率留到结算」直接冲突。

两条路：维持总纲、把正确率从练习页拿掉；或修订共性约束 2，允许「连对次数」这类正向即时反馈但仍禁止准确率。**建议后者**——连对是驱动力，准确率才是焦虑源，两者性质不同。**本项未决，实现前需确认。**

## 6. 验收要点

- 三个练习页的功能按钮位于左右竖栏，顶部不超过 50pt，谱面为最大区块。
- 图标按钮 44×44pt 且带文字小标。
- 五个状态色在三个练习页与曲谱审核页表现一致；红压过蓝。
- 三页开题无目标键高亮，按设置延时提示；`none` 不预先提示，旧 `instant` 最早 3 秒后提示。
- 手机模式的屏幕与 MIDI 均错答停留、订正推进；手动跳小节不计通过。
- 正确率三页统一按首次作答计，重试不改判。
- 钢琴模式可清楚切换播放与练习；练习开始 / 结束、错音停线与订正后继续可见。
- 钢琴模式等待判定时，和弦缺哪个音有明确文案。
- 和弦练习显示当前阶段与达标条件，升档有反馈，错题可单独重练。
- 音组容差在总纲 8.4 有明确取值，代码中无第二套未登记的常量。
