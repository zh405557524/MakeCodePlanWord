## 1. 功能定位与边界

统一处理 V2.1 页面中的会员门禁、训练/翻唱独立报价、积分回跳、未提交草稿和活动任务恢复。前端不实现计费结算，只展示服务端事实。

## 2. 会员与积分规则

- 训练和翻唱均是会员能力，但计费场景独立。
- 价格从模型接口实时读取；100/200 仅为后台初始配置，不写死 UI。
- 未配置价格、模型停用或容量关闭显示“暂未开放”。
- 非会员进入现有会员页；积分不足进入现有充值页。
- 回跳后保留输入，但重新请求模型、价格、音色和素材状态。
- 任务成功后刷新积分；失败/超时由后端释放后再刷新，不在本地加回。

## 3. 草稿范围

允许保存：源作品 ID或已完成业务 assetId、音色/模型版本 ID、设置、模型项、授权版本、entrySource、活动训练/翻唱 taskId。

禁止保存：OSS/Provider 签名 URL、厂家模型 ID/文件地址、原始音频二进制、长期本地路径、Token 和支付信息。

建议键包含 `catsinger.voice_cover.v2.1.{userId}`，并遵循现有 GetStorage/Hive 方案。

## 4. 幂等键生命周期

- 用户第一次确认提交时生成。
- 网络失败且未修改关键输入时复用。
- 后端返回原任务时直接恢复。
- 源歌曲、音色、模型、设置、授权版本或报价改变后生成新键。
- 训练与翻唱使用不同作用域，不能共用键。

## 5. 恢复顺序

```text
读取本地定位信息
  -> 查询活动 taskId/服务端详情
  -> 查询源素材、音色、模型和报价
  -> 清除已删除/拒绝/停用选择
  -> 恢复可用表单或进入任务页
```

本地内容只作定位线索，不能覆盖服务端状态。账号切换、退出登录或隐私撤回必须清空本账号草稿、任务引用和试听缓存。

## 6. 异常与并发

- Token 失效先走现有登录恢复，成功后重新验证 owner 和页面状态。
- App 切换或用户切换时取消旧请求，epoch 不一致的响应丢弃。
- 同一按钮独立 busy，训练和翻唱任务不能并发双提交。
- 草稿版本不兼容时安全丢弃并记录本地诊断，不崩溃。

## 7. 实现步骤

1. 定义版本化草稿 DTO 和关键字段指纹。
2. 接入会员/充值回跳及重新报价。
3. 实现训练/翻唱独立幂等键生命周期。
4. 实现活动任务优先恢复和终态清理。
5. 接入登录、退出、隐私撤回和 App 切换清理钩子。

## 8. 测试与验收

- 非会员、积分不足、充值成功/取消后返回同一页面。
- 报价变化后旧 pricingVersion 不可提交。
- 双击、网络超时、杀进程不会重复扣费或创建两任务。
- A 用户草稿不会出现在 B 用户；catsinger 状态不会串到其他 App。
- 退出登录和隐私撤回后无本地音频引用、签名 URL 或活动任务残留。
- 后端失败释放积分后余额刷新准确。
