## 使用边界

- 正式产品名沿用用户已确认的「翻唱声音克隆」；Figma 图层中的「AI翻唱」只作为视觉来源名称。
- 设计中的 `6~90s`、`45MB`、`1分钟`、`30/80/120/180/260积分`、`-12~12`、`0~200%` 等均为示例。产品校验读取当前模型的有效能力和实时报价。
- 设计中的「取消」不得解释为取消已经创建的训练或翻唱任务；当前产品规则仍是不提供任务取消。
- 本期只允许克隆本人声音。使用规范、权利声明等正式法律文案以审核后的平台协议为准，设计文字不直接作为上线协议真源。
