## 4. 交互验收

首页：

- 输入 prompt 后点开始创作，切到写歌 Tab 并回填描述。
- prompt 为空点开始创作，切到写歌 Tab，不提交。
- 纯音乐入口切到写歌 Tab，并开启纯音乐。
- AI作词入口切到高级创作或显示 AI帮写入口。

写歌：

- 灵感/高级分段切换正常。
- 灵感速递 loading 禁止重复点击。
- 灵感速递成功覆盖音乐描述。
- AI帮写成功回填歌词。
- 模型为空时不能提交。
- 提交中不能重复点击。

场景写歌：

- 第 1 步到第 4 步依次为送给谁、什么场景、想表达什么、喜欢什么风格。
- 点选选项只改变选中态，不自动跳题。
- 未选择时底部按钮置灰，选择后按钮高亮。
- 已选答案累计显示为绿色小标签。
- 第 4 步点击开始创作后切到写歌 Tab，并回填音乐描述。
- 场景来源提交生成时带 `mode=scenario`、`sceneCode`、`sceneAnswers`。

作品：

- 歌曲/专辑分段切换正常。
- 生成中/已完成分组能同时展示。
- 已完成作品点击进入播放器。
- 创建专辑成功后切到专辑 Tab。

我的：

- 未登录时需要登录的入口跳登录。
- 已登录时会员、积分、订单、任务、反馈、设置入口能跳转。
- 联系客服暂未接入时有明确 toast。

## 5. 状态验收

每个主页面至少覆盖：

- loading
- empty
- error
- disabled
- submitting

空态要求：

- 首页案例为空，只影响热门案例区，不让整页空。
- 首页最近作品为空，只影响最近作品区。
- 作品为空时显示去写歌入口。
- 专辑为空时显示创建专辑入口。

错误态要求：

- 配置失败可重试。
- 案例失败不影响写歌能力。
- 最近作品失败不影响首页 prompt。
- AI帮写/灵感速递失败必须 toast。

## 6. 布局验收

- 所有文字不使用 viewport 字体缩放。
- 按钮文字不溢出。
- 长标题单行省略或两行截断。
- 大输入卡内字数和底部动作不重叠。
- 固定按钮不遮挡迷你播放器和底部 Tab。
- 列表底部 padding 足够。
- 键盘弹起时写歌输入区域可滚动到可见位置。
