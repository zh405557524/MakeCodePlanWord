# 测试数据与安全门禁

## 账号矩阵

| 编号 | 用途 | 数据要求 |
|---|---|---|
| U-FRESH | 首次启动 | 清除 App 数据或新设备，无隐私选择、无 Token |
| U-NORMAL | 主流程 | 注册账号，积分充足，含多种作品 |
| U-LOW | 积分不足 | 余额低于当前最便宜写歌/翻唱模型价格 |
| U-VIP | 会员 | 有效会员和至少一条已支付会员订单 |
| U-GUEST-IOS | iOS 游客 | 新设备游客账号，可恢复到同一游客身份 |
| U-INVITER/U-INVITEE | 邀请 | 两个未互相绑定过的注册账号 |
| U-DISPOSABLE | 注销 | 一次性注册账号，无需保留的作品/订单 |

## 作品与资源

- 原创、纯音乐、翻唱各至少 2 首。
- 生成中、失败、完成、无封面、静态歌词、时间轴歌词、长标题各至少 1 首。
- 准备第三方临时地址已过期但平台持久地址有效的作品，以及持久地址失效的错误样本。
- 自动化新建标题统一使用 `AUTOTEST_{run_id}`，只清理当前运行记录的作品 ID。

## 音频边界

- 合法：MP3、WAV、M4A、AAC、FLAC；另按当前 Android 兼容逻辑准备 MP4 音频容器。
- 时长：5 秒、6 秒、30 秒、5 分钟、5 分01秒、6 分钟、6 分01秒。
- 大小：接近 50MB、等于 50MB、超过 50MB。
- 异常：损坏文件、空文件、伪扩展名、无读取权限文件。
- 专业写歌参考音频和 AI 翻唱源音频分别执行边界，不把两者时长规则混用。
- 专业闭环数据额外准备：一首当前用户的可播放完成作品，两个可区分的合法本地音频 A/B，以及一个可控上传失败样本。
- 参考音频生成作品标题使用 `AUTOTEST_REF_WORK_{run_id}` 或 `AUTOTEST_REF_LOCAL_{run_id}`，记录源 assetId、taskId、workId 和积分流水，便于核对任务快照与安全清理。

## 后台预置

- 当前 App 切换为 `catsinger`。
- 简易、专业、歌曲改编、翻唱场景各配置至少两个启用模型；配置一个禁用模型、不同积分价格、默认项、长公开名称和说明。
- 配置至少两个翻唱音色，其中一个带试听音频；另准备全部停用状态。
- 配置首页歌曲、封面、音频、热门案例、会员/积分商品、任务、邀请规则和版本更新策略。

## 危险操作

- 生产环境只允许 `normal` 只读用例。
- `paid` 需测试环境并显式传 `--allow-paid`。
- `delete` 需显式传 `--allow-delete`，且只能删除本次运行或指定测试作品。
- `account_delete` 需一次性账号并显式传 `--allow-account-delete`。
- Android 外部支付宝与 iOS StoreKit 使用测试链路；没有沙箱时只执行到付款前确认页。
