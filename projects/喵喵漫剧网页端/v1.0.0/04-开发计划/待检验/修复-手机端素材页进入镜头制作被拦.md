## 1. 问题

用户规划的流程（`01-产品/requirements.md` 第 44 行的流程图、AC-32-1）：

1. 素材页点“进入镜头制作”；
2. 系统自动做片段分析（页面显示等待）；
3. 进入镜头制作页。

手机端现在的做法（`lib/pages/projects/materials/view.dart` 的 `_shots`，第 844～849 行）：

```dart
if (!e.entryState['shots']!.accessible) {
  CustomToast.text(e.entryState['shots']!.reason ?? AppStrings.projectUnavailable);
  return;
}
```

这段在调“确认素材”之前执行。新流程下，还在素材阶段的集没有片段，后端返回 `entryState.shots.accessible = false`、原因“请先完成片段分析”（后端 `EpisodeProgressService#entryState`，测试 `materialsStageShouldNotEnterShots` 也这样断言）。结果：手机端要求“片段分析做完才让点”，后端是“点了才开始片段分析”，新作品永远进不去，只会提示“请先完成片段分析”。老作品（已经有片段的）不受影响。

## 3. 任务 P-01：素材阶段点“进入镜头制作”不再先查“镜头制作页能不能进”

- 可改文件：`lib/pages/projects/materials/controller.dart`、`lib/pages/projects/materials/view.dart`、`test/projects/shot_generation_contract_test.dart`
- 具体做法：
  1. 在 `MaterialsController`（`controller.dart`）里加一个不依赖页面的静态方法，把“点了以后要不要拦、拦的话提示什么”写在一处：
     ```dart
     /// 点“进入镜头制作”时要不要拦住：返回要提示的原因；返回 null 表示可以继续。
     /// 素材阶段：只看素材页本身能不能用，片段还没生成是正常的（点了以后系统才做片段分析）。
     /// 片段、视频阶段：看镜头制作页能不能进。其他阶段：不能进。
     @visibleForTesting
     static String? shotsEntryBlock(DramaEpisode e) {
       final stage = e.stage;
       if (stage == DramaEpisodeStage.materials) {
         final access = e.entryState['materials']!;
         return access.accessible ? null : (access.reason ?? AppStrings.projectUnavailable);
       }
       final access = e.entryState['shots']!;
       if (stage == DramaEpisodeStage.shots || stage == DramaEpisodeStage.videos) {
         return access.accessible ? null : (access.reason ?? AppStrings.projectUnavailable);
       }
       return access.reason ?? AppStrings.projectUnavailable;
     }
     ```
     需要 `@visibleForTesting` 的 import 时，按本仓库 part 聚合的写法加在 `lib/pages/projects/materials/index.dart`——**这个文件不在可改文件里，必须加 import 时停下问用户**；可以不用这个注解（去掉 `@visibleForTesting` 一行即可），优先不加。
