#### B-01 片段里切换形象（K-21）
- 关联：AC-01-7、AC-01-8；总览第 1 行
- 文件：`shot/controller/DramaShotController.java`（`POST /shots/{shotId}/look-switch`）、新建 `shot/dto/ShotLookSwitchRequest.java`（严格读取，照 `ShotEditRequest.Reader`）、`shot/service/DramaShotService.java`（新增 `switchLook`）
- 做法：
  1. 校验：片段本人、`ACTIVE`、版本 = `expectedRevision`（否则 `-560001`）；`from` 是这个片段的引用；`from`、`to` 都是本集未归档关联，且两个素材的主体相同（主体 ID = `parentAssetId ?: id`），否则 `-560007`“只能在{主名}自己的形象之间切换”；`to` 已在片段里 → `-560007`“本片段已在用「{名}」”；`to` 没有可用的已应用图片 → `-560002`“「{名}」还没有图片，请先去角色详情生成”；片段有进行中的视频任务 → `-560005`。
  2. 换：调 `DramaShotProjectService#replaceReference` 的单片段版本（在 `shot` 包内把 M02 的方法抽出一个“只处理给定片段”的私有方法共用），描述里 `@from名` → `@to名`。
  3. `applyToFollowing = true`：本集按 `ordinal` 往后取片段，条件“场景引用集合和当前片段完全相同、并且引用了 `from`”，遇到第一个场景不同的就停；跳过有进行中视频任务、已经有 `to` 的；每个照第 2 步换。一个事务。
  4. 返回改到的全部片段（用现有 `DramaShotResponse` 组装，含 B-02 的 `reminders`）。
- 验证：新增 `src/test/java/com/lxwx/narrateservice/CatdramaShotLookTests.java`（PostgreSQL 集成，同 M02 启用条件）：单个切换、描述替换（台词引号里的不换）、带上后面 2 个同场景片段 + 第 3 个不同场景停住、`to` 已在用、`to` 没图、跨角色、视频任务中、版本过期；`./gradlew test --tests '*CatdramaShotLookTests' --tests '*CatdramaShotTests'`；用例 TC-M05-01、TC-M05-02
- 结果：（Claude，2026-11-24，提交 `d4c9c8a8`）`POST /shots/{shotId}/look-switch`、`ShotLookSwitchRequest`（严格读取）、`DramaShotLookSwitched{shots}`、`DramaShotService#switchLook`。`DramaShotProjectService` 把 M02 `replaceReference` 的逐片段部分抽成包内方法 `replaceInShots`（`replaceReference` 改为调它，行为不变），另加包内 `busyShots`。和计划的出入：① 切换时按新描述、新引用**重算对白和时间计划**（`speech_spec`、`timing_plan`），M02 的删除形象路径不重算（照旧）；② `from` 不在片段里也返回 -560007“只能在{主名}自己的形象之间切换”；③ 本场后面的片段：场景集合相同但没用 `from` 的跳过、继续往后看，遇到场景不同才停；“正在生成”= 有进行中的视频任务或视频 GENERATING / PROCESSING。新建 `CatdramaShotLookTests`（PG，6 个用例：带后面片段 + 场景不同停住 + 已在用 / 不用的跳过、只换当前再换回、已在用 / 没图 / 跨角色 / 版本过期 / 视频生成中、后面片段在生成被跳过、提醒、请求格式）。编译通过，测试没跑。 Codex（2026-11-24）：相关自动或人工证据已核对，覆盖详情见总检验清单。
