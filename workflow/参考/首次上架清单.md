# 首次上架清单（参考）

第一次把 App 提交到某个商店，或第一次上线付费功能时对照。日常版本发布用 `release.md` 里的检查清单即可。

## 构建与签名

- [ ] 包名 / Bundle ID、版本号、构建号策略确定（构建号只增不减）
- [ ] dev / staging / prod 三套环境配置分开，正式包指向正式环境
- [ ] Android：keystore 不入仓库，密码通过环境变量注入；AAB 提交；64 位；targetSdk 满足 Google 当年要求；混淆规则验证过
- [ ] iOS：证书和描述文件有效；Capabilities（推送、Sign in with Apple、内购）开启；ATS 配置；隐私清单（Privacy Manifest）包含所用的 Required Reason API 和三方 SDK
- [ ] Info.plist 中所有权限说明文案清楚说明用途
- [ ] 崩溃符号（dSYM / mapping）会上传到崩溃平台
- [ ] 图标、启动图齐全；正式包没有调试日志、测试账号、占位图、Beta 字样

## 隐私与合规

- [ ] 隐私政策和用户协议有可访问的 URL，内容与 App 实际行为一致
- [ ] 隐私政策列出所有三方 SDK：名称、用途、收集的信息
- [ ] 用户同意隐私政策之前，不初始化会收集个人信息的 SDK
- [ ] 提供账号注销入口；拒绝授权后基础功能可降级使用
- [ ] 目标地区的法规：欧盟 GDPR、美国 CCPA / COPPA（涉及儿童时）
- [ ] Google Play 数据安全表单、App Store 隐私营养标签已填写且与实际一致

## 付费与订阅

- [ ] 商店商品已配置，各地区价格已确认
- [ ] 订阅页清楚说明价格、周期、自动续订、取消方式
- [ ] 提供"恢复购买"
- [ ] 不引导用户到 App 外支付（除非所属品类允许）
- [ ] 沙盒 / 内部测试账号覆盖至少两个不同币种的地区
- [ ] 服务端校验收据；订单记录商店实际币种和金额

## 商店素材

- [ ] 各尺寸截图（iPhone 6.7"/6.5"、iPad（如支持）、Android 手机 / 平板）
- [ ] 各语言的名称、副标题、描述、关键词
- [ ] Google Play 特色图
- [ ] 年龄分级问卷

## 常见拒审原因

**App Store**
- 不登录就无法使用任何功能（应允许先浏览）
- 订阅信息披露不完整
- 使用了其他第三方登录却没有提供 Sign in with Apple
- 隐私政策与实际行为不符
- 有未完成的功能、占位内容

**Google Play**
- 数据安全表单与实际不符
- 敏感权限没有合理用途说明
- targetSdk 过低
