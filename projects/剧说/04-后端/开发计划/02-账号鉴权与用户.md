本模块负责短信验证码、一键登录占位、JWT 签发、刷新令牌、退出登录、注销申请和我的页用户聚合信息。

## 3. 接口契约

### POST `/api/auth/sms/send`

请求：

```json
{
  "phone": "13800000000",
  "scene": "LOGIN"
}
```

响应：

```json
{
  "cooldownSeconds": 60
}
```

错误码：`BAD_REQUEST`、`SMS_TOO_FREQUENT`。

### POST `/api/auth/sms/login`

请求：

```json
{
  "phone": "13800000000",
  "code": "123456",
  "scene": "LOGIN"
}
```

响应：

```json
{
  "accessToken": "jwt",
  "refreshToken": "refresh",
  "profile": {
    "id": "1",
    "phoneMasked": "138****0000",
    "inviteCode": "ABCD12",
    "pointsBalance": 0,
    "vipStatus": "NONE"
  }
}
```

错误码：`SMS_CODE_INVALID`、`TOKEN_EXPIRED`。

### POST `/api/auth/one-click-login`

请求：

```json
{
  "providerToken": "token-from-client",
  "provider": "MOBILE"
}
```

响应同短信登录。

### GET `/api/user/profile`

鉴权：必须登录。

响应返回用户、积分、会员和邀请码聚合信息。

### POST `/api/user/logout`

鉴权：必须登录。撤销 refresh token，access token 到期自然失效。

### POST `/api/user/delete-request`

鉴权：必须登录。仅登记注销申请，不物理删除用户。

## 4. 数据表与迁移

| 表 | 关键字段 |
|----|----------|
| `users` | `phone_hash`、`phone_masked`、`invite_code`、`status` |
| `sms_codes` | `phone_hash`、`scene`、`code_hash`、`expires_at`、`used_at` |
| `refresh_tokens` | `user_id`、`token_hash`、`expires_at`、`revoked_at` |
| `point_accounts` | 登录创建用户时初始化账户 |

索引：

- `users.phone_hash` 唯一。
- `users.invite_code` 唯一。
- `sms_codes.phone_hash + scene + created_at` 普通索引。
- `refresh_tokens.token_hash` 唯一。

## 5. 业务规则

- 验证码 5 分钟有效。
- 同一手机号发送验证码 60 秒限流。
- 验证码只存哈希，不存明文。
- 登录时若用户不存在则创建用户、生成邀请码、初始化积分账户。
- 手机号展示只使用脱敏值。
- 一键登录 Provider 未接真实供应商前返回 mock 脱敏手机号。
- 注销申请不影响历史订单、积分流水和作品审计数据。
