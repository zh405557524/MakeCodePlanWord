## 2. 当前移动端结构

- App 名称：喵喵写歌；包名：`com.lxwx.catsinger`；请求 App Code：`catsinger`。
- 底部主导航只有三个用户可见 Tab：`首页 / 作品 / 我的`。
- 首页用户可见主入口：`AI写歌` 进入专业模式，`改编歌曲` 进入歌曲改编；首页配置歌曲可进入配置歌曲播放器。
- 创作页内部可切换：`简易模式 / 专业模式 / 歌曲改编`。三种模式均按后台公开模型目录决定是否展示“创作模型”。
- 作品页当前只展示“我的音乐”；代码中的草稿、喜欢、专辑列表不作为主页面通过条件。专辑能力仅从作品操作链路验证。
- AI 翻唱独立页面可从作品详情/播放器的“重新翻唱”进入；没有把不存在的首页入口写成当前测试前提。
- 场景写歌路由和四步 Controller 存在，但当前首页没有稳定用户入口，登记为不可达能力，不纳入正常主链路。

## 3. 用户功能真源

| 用户域 | 当前行为 |
|---|---|
| 首次启动与隐私 | 首次进入首页必须先完成隐私选择；用户协议、隐私政策可打开；拒绝不初始化受保护 SDK；后续可撤回同意。 |
| 登录与账号 | Android 支持手机号/验证码及环境允许时的一键登录；iOS 支持游客、手机号登录和恢复购买。游客可使用创作/作品/支付基础能力，邀请、兑换和账号安全要求注册账号。 |
| 简易写歌 | 输入音乐描述，可用灵感速递，支持人声/纯音乐、模型选择和生成确认。 |
| 专业写歌 | 歌名、歌词、润色歌词、歌手、风格、场景、对象、语言、时长、纯音乐、参考音频和模型选择。 |
| 歌曲改编 | 从作品库、录音或本地文件导入源歌曲，填写改编要求和歌名，选择模型后生成。 |
| AI 翻唱 | 从作品或本地音频选源，确认版权，选择后台音色，配置保留歌词/伴奏、音高、情感、混响并提交。 |
| 模型选择 | 仅展示后台对当前场景公开的固定模型；显示公开名称、实时积分价格和扩展说明；取消不生效，确认只影响本次任务。 |
| 生成任务 | 展示准备、歌词、音频、歌名、海报、保存作品等阶段；退出页面不取消任务；完成/失败后作品和积分状态应一致。 |
| 作品与播放 | 展示生成中、失败和完成作品；支持播放、暂停、拖动、上下首、静态/时间轴歌词、详情、下载、分享、收藏、删除和再创作。 |
| 后处理 | 支持重新生成、同款生成、重新翻唱、封面重做、歌词时间轴重做和加入专辑；后台异步任务必须给出处理中、成功或失败反馈。 |
| 会员积分订单 | 支持会员、积分充值、订单、积分明细；Android 走当前 Web/外部支付宝链路，iOS 走 StoreKit 并支持恢复购买。 |
| 增长能力 | 注册用户可签到、做积分任务、使用兑换码、邀请好友、查看收益和发起/查看提现。 |
| 我的与设置 | 用户资产、积分、会员、客服、反馈、协议、版本、更新、缓存、账号与安全、退出、隐私撤回和账号注销。 |

## 4. 后端与后台对账原则

- 所有用户接口由 App 自动携带 `X-App-Code: catsinger`；测试人员不直接调用接口来代替 App 操作。
- 后台用于准备模型、价格、音色、首页歌曲、商品、任务、邀请和版本数据；用例只检查配置在移动端产生的可见结果。
- 生成、扣积分、订单、提现、删除和注销的服务端状态可通过测试后台或脱敏日志做辅助证据，但移动端可见结果仍是通过判据。
- 第三方音频和封面必须最终落为平台可持续访问资源；临时 URL 失效后的播放与下载列入资源生命周期用例。
