## P0 用例

### App 首页与二级页

1. 首页保持 Banner、三个创作入口和底部导航，热门案例区域按 `sortOrder` 显示两列标签卡片。
2. 标签配置封面时显示该封面；无封面且无有效歌曲时显示渐变占位图。
3. 点击标签进入 `/song/home-lists/:tagCode`，确认二级页有返回按钮且不显示底部导航。
4. 二级页顶部显示曲线封面、红蓝光晕和标签名称；歌曲严格保持接口顺序与数量。
5. 下拉刷新成功后替换歌曲；初次加载、空列表、普通失败重试和 404 标签失效均显示对应状态。
6. 点击歌曲进入配置歌曲播放器；三点菜单只显示“查看详情”。
7. 只读详情不显示下载、分享、删除、加入专辑、重新生成和重新翻唱；“我的作品”详情原行为不变。

### Web/Admin 标签封面

1. 编辑标签时可看到封面 URL、预览、上传和清空入口，已保存 tagCode 仍不可修改。
2. 上传合法图片后显示预览并可保存；替换后列表显示新封面状态。
3. 上传非图片或超过 8MB 的文件时显示后端错误且不覆盖当前封面。
4. 清空封面并保存后恢复“第一首有效歌曲封面”提示。

### Java 与兼容

1. `GET /api/song-config/home-lists` 的 `coverUrl` 优先使用标签独立封面。
2. 未配置封面时按首页编排顺序跳过禁用、不可播放或不可公开歌曲，取第一首有效歌曲封面。
3. 显式空列表、无有效歌曲或第一首歌曲无封面时返回空字符串，不写回标签表。
4. `POST /api/admin/song/home-tags/covers` 沿用图片格式和 8MB 限制。
5. 旧 `GET /api/song-config/home-modules` 的路径、字段和 `displayMode` 保持不变。
