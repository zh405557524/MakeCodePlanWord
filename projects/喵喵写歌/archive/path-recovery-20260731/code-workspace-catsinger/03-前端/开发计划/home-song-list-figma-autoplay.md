# CHG-0017 首页歌曲二级页新版对稿与自动播放开发计划

## 范围

- 视觉真源为 TalkToFigma `thx5vx4v` 中最新 `首页2（32:247）`。
- 只修改 Flutter App 的 `pages/home/song_list`、复用歌曲列表行、播放队列接入和测试。
- 不修改公开接口、服务端编排、Web/Admin、数据库、原生层和作品所有者操作。

## UI 契约

1. 375×812 基准下，头图高 333，底部保持曲线裁切。
2. 返回区域为 34×34 的无圆底白色左箭头；栏目标题左距 21、字号 16、字重 600。
3. 歌曲列表左距 27，封面 54×54、圆角 8；相邻歌曲起点相差 70。
4. 歌名字号 16/字重 600，副标题字号 12/字重 500，更多图标 20；正文后方保留红蓝光晕。

## 播放契约

1. 列表顺序完全沿用 `/home-lists/{tagCode}/songs` 返回顺序。
2. 点击歌曲后先将列表转换为播放队列，强制定位到所点歌曲，再调用播放并进入配置歌曲播放器。
3. 播放器上一首/下一首继续由 `MusicPlayService` 和 CHG-0016 会话同步处理。
4. 无有效歌曲标识时不导航，并显示用户可读提示。

## 验证

- 执行 `dart format`、`flutter analyze`、相关 `flutter test` 和 `git diff --check`。
