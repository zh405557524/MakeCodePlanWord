## 1. 功能定位与边界

本模块负责说明弹窗类能力在 P0 的处理方式。最新口径：除首页和资产库外，其它页面原工程没有的先空白展示，因此删除确认、角色编辑等弹窗本期不按 Figma 细化实现；如入口不可避免触发，统一不执行真实动作。

## 2. 入口、路由与页面文件

| 文件 | 处理 |
|------|------|
| `lib/widgets/app_confirm_dialog.dart` | 暂不扩展，除非资产库管理入口必须确认 |
| `lib/pages/blank_feature/*` | 其它入口先空白展示 |
| `lib/pages/asset_library/*` | 管理入口只 Toast 或进入空白页 |

## 3. 依赖前置

- 依赖 T-F008 占位页。
- 依赖 T-F003 通用组件。
- Java 无依赖。

## 4. 视觉参考与设计稿分析

本模块不按首页和资产库以外的弹窗类 Frame 细节还原；相关入口本期只保留空白页或 Toast。

## 5. 涉及模块与类

- `AppConfirmDialog`
- `BlankFeaturePage`
- `CustomToast`

## 6. 业务内容与数据流

```text
点击删除 / 编辑
  -> Toast 或空白页
  -> 不展示真实编辑表单
  -> 不调接口
```
