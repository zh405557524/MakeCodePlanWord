## P0 用例

### 模块标签

1. 进入歌曲配置的“首页模块”，确认模块标签表不再显示“展示模式”。
2. 新增标签时填写名称、tagCode、状态和排序，保存后确认 tagCode 只读。
3. 编辑已有标签，确认只能修改名称、状态和排序。

### 首页列表编排

1. 确认模块标签与歌曲配置之间显示“首页列表数据”，每个标签只有一行。
2. 未保存显式列表时，确认来源为“兼容回退”；场景模板默认展示 4 首，热门歌曲默认展示 10 首。
3. 打开某标签的配置弹窗，确认候选歌曲仅包含已挂当前标签的歌曲。
4. 执行加入、移除、上移和下移，保存后重新打开，确认顺序保持一致且不受歌曲自身排序影响。
5. 将展示数量分别设置为 1、100，确认可保存；设置为 0 或 101，确认前后端均拒绝。
6. 移除全部歌曲并保存，确认允许保存，公开歌曲接口返回 200 和空数组。

### 歌曲筛选与默认标签

1. 确认歌曲配置表上方显示“全部 + 各模块标签”。
2. 切换标签后，确认表格只展示已挂该标签的歌曲。
3. 在标签筛选状态下新增歌曲，确认编辑弹窗默认预选当前标签。
4. 切换 App 后，确认标签筛选与首页列表数据不会沿用上一个 App 的状态。

### 公开接口与兼容

1. 不带 `X-App-Code` 调用公开首页列表接口，确认请求被拒绝。
2. 调用 `GET /api/song-config/home-lists`，确认只返回启用标签及其名称、排序和展示数量。
3. 调用 `GET /api/song-config/home-lists/{tagCode}/songs`，确认按显式编排顺序过滤后截取展示数量。
4. 将编排靠前歌曲禁用或将来源作品设为不可播放/不可公开，确认跳过该歌曲并由后续可用歌曲补足。
5. 使用未知或禁用标签查询，确认返回 404；有效标签无可用歌曲时返回 200 和空数组。
6. 调用旧 `GET /api/song-config/home-modules`，确认字段和 `displayMode` 保持不变，`items` 与新列表歌曲一致。

## P1 用例

### 保存校验与关联保护

1. 保存重复歌曲编码，确认返回参数错误。
2. 把未挂当前标签的歌曲加入列表，确认返回参数错误。
3. 显式列表选中歌曲后，尝试删除歌曲，确认提示先从首页列表移除。
4. 显式列表选中歌曲后，编辑歌曲并移除对应标签，确认提示先从首页列表移除。
5. 清空显式列表后，确认歌曲可删除；禁用歌曲本身始终允许。
6. 编辑已保存标签并修改 tagCode，确认后端拒绝。

### 兼容回退

1. 删除测试环境中的显式列表记录，保留标签与歌曲关系。
2. 确认后台列表按歌曲原 `sortOrder/itemCode` 生成回退顺序，且 `persisted=false`。
3. 首次保存后修改歌曲自身排序，确认公开列表仍使用显式 `itemCodes` 顺序。
