## 当前产品口径

- 首页三业务独立：AI 写歌 `/api/song-generations`、歌曲改编 `/api/song-covers`、翻唱声音克隆 `/api/song-voice-covers`。历史“AI 翻唱”是改编旧名，不得混入新声音克隆任务或作品。
- P03 专业写歌和 P04 歌曲改编的「使用指定音色」延至下版。本期入口不可见、不进入 P07，也不随请求提交；即使模型能力支持也不开放。当前 Flutter 产品开关为 `false`，保留的内部路由不算用户可达。P05 翻唱声音克隆选择本人/官方音色仍必须测。
- P04/P05 生成页不显示歌曲权利勾选，也不因此阻断提交；兼容字段固定 `true` 不是用户显式勾选的证据。P08/P09 本人声音训练授权仍须验。
- 模型支持的设置保持可用；**已上线**但当前模型不支持的设置保留置灰并解释。价格、时长、容量与参数范围取服务端当前模型契约，不拿 Figma 示例数字作断言。切模型清除无效值、报价刷新；默认/程序化校正静默，用户主动换模才解释当前可见模式被清除的字段。
- 本地图片、音频和视频提取后的最终字节须先查重再上传；查重命中须是当前 App/用户/兼容用途的有效资源，不能跨用户复用或绕过审核。站内作品引用按权限复用已有资源 ID。
- 正向写歌、改编、翻唱声音克隆和音色训练的“提交成功”都不等于业务成功。歌曲生成必须等对应作品的持久化音频真实开始播放、进度连续增长至少 5 秒；失败、超时、缺作品或不可播放均 `FAIL`。
