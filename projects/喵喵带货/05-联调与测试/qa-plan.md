## 1. 测试目标与边界

本计划用于验证喵喵带货移动端从启动、登录、首页创作、脚本与视频生成、作品恢复，到会员、积分、支付、邀请、设置等功能可以稳定使用，并重点防止以下发布阻断问题：

- App 崩溃、ANR、白屏或无法返回。
- 重复创建作品、重复提交生成任务、重复扣积分或重复扣款。
- 草稿、脚本、生成进度或登录态在切后台、弱网、杀进程后丢失。
- 作品状态与页面入口不一致，失败页无法返回或恢复。
- 隐私同意前初始化受保护 SDK，或撤回同意后仍发送设备审计信息。
- AI 图片、形象或视频在预览、下载、分享链路中缺少 AI 标识。

本轮只编写待执行测试计划与手工用例，不执行测试、不预填通过率、不修改 Flutter、Java、Web/Admin、数据库或接口。

CHG-0055 已完成 Java 与 Web/Admin 自动化验证，但尚未进入本计划的真机/真实 Provider 联调结论；Flutter 用户端未因该变更修改。以下新增验收项同样保持 `未执行`，不得把仓库自动化通过等同于正式 QA 通过。

## 6. 执行顺序

1. 确认候选包版本、后端部署、账号、作品夹具、支付环境和 Provider 额度。
2. Android 主设备执行启动、隐私、手机号/一键登录和三个 Tab 冒烟，同时确认登录页无游客入口；任一 P0 失败立即停止后续测试。
3. 执行三种创作入口、脚本、报价、视频、作品详情、下载分享完整主链路。
4. 执行积分不足、支付结果、失败页、重试、弱网、后台和杀进程恢复。
5. 执行“我的”全部公共页面、邀请、设置、协议和反馈。
6. 在 API 24/API 36 执行 P0 与兼容专项，在 iOS 13+/主 iPhone 执行差异专项。
7. 汇总证据、缺陷和阻塞项；P0/P1 修复后重新执行原用例及受影响回归集。
8. 所有退出条件满足后填写终态测试报告，并等待用户确认；不得自动推进到构建打包。

## 8. 性能与可用性基线

本轮不擅自新增产品 SLA；通过固定方法建立候选版本基线，供当前版本判定和后续版本对比：

- Android 12 主设备在稳定 Wi-Fi 下，冷启动、热启动、首页首屏、作品列表首屏各执行 5 次，记录中位数和最慢值。
- 通过联调日志记录普通读取接口、提交接口的 P50/P95；上传、脚本、图片和视频 Provider 耗时单独统计，不混入普通接口。
- 用户提交上传或生成后，页面必须立即出现明确 loading/progress/disabled 反馈，禁止看似可重复点击。
- 与同设备最近一次已接受基线相比，关键页面明显变慢、持续卡顿、掉帧、内存异常增长或视频退出后仍播放均登记缺陷。
- 任何导致主流程不可操作、ANR、崩溃或重复业务写入的性能问题按 P0/P1 处理，不以“仅性能”降级。

## 9. 安全与隐私检查

- Android 未登录/注册用户与 iOS 未登录/游客/注册用户只能访问各自允许的路由；Android 不得显示或创建游客账号，前端隐藏不能代替服务端鉴权。
- 账号 A 无法读取、编辑、下载、删除或重生成账号 B 的作品。
- Token 过期、刷新失败和服务端注销后，不继续展示私有数据。
- 抓包确认隐私同意前不发送匿名安装标识、系统版本和设备型号；撤回后后续请求立即移除。
- 页面、Toast、日志和分享内容不暴露 Token、验证码、完整手机号、内部异常栈、对象存储永久地址或其他账号数据。
- 重复点击、回调重放和网络重试不产生重复作品、任务、扣分、订单或退款。
- 分享与相册导出的临时文件仅包含目标内容，不夹带其他用户缓存。

- 候选包、后端部署版本、接口域名和 App Code 已登记。
- `CHG-0020`、`CHG-0019` 已关闭或由负责人明确 defer，并说明对测试结论的影响。
- 测试账号、状态作品、Provider 额度、支付宝测试环境和 StoreKit Sandbox 可用。
- 隐私、相机、相册、支付、视频和分享能力可在目标真机执行。

### 11.2 发布退出

- Android 主设备全部 Android/双端适用的 P0～P2 已执行，并确认无游客入口；API 24/API 36 的 Android/双端 P0 与兼容专项已执行。
- iOS P0 冒烟和平台差异专项已执行。
- P0/P1 缺陷为 0；P2 均有负责人、处理版本和书面接受结论。
- 无崩溃/ANR、重复作品/任务、重复扣分/扣款、草稿丢失、状态误跳、隐私提前初始化或 AI 水印绕过。
- 联调矩阵全部为“已打通”，被环境阻塞的关键链路不得按通过处理。
- 测试报告、设备信息、截图/录屏、日志和缺陷回归记录完整。
