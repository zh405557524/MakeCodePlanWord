# 喵喵带货移动端全量手工回归用例

> 适用版本：`v1.0.1+102`
>
> 状态：`waiting_review / not_run`
>
> 执行策略：Android 主设备执行全部 Android/双端适用的 P0～P2，但不执行 iOS 游客专属用例；Android API 24/API 36 执行适用的 P0 与兼容专项；iOS 执行 P0 冒烟、游客账号和平台差异专项。
>
> 环境、账号、作品夹具、结果枚举和退出标准见 [`../qa-plan.md`](../qa-plan.md)。

## 执行说明

- 表内每一行是一条独立测试用例；模块字段、优先级、前置条件、测试数据、步骤、预期结果和备注均为用例组成部分。
- 步骤与预期使用相同序号对应。执行结果只能记录为 `passed / failed / blocked / not_run`。
- Android 不提供游客账号：登录页不得显示游客入口，不执行 A1、游客恢复或游客绑定用例；Android 登录使用 A2/A3/A4/A5，覆盖手机号和环境可用时的一键登录。
- A1 及模块标记为“iOS 游客”的用例仅在 iOS 执行；iOS 覆盖游客、手机号和环境可用时的一键登录。
- 涉及真实短信、支付宝、StoreKit、AI Provider、相册、相机、分享和视频播放的用例必须在受控测试环境或真机执行。
- `CHG-0020` 未闭合前，涉及精确积分公式、失败退款金额和重新生成扣分金额的用例标记为 `blocked`，不得自行猜测期望值。
