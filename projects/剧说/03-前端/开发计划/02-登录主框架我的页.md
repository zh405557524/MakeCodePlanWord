## 1. 功能定位与边界

本模块负责 App 的基础用户路径：未登录用户进入登录页，登录成功后进入主框架；主框架承载创作、作品、我的三大 tab；我的页展示账号、积分、VIP、邀请码和二级入口。

本模块包含：

- 一键登录页前端流程。
- 手机号验证码登录页前端流程。
- 协议勾选与协议入口。
- 底部三 tab 主框架。
- 创作首页的主入口、热门案例、积分和会员入口。
- 我的页账号区、邀请码复制、积分、VIP、功能入口。
- 我的页跳转邀请好友、积分详情、积分充值、客服、意见反馈、更多设置。

本模块不包含：

- 真实运营商一键登录 SDK 接入。
- 真实短信验证码发送与校验。
- 真实用户中心接口。
- 作品列表完整实现。
- 邀请好友、更多设置、意见反馈页面内容实现；这些放在 `05-商业化与我的二级页.md`。

## 6. 业务内容与数据流

### 6.1 登录数据流

```text

AuthView
  -> AuthController.submit()
  -> AuthApi mock login
  -> UserStore.setSession()
  -> UserStore.fetchProfile(mock)
  -> Router 返回目标页或 main

```

规则：

- 未勾选协议时阻止提交，并提示“请先阅读并同意用户协议和隐私政策”。
- 手机号格式不合法时阻止发送验证码。
- 获取验证码进入 60 秒倒计时，倒计时期间按钮 disabled。
- 登录成功后写入 token、手机号、邀请码、积分、VIP 状态。
- 登录失败保留用户已输入手机号。

### 6.2 主框架数据流

```text

MainView
  -> MainController.currentIndex
  -> HomeTab / WorksTab / AccountTab
  -> 子模块 Controller

```

规则：

- tab 切换不重建全局 Store。
- 首页点击创建项目：未登录先进入登录，已登录进入 `creationVideo`。
- 首页点击会员入口进入 `membership`。
- 首页点击积分入口进入积分相关页面，具体目标按 PRD 和后续业务确认。

### 6.3 我的页数据流

```text

AccountView
  -> AccountController.loadProfile()
  -> UserStore.profile
  -> AccountView 渲染积分 / VIP / 邀请码
  -> 点击入口 pushNamed(...)

```

规则：

- 邀请码复制使用系统剪贴板，成功 / 失败都有 toast。
- 未登录访问我的页敏感入口时进入登录。
- 我的页所有入口先接路由，不允许空点击。

- 登录页可展示一键登录态和验证码登录态。
- 未勾选协议点击登录有明确提示。
- 验证码按钮有格式校验、倒计时、disabled 状态。
- mock 登录成功后进入主框架，并能在我的页看到账号、积分、VIP、邀请码。
- 主框架创作 / 作品 / 我的三个 tab 可切换。
- 创作首页点击创建项目能进入创作页路由或触发登录。
- 我的页邀请码可复制，成功 / 失败都有提示。
- 我的页邀请好友、积分详情、积分充值、意见反馈、更多设置等入口都有路由承接。
- 页面至少覆盖 loading、submitting、error、success 状态。
- `flutter analyze` 无新增错误。

## 11. 编码注意事项

- 登录页不要直接写真实运营商 SDK，必须走 Service / Api 抽象。
- 协议和隐私政策入口走 `webview` 路由，URL 和标题先用配置占位。
- tab 状态归 `MainController` 管，用户信息归 `UserStore` 管，不要互相混写。
- 页面不要写死真实 API path。
- 我的页“更多设置”与创作页“更多设置弹层”命名要区分，避免路由和类名混淆。
- 作品 tab 在本模块只作为主框架占位或接入作品模块，不在此处实现完整作品逻辑。
- 用户可见文案先集中到常量或 l10n 预留位置，避免后续国际化清理困难。
