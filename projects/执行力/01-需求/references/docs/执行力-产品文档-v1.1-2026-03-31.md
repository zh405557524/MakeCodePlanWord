## 三、数据结构

### 3.1 Task（Now 页任务）

```typescript
export type TaskCategory = 'work' | 'study' | 'life' | 'health';
export type TaskPriority = 'low' | 'medium' | 'high';
export type TaskStatus = 'pending' | 'in-progress' | 'completed';

export interface Task {
  id: string;
  title: string;
  description?: string;
  category: TaskCategory;
  priority: TaskPriority;
  status: TaskStatus;
  estimatedMinutes?: number;
  date: string;           // "YYYY-MM-DD"
  createdAt: string;      // ISO 8601
  completedAt?: string;   // ISO 8601
}
```

### 3.2 AppState（应用状态）

```typescript
export type EnergyLevel = 'low' | 'medium' | 'high';
export type AppMode = 'light' | 'normal' | 'intensive';

export interface AppState {
  energy: EnergyLevel;
  mode: AppMode;
  aiModel: string;  // 'gpt-4o' | 'gpt-3.5-turbo' | 'claude-3'
}
```

### 3.3 CustomTask / CustomPhase / CustomPlan（自定义计划）

```typescript
export type TaskType = 'sequential' | 'recurring';

export interface CustomTask {
  id: string;
  title: string;
  taskType: TaskType;
  done: boolean;
  // sequential 模式
  startDate?: string;       // "YYYY-MM-DD"
  startTime?: string;       // "HH:MM"
  endTime?: string;         // "HH:MM" — 若设置则覆盖 duration
  duration?: number;        // 分钟
  // recurring 模式
  recurringDays?: number[]; // 0=Sun...6=Sat
  recurringTime?: string;   // "HH:MM"
}

export interface CustomPhase {
  id: string;
  name: string;
  description: string;
  period: string;
  status: 'upcoming' | 'active' | 'completed';
  tasks: CustomTask[];
}

export interface CustomPlan {
  id: string;
  name: string;
  type: string;
  icon: string;
  color: string;
  gradFrom: string;
  gradTo: string;
  startDate: string;
  endDate?: string;
  isLongTerm: boolean;
  dailyMinutes: number;
  phases: CustomPhase[];
  tasks: CustomTask[];   // 计划级别任务（不属于任何阶段）
  createdAt: string;
  updatedAt: string;
}
```

## 五、页面详情

### 5.1 Now 页（/）
- 展示今日任务列表，按优先级排序
- 任务卡片支持状态切换（pending → in-progress → completed）
- 顶部显示当前时间、日期和能量状态

### 5.2 Chat 页（/chat）
- 全屏 AI 对话界面，隐藏底部导航
- 支持文本消息发送
- 接入 AI 模型（当前为模拟回复）

### 5.3 Plan 页（/plan）
- 自定义计划列表（来自 custom_plans）
- 入口卡片：年度作战地图
- 快捷创建新计划按钮

### 5.4 年度作战地图（/plan/battle）
- 5 条预设主线：换工作 / 作品集 / 买房 / 恋爱 / 状态管理
- 每条显示：进度条、当前阶段、7日执行节奏、AI 建议
- 状态徽章：active / blocked / idle

### 5.5 主线详情（/plan/battle/:trackId）
- 完整阶段时间线（completed / active / upcoming）
- 当前阶段任务列表
- 顺序任务显示时间段，定期任务显示周期

### 5.6 计划编辑器（/plan/editor、/plan/editor/:planId）
- 创建/编辑自定义计划
- 添加阶段和任务
- 任务双模式：sequential（指定日期时间段）/ recurring（按周期重复）
- sequential 模式：startDate + startTime + duration 联动计算 endTime

### 5.7 Profile 页（/profile）
- 顶部 Hero 卡片（可点击跳转个人信息）← v1.1 NEW
- 展示用户头像/昵称/座右铭/标签
- 能量水平选择（低/中/充沛）
- 执行模式选择（轻量/正常/专注）
- AI 模型选择
- 清空所有数据

### 5.8 个人信息页（/profile/me）← v1.1 NEW
- 头像选择：20 个 Emoji + 8 种背景色
- 编辑昵称、座右铭、城市
- 标签系统：10 个预设标签 + 自定义标签
- 执行数据展示（总任务/已完成/完成率 + 进度条）
- 数据存入 localStorage key: user_profile

### 5.9 开屏页面（SplashScreen）← v1.1 NEW
- 每次应用启动展示约 2 秒
- 深紫色渐变背景（#0f0d2e → #3730a3）
- ⚡ Logo 弹性弹入动画（spring ease）
- 4 层同心圆光晕装饰
- 旋转渐变光环（12s 循环）
- 应用名"执行力" + 副标题渐显
- 跳动加载点（三个点，stagger 延迟）
- 退出：scale(1.06) + opacity(0) 淡出

## 七、动画规范

|------|------|
| 页面入场 | opacity 0→1, y 16→0, duration 0.3s |
