# 剧说 CHG-0012 积分任务中心技术文档

> 版本：v0.8.0
> 提出日期：2026-06-08
> 当前状态：in_progress

## 1. 总体方案

新增任务中心能力，沿用现有 Java Spring Boot 后端、Flutter App、Flutter Web 后台管理和积分账本体系。签到作为新的积分来源写入积分流水；邀请任务只读取现有邀请数据和规则，不新增二次奖励。

## 2. 后端接口

- `GET /api/tasks/center`：返回积分余额、签到状态、7 日签到配置、邀请任务进度和按钮状态。
- `POST /api/tasks/check-in`：执行当日签到，幂等返回签到结果、发放积分、最新积分和连续天数。
- `GET /api/admin/task-center/rules`：后台查询任务中心规则。
- `PUT /api/admin/task-center/rules`：后台更新任务中心规则。

## 3. 数据与账本

- 新增签到记录表，按 `user_id + app_code + checkin_date` 唯一。
- 签到奖励通过现有 `PointsService` 发放，新增积分业务类型 `TASK_CHECKIN`。
- 业务 ID 使用签到日期或记录 ID 保证幂等。
- 默认规则写入应用配置，缺失时服务端兜底。

## 4. App 方案

- 新增 `taskCenter` 路由与 `/task-center` 页面。
- 新增任务中心 API、model、controller、view。
- 我的页在支付订单上方新增入口，并沿用登录拦截。
- UI 使用当前暗色主题和 `CustomTheme.primary`。

## 5. 后台方案

- 新增任务中心配置页或配置入口。
- 支持开关、7 天奖励数组、邀请任务标题、说明、目标人数、奖励展示文案。
- 后台提交后写入任务中心规则配置。

## 6. 异常策略

- 未登录访问走现有鉴权。
- 已签到重复提交返回已签到状态，不重复发奖。
- 配置异常或缺失时使用默认规则。
- 邀请任务进度读取失败不影响签到，接口返回可展示的默认邀请任务。
