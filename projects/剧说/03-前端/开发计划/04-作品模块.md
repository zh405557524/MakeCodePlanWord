## 1. 功能定位与边界

本模块负责“我的作品”前端闭环：展示作品空态、作品列表、分类筛选、作品详情、播放预览和下载入口，同时为生成中、生成失败、草稿、已完成等状态预留前端展示能力。

本模块包含：

- 作品 tab 的空态。
- 作品 tab 的列表态。
- 分类筛选：全部、短剧、漫剧、电影、电视剧。
- 作品卡片：封面、状态、标题、日期、更多操作入口。
- 作品详情页：播放预览、作品名称、参数标签、下载视频。
- 草稿、生成中、生成失败、已完成、过期等状态模型。
- 下载、播放失败等前端异常提示。

本模块不包含：

- 真实视频播放 SDK 深度集成。
- 真实下载到相册权限细节。
- 真实生成任务轮询。
- 作品删除和更多菜单的完整业务；当前可预留入口。
- 作品过期后的最终策略；PRD 中仍待确认。

## 6. 业务内容与数据流

### 6.1 作品列表数据流

```text

WorksTab
  -> WorksController.onInit()
  -> WorksApi.fetchWorks(mock)
  -> loading / empty / error / success
  -> 切换分类
  -> 刷新列表
  -> 点击卡片进入详情

```

规则：

- 首次进入展示 loading。
- 无作品展示空态和立即创造。
- 切换分类后更新列表，列表为空时仍展示该分类下空态。
- 列表失败展示错误态和重试按钮。
- 下拉刷新可重新拉取 mock 数据。

### 6.2 作品详情数据流

```text

WorkCard
  -> pushNamed(workDetail, id)
  -> WorkDetailController.load(id)
  -> WorkDetailView
  -> 点击播放 / 下载
  -> mock 播放 / mock 下载

```

规则：

- 详情页必须处理 id 不存在或数据加载失败。
- 生成中作品进入详情时展示处理状态，不展示可下载按钮。
- 生成失败展示失败原因和重试 / 返回入口，是否支持重试待确认。
- 已完成作品展示下载按钮。
- 过期作品展示过期提示，下载按钮 disabled。

### 6.3 状态映射

| 状态 | 列表展示 | 详情展示 |
|------|----------|----------|
| `draft` | 草稿标签 | 可继续编辑，跳创作页待确认 |
| `queued` | 排队中 | 处理中提示 |
| `processing` | 生成中 | 进度占位或处理中提示 |
| `failed` | 失败标签 | 失败原因、可重试入口待确认 |
| `completed` | 已完成 | 可播放、可下载 |
| `expired` | 已过期 | 禁止下载，提示保留规则 |

## 10. 验收标准

- 主框架作品 tab 可进入作品页。
- 无作品时展示空态和立即创造入口。
- 有作品时展示分类筛选和作品卡片。
- 切换分类可刷新对应列表。
- 点击作品卡片进入详情页。
- 详情页展示视频预览、作品名、参数标签和下载按钮。
- 草稿、生成中、失败、完成、过期状态至少有前端展示。
- 下载失败、播放失败有 toast 或错误态。
- 列表加载失败和详情加载失败可重试。
- `flutter analyze` 无新增错误。

## 11. 编码注意事项

- 作品保留 7 天是当前 PRD 规则，但过期策略待确认，代码中用枚举和提示承接，不写死删除逻辑。
- 下载到相册涉及权限，真实能力待确认前只做 Service 抽象和 mock。
- 视频播放可先用占位组件，不提前锁定播放 SDK。
- 作品状态要与后续生成任务状态机兼容，避免只写 completed / failed 两态。
- 作品卡片更多菜单内容待确认，先保留入口或最小菜单，不扩展未确认业务。
