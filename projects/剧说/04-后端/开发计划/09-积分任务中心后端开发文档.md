# 剧说 Java 模块开发文档：09-积分任务中心

> 版本：v0.8.0
> 创建日期：2026-06-08
> 当前状态：done

## 1. 功能范围

- 用户侧任务中心概览接口。
- 用户侧签到接口。
- 后台任务中心规则查询和更新接口。
- 签到记录表和积分账本接入。
- 后端集成测试。

## 2. 后端路径

- `app/narrate/task/**`：用户侧任务中心 controller/service/entity/dto/vo/repository。
- `admin/controller/AdminTaskCenterController.java`：后台规则接口。
- `db/migration/V12__task_center.sql`：签到记录表和默认配置。

## 3. 接口契约

- `GET /api/tasks/center`
  - 返回当前积分、签到状态、签到天数、7 日奖励、邀请任务进度。
- `POST /api/tasks/check-in`
  - 当日首次签到发放积分；重复签到幂等返回已签到。
- `GET /api/admin/task-center/rules`
  - 返回当前任务中心配置。
- `PUT /api/admin/task-center/rules`
  - 更新任务中心开关、签到奖励数组和邀请任务展示规则。

## 4. 账本规则

- 新增 `PointBizType.TASK_CHECKIN`。
- 签到发奖调用 `PointsService`，业务 ID 固定为 `checkin:{yyyy-MM-dd}:{userId}`。
- 同一日期唯一签到记录防重复发奖。
