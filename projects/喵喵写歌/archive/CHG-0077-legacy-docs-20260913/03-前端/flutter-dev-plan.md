## 2. 总体策略

本轮前端顺序调整为“先对齐 UI 页面，再补功能链路”：

1. 先统一主题、基础组件、底部导航、固定按钮和迷你播放器避让
2. 再按设计稿重写首页、写歌、作品、我的四个主 Tab
3. 然后补案例详情、场景问答、生成详情、作品详情、专辑详情
4. 最后补 AI帮写、图片写歌、参考音频、下载分享、会员积分联调

核心原则：

- 新设计稿优先级高于旧截图和当前页面实现
- 以 375x812 为实现基准
- 所有主页面必须有 loading、empty、error、submitting、disabled

## 5. 接口与功能缺口

前端编码前需要确认或补齐后端接口：

- 热门案例列表/详情/使用模板
- 最近作品
- AI帮写歌词
- 图片写歌上传和创建
- 参考音频真实效果联调验收（App 端录音/相册导入/上传/提交已完成）
- 生成任务阶段进度、百分比、剩余时间
- 作品详情、分享、重新生成、加入专辑
- 专辑详情、添加歌曲、封面上传
- 会员信息、积分信息、积分充值、积分明细

若后端暂未完成，前端可先按接口模型写好 API 和 UI 状态，但不得做只在本地生效的假业务闭环。
