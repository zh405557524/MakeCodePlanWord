## 1. 返工背景

用户反馈“前端 UI 没有按照设计稿来”。经对照当前文档、设计稿和 Flutter 工程，当前问题不是产品方向或后端架构错误，而是 Flutter 主页面仍偏向旧骨架/临时样式：

- 首页仍是“情景写歌 + 歌曲示例”简版，没有设计稿中的品牌区、大输入卡、2x2 快捷功能和热门案例结构。
- 写歌页已具备灵感速递，但整体仍缺少设计稿中的标题、表单层次、固定底部按钮和高级创作完整结构。
- 作品页仍使用默认 `SegmentedButton` 和 `ListTile`，没有设计稿中的生成中卡、完成歌曲卡和专辑卡样式。
- 我的页仍沿用旧积分/邀请布局，没有设计稿中的用户资产卡、快捷入口、PRO 升级卡和菜单分组。

本轮返工目标是让后续编码不再凭旧骨架推进，而是按新设计稿逐页对稿。

## 3. 返工范围

本轮必须返工：

- 全局视觉基线：深紫黑背景、绿色到青色主按钮、橙色 PRO、紫灰辅助文字、弱描边卡片。
- 底部导航：按设计稿四 Tab，贴底半透明深色栏，激活态绿色图标和文字。
- 首页：品牌区、大输入卡、2x2 快捷入口、热门案例、最近作品。
- 写歌：AI 写歌标题、灵感/高级分段、音乐描述/歌词输入、固定开始创作按钮、迷你播放器避让。

本轮不返工：

- 已完成的 Java 后端 T-B001 至 T-B014 主链路。
- Web/Admin 后台页面整体视觉。
- Figma 设计稿制作流程。

## 4. 页面返工清单

### 4.1 首页

设计稿：

- `首页/首页1.png`
- `首页/首页2.png`

现状偏差：

- 当前首页标题只有“喵喵写歌”，缺少猫头像、品牌副标题和 PRO 会员按钮。
- 当前首页没有设计稿中的大输入卡，开始创作不在卡片内部。
- 当前快捷入口不是 2x2 卡片结构。
- 热门案例和最近作品没有按设计稿展示。

实现要求：

- 顶部品牌区：猫头像符号、`喵喵写歌`、副标题`一句话生成你的专属歌曲`、橙色 `PRO会员`。
- 大输入卡：prompt 输入、推荐标签、`0/200` 字数、绿色到青色渐变 `开始创作`。
- 快捷功能 2x2：场景写歌、图片写歌、纯音乐、AI作词；每个卡片有彩色图标块、标题、说明。
- 热门案例：横向滚动卡片，优先消费后端 `song-cases`；短期若 Flutter 尚未封装，先用 `examples` 安全降级但不写死假业务。
- 最近作品：优先消费 `/api/song-works/recent`；短期可用作品列表前几条降级。

验收点：

- 375x812 首屏能同时看到品牌区、大输入卡、快捷功能标题和热门案例顶部。
- 底部导航不遮挡热门案例。
- 长 prompt、长案例标题不撑破卡片。

### 4.2 写歌页

设计稿：

- `Ai写歌/AI写歌-灵感创作1.png`
- `Ai写歌/AI写歌-灵感创作2.png`
- `Ai写歌/AI写歌-高级创作1.png`
- `Ai写歌/AI写歌-高级创作2.png`
- `Ai写歌/AI写歌-高级创作3.png`
- `Ai写歌/AI写歌-高级创作5.png`

现状偏差：

- 缺少顶部 `AI 写歌` 标题。
- 当前灵感创作卡片偏旧参考图，未完整对齐新稿输入框、字段和标签层级。
- 高级创作字段过少，缺少 AI帮写、歌手类型、语言、时长、参考音频、模型区域。
- 固定按钮和迷你播放器避让需要按设计稿重做。

实现要求：

- 标题：`AI 写歌`。
- 分段：`灵感创作 / 高级创作`，激活态绿色描边和深绿填充。
- 灵感创作：音乐描述、灵感速递、字数、音乐名称、曲风描述、曲风标签、纯音乐。
- 高级创作：歌词输入、AI帮写、音乐名称、曲风描述、歌手类型、语言、时长、参考音频、AI模型。
- 固定底部按钮：绿色到青色渐变 `开始创作`，按钮避让迷你播放器和底部 Tab。

验收点：

- 灵感创作和高级创作首屏结构分别与设计稿一致。
- 字数计数实时变化。
- 灵感速递请求期间禁用重复点击，成功后覆盖音乐描述。
- 键盘弹出时输入框和底部按钮不互相遮挡。

### 4.3 作品页

设计稿：

- `作品/作品-作品.png`
- `作品/作品-专辑.png`
- `作品/专辑创建.png`
- `作品/专辑创建2.png`
- `作品/专辑详情.png`

现状偏差：

- 当前作品页使用默认 Material 分段按钮，不符合设计稿。
- 歌曲列表没有区分生成中和已完成。
- 生成中作品缺进度条、百分比、模型和剩余时间。
- 专辑页缺设计稿中的专辑卡和渐变创建按钮。

实现要求：

- 标题：`作品`。
- 分段：`歌曲 / 专辑`，复用写歌页分段样式。
- 歌曲 Tab：生成中分组 + 已完成分组。
- 生成中卡：封面占位、标题、渐变进度条、百分比、模型、剩余时间。
- 已完成卡：封面、标题、风格/模型/时长、创建时间占位、圆形播放按钮。
- 专辑 Tab：专辑卡 + `创建专辑` 渐变按钮；空态也保留创建入口。

验收点：

- 生成中和已完成能同时展示。
- 专辑有数据和无数据状态都能看懂。
- 列表底部不被底部导航遮挡。

### 4.4 我的页

设计稿：

- `我的/我的.png`
- `我的/我的2.png`

现状偏差：

- 当前我的页是旧会员/积分样式，缺少设计稿的用户资产卡结构。
- 快捷入口和 PRO 升级卡样式不一致。
- 菜单列表缺图标块、状态 badge 和分组质感。

实现要求：

- 标题：`我的`。
- 用户资产卡：头像、`音乐创作者`、PRO 状态、续费按钮、积分余额、创作歌曲/今日剩余/已下载统计。
- 快捷入口：邀请好友、积分明细、积分充值、联系客服。
- PRO 卡：`升级到 PRO 会员`、`无限创作 · 商业授权 · WAV下载`。
- 菜单：我的会员、任务中心、支付订单、兑换码、意见反馈、联系客服、系统设置。

验收点：

- 未登录和已登录状态都能展示。
- 375x812 下菜单第一屏与设计稿层级一致。
- 菜单底部不被导航遮挡。
