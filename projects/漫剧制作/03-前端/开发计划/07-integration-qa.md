# 07 - 联调与验收开发计划

> 覆盖任务：F-026 ~ F-029  
> 状态：`pending`  
> 依赖：F-001 ~ F-025

## 目标

完成主流程、异常态、任务恢复、多尺寸适配和 Figma 视觉验收，确保 App 可以从首页完成一次漫剧制作闭环。

## 任务拆分

| ID | 任务 | 输出 | 验收 |
| --- | --- | --- | --- |
| F-026 | 主链路联调 | 首页 -> 作品创建 -> 角色 -> 场景 -> 分镜 -> 预览 | 全链路接口可跑通 |
| F-027 | 异常态与任务恢复 | 失败重试、后台恢复、重复任务处理 | 不丢草稿、不清空旧资产 |
| F-028 | 多尺寸适配 | 375x812、390x844、430x932 | 无溢出、无遮挡 |
| F-029 | Figma 视觉验收 | 逐 Frame 修正 | 颜色、间距、字号、圆角、状态一致 |

## 主链路检查

1. 首页拉取作品列表。
2. 新建作品进入作品创建页。
3. 点击「开始解析」同步返回 `workId`。
4. 角色页生成/重新生成图片，生成中禁止下一步。
5. 场景页生成/重新生成图片，生成中禁止下一步。
6. 分镜页编辑描述、选择角色、选择场景、选择参数。
7. 单分镜生成和一键生成全部可轮询刷新。
8. 视频预览页生成视频并播放。
9. 分享链接可创建并展示。

## 异常检查

- 同步解析失败：保留故事文本。
- 图片任务失败：保留旧图或占位，允许重试。
- 分镜任务失败：保留旧资产和描述。
- 视频任务失败：保留预览数据，允许重试。
- 网络断开：显示缓存并禁止关键提交。
- App 切后台：降低轮询频率；回前台恢复任务查询。

- `AI漫剧 / 06-视频预览`
- `AI漫剧 / 08-角色选择（多选）`
- `AI漫剧 / 09-场景选择（单选）`

## 通过标准

- 文本解析无轮询。
- 图片、分镜资源、视频生成全部轮询。
- 角色/场景没有「已生成」文案依赖。
- 分镜字段为 `description`。
- 多尺寸下按钮、文字、卡片不遮挡、不溢出。
