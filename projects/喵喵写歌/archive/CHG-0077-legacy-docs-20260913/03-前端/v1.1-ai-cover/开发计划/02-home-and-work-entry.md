# 02 AI 翻唱入口模块

- 版本：v1.1-ai-cover
- 对应任务：F-COVER-02、F-COVER-07
- 状态：done
- 影响工程：`/Users/soul/code/lxwx/catsinger`

## 1. 功能定位

本模块把 AI 翻唱入口接进已有 App，不改变 v1.0 写歌主链路。入口分两类：从首页开始翻唱、从已有作品重新翻唱。

## 2. 首页入口

### 2.1 入口位置

- 页面：`首页`
- 区块：快捷功能区
- 新入口：`AI 翻唱`
- 设计来源：`ai翻唱-首页入口.png`

### 2.2 点击行为

- 点击 `AI 翻唱`：
  - 已登录：进入 `/song-cover/upload`。
  - 未登录：跳登录，登录成功后回到 `/song-cover/upload`。
- 若用户当前没有作品，不影响入口展示；上传页仍支持本地音频上传。

### 2.3 UI 要点

- 保持 v1.0 首页卡片网格样式。
- 图标用翻唱/麦克风/旋律相关符号，不使用旧 Sonus 视觉。
- 文案短：`AI 翻唱`，副文案可用 `换个声音唱这首歌`。

## 3. 作品页重新翻唱入口

### 3.1 入口位置

- 页面：`作品`
- 对象：已完成作品卡、作品详情页。
- 入口：`重新翻唱`。

### 3.2 点击行为

- 原创歌曲：直接带 `sourceWorkId` 进入 `/song-cover/upload`。
- 翻唱歌曲：允许再次翻唱，源作品默认为当前翻唱版；详情页可后续扩展选择原版或翻唱版。
- 纯音乐：允许翻唱但默认提醒“纯音乐可能没有歌词，翻唱效果以实际生成结果为准”。
- 生成中/失败作品：入口置灰或隐藏。

## 4. 状态与异常

| 场景 | 行为 |
| --- | --- |
| 用户未登录 | 跳登录 |
| 作品缺音频 URL | Toast：当前作品暂无可翻唱音频 |
| 作品生成中 | 不展示重新翻唱 |
| 接口返回无权限 | Toast + 保持当前页 |

## 5. 实现步骤

1. 在首页快捷入口数组中增加 `cover` 项。
2. 在首页 Controller 增加 `goCoverUpload()`。
3. 在作品卡和详情操作栏增加 `重新翻唱` 按钮。
4. 路由跳转统一走 `SongCoverStore.startFromWork(workId)`。
5. 更新埋点名，便于后续统计入口转化。

## 6. 验收标准

- 首页点击 AI 翻唱能进入上传页。
- 作品详情点击重新翻唱能带入作品信息。
- 未登录时不丢失跳转意图。
