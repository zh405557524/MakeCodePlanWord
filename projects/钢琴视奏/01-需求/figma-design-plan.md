# 钢琴视奏 v1.2 Figma 设计稿计划

## 1. 文档目的与适用范围

本文用于指导钢琴视奏 v1.2 的 Figma 设计稿更新与后续代码实现。范围限定在已有 app 的 UI 颜色、背景装饰、图标资源和页面层级微调，不覆盖核心练习业务逻辑。

## 2. 设计目标与视觉方向

- 将旧版深紫蓝视觉更新为浅色、通透、柔和的学习工具风格。
- 使用冷雾蓝、冰紫、青绿形成音乐练习产品的清爽感。
- 通过毛玻璃卡片、柔和阴影、钢琴键和五线谱装饰提升辨识度。
- 让首页、进度、设置、练习页在同一套 Token 下保持一致。

## 6. 组件与设计 Token 清单

### 颜色 Token

| Token | 色值 / 表现 | 用途 |
|-------|-------------|------|
| `color.background.coldMist` | `#F3F6FF` | 页面基础背景 |
| `color.background.blueMist` | `#EEF4FF` | 顶部和大面积浅蓝背景 |
| `color.background.purpleMist` | `#F8F3FF` | 冰紫渐变辅助 |
| `color.brand.primary` | `#5B7CFA` | 主按钮、导航选中、关键数字 |
| `color.brand.purple` | `#8B6CF6` | 练习次数、音乐图标、渐变 |
| `color.brand.aqua` | `#42C7C7` | 准确率、目标、统计 |
| `color.text.primary` | `#172033` | 标题和主数字 |
| `color.text.secondary` | `#64748B` | 副文案和说明 |
| `color.card.glass` | `rgba(255,255,255,0.72)` | 主卡片和列表项 |
| `color.border.soft` | `rgba(91,124,250,0.12)` | 卡片浅描边 |

### 组件清单

- `AppBackground`：冷雾渐变背景，支持钢琴键角落装饰与五线谱波纹。
- `GlassCard`：半透明白卡、20-28 圆角、柔和阴影、浅蓝描边。
- `StatCard`：首页三张数据卡，含图标圆底、主数字、副文案和短进度条。
- `PrimaryPracticeButton`：蓝紫青渐变主 CTA，含播放图标与箭头按钮。
- `ModeListItem`：练习模式列表项，含图标容器、标题、副标题、右箭头。
- `BottomTabBar`：首页/进度/设置三栏，选中态主蓝，未选中灰蓝。
- `ProgressBarChart`：每日得分柱状图，蓝紫渐变柱体。
- `SettingsListItem`：设置列表项，图标容器按功能区分颜色。
- `PracticePianoKey`：练习页大键盘白键/黑键/选中态。
- `PracticeSideAction`：暂停、设置、统计三个竖向操作按钮。

## 7. 交互 / 原型清单

- 首页 `开始练习` → 练习页面布局。
- 首页底部导航 `进度` → 进度页面布局。
- 首页底部导航 `设置` → 设置页面布局。
- 进度页 `查看全部` → 后续统计详情页或保持待补齐链接。
- 设置页各列表项 → 对应设置子页面；当前 Figma 已有音符设置、练习设置、账户信息、音效设置、练习提醒、帮助中心、关于应用、MIDI 设备连接等节点。
- 练习页 `返回` → 首页；`设置` → 练习设置；`统计` → 进度页或练习统计弹层。

## 8. 设计验收标准

- 页面背景、卡片、主按钮、图表、导航态使用统一 Token，视觉不再出现旧版大面积深紫底。
- 参考图中的主要视觉信号均能在 Figma 中定位：钢琴键装饰、五线谱波纹、玻璃 Logo、统计卡、目标卡、横屏键盘。
- 竖屏主界面以 375 x 812 为基准，内容不被底部 Home indicator 或导航遮挡。
- 横屏练习页以 812 x 375 为基准，左右面板、中间五线谱和键盘不重叠。
- 中文标题、数字与副文案均有足够对比度，长文本不溢出卡片。
- 图标资源优先来自 `piano_sight_reading_assets`，缺失时记录替代方案。
- `图标` 资源区必须保留 `v1.2 SVG 文件名映射`，确保设计稿中的每个图标使用都能追溯到具体 SVG 文件名。
- 5 个主页面本体必须直接包含可见图标层，图层命名对应 `icon_*.svg` 或 `icon_app_piano_glass.svg`，不能只停留在资源区映射或页面注释。
