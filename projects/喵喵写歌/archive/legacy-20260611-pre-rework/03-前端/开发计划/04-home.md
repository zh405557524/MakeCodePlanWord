## 1. 功能定位

首页是最快创作入口。实现时必须按新设计稿写 UI，不沿用旧 Explore/Sonus 布局。

## 2. 页面结构

从上到下：

1. 品牌区：猫头像、喵喵写歌、副标题、PRO会员按钮
2. AI 写歌输入卡：prompt 输入、推荐标签、字数、开始创作按钮
3. 快捷功能四宫格：场景写歌、图片写歌、纯音乐、AI作词
4. 热门案例：横向卡片、更多入口
5. 最近作品：封面、标题、创建时间、播放按钮
6. 底部 Tab

## 3. 交互

- 开始创作：带 prompt 切到写歌 Tab
- 场景写歌：进入 `song_scenario`
- 图片写歌：进入图片选择并带入写歌流程
- 纯音乐：切到写歌 Tab，并开启纯音乐
- AI作词：进入 AI 帮写流程
- 热门案例：进入案例详情
- 使用模板：回填写歌 prompt、标题、曲风
- 最近作品：进入作品详情或播放器

## 4. API
