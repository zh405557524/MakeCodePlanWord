# 钢琴视奏练习产品文档 v2.0

## 1. 文档说明

### 1.1 文档目的

本文档是在基础产品文档之上形成的 v2.0 产品规划文档，用于后续二次迭代开发。文档保留当前版本已经形成的产品结构、页面、核心练习流程与业务规则，并新增账户体系、后台服务、和弦练习、歌曲练习、歌曲解锁机制，以及后续 AI 生成/上传曲谱能力的扩展预留。

### 1.2 v2.0 版本定位

v2.0 的核心目标是把产品从“单机视奏练习工具”升级为“有账户、有成长路径、有内容奖励、有后台运营能力的钢琴学习产品”。

当前版本的核心是音符识别；v2.0 的核心是成长体系：

- 用户通过音符识别、挑战升级、和弦练习提升能力。
- 等级提升后解锁对应难度歌曲。
- 歌曲练习作为奖励内容，增强学习成就感。
- 账号体系和后台服务承接用户数据、内容配置、曲库管理、付费扩展和运营能力。

### 1.3 外部产品参考

v2.0 的歌曲练习逻辑参考 Simply Piano 的公开产品思路，但不复制其内容版权或视觉资产。可参考的产品原则包括：

- 课程与歌曲结合，让用户通过练习逐步获得演奏真实歌曲的能力。
- 使用实时反馈降低练习挫败感。
- 歌曲库按能力水平组织，让歌曲成为学习进度的奖励。
- 部分歌曲或内容能力与订阅/付费权益绑定。
- 手机端和钢琴端界面应服务于不同练习场景。

## 2. 产品概述

### 2.1 产品名称

钢琴视奏练习。

### 2.2 产品定位

一款面向钢琴学习者的五线谱识读与视奏训练产品。产品围绕“看谱面音符，快速找到并弹出对应琴键”建立基础能力训练闭环，并通过和弦练习、歌曲练习、等级解锁和内容奖励，帮助用户从单音识别逐步过渡到真实音乐片段和歌曲演奏。

### 2.3 产品目标

- 帮助初学者建立五线谱音符与钢琴键盘的对应关系。
- 通过短时高频练习提升识谱速度、准确率和反应能力。
- 通过等级体系引导用户从单音、和弦逐步进入歌曲练习。
- 通过歌曲解锁机制，让歌曲成为用户能力成长后的奖励。
- 通过账户体系保存用户长期学习进度。
- 通过后台服务支持曲库、等级、成就、付费权益和运营配置。
- 为未来 AI 生成曲谱、上传曲谱、试听和个性化练习预留产品与数据扩展空间。

### 2.4 当前版本范围

当前基础版本已包含：

- 首页。
- 音符识别练习。
- 视奏挑战。
- 练习设置。
- 进度统计。
- 等级体系。
- 成就展示。
- 练习提醒。
- MIDI 连接。
- 麦克风拾音。
- 本地账户资料。
- 帮助中心。
- 多语言。

v2.0 新增范围：

- 账户体系打通。
- 后台服务能力。
- 和弦练习。
- 歌曲练习。
- 歌曲等级解锁。
- 手机版歌曲练习体验。
- 钢琴版歌曲练习体验。
- 曲库管理与运营配置。
- 付费能力预留。
- AI 生成曲谱与上传曲谱能力的扩展性预留。

### 2.5 v2.0 不开发范围

以下能力不在 v2.0 正式开发范围，但需要在产品结构、数据结构和后台能力上预留扩展：

- 用户用 AI 生成指定风格或难度的钢琴曲。
- 用户上传曲谱并自动解析。
- 用户上传音频并生成可练习曲谱。
- 用户购买 AI 生成曲谱、上传曲谱解析、试听和练习服务。
- 对版权曲目的自动生成或曲谱复刻。

## 3. 目标用户

### 3.1 核心用户

- 钢琴初学者：正在学习五线谱，需要快速认识谱面音符和键盘位置。
- 自学用户：缺少老师监督，需要清晰的练习路径和反馈。
- 视奏薄弱用户：能弹琴，但读谱速度慢，希望专项训练。
- MIDI 用户：拥有电子琴或 MIDI 键盘，希望用真实键盘练习。
- 原声钢琴用户：希望通过麦克风拾音完成基础练习。
- 有歌曲目标的用户：希望通过练习最终弹会熟悉或喜欢的歌曲。

### 3.2 用户痛点

- 单音识谱训练枯燥，缺少阶段奖励。
- 不知道练到什么程度可以开始弹歌曲。
- 曲谱难度和自身能力不匹配，容易挫败。
- 缺少系统化路径：音符、和弦、歌曲之间没有衔接。
- 更换设备后学习进度无法同步。
- 想练某首歌，但版权、难度和曲谱来源存在问题。

### 3.3 v2.0 重点解决的问题

- 用账号体系保存长期学习进度。
- 用后台服务承接曲库、等级、内容解锁和付费权益。
- 用和弦练习补齐歌曲演奏前的基础能力。
- 用歌曲练习承接用户的情绪价值和成就感。
- 用“等级解锁歌曲”建立清晰学习目标。
- 为未来 AI 个性化曲谱能力做产品预留，避免版权风险。

## 5. 核心业务流程

### 5.1 首次使用流程

1. 用户打开应用。
2. 展示启动页。
3. 检查登录态。
4. 如果未登录，可允许游客模式进入基础体验。
5. 用户进入首页。
6. 进入核心功能前确认用户协议与隐私政策。
7. 系统建议用户完成新手音符练习。
8. 完成新手练习后，进入 Lv1 学习路径。

产品要求：

- 游客可体验基础练习，但关键进度同步、歌曲解锁和付费权益需要登录。
- 新用户应尽快进入第一轮练习，避免被复杂设置阻塞。
- 首次练习建议题量较少，降低压力。

### 5.2 登录与账户流程

1. 用户点击登录。
2. 选择手机号、邮箱或第三方登录方式。
3. 登录成功后创建或恢复用户学习档案。
4. 同步历史练习记录、等级、成就、解锁歌曲和付费权益。
5. 多设备登录时，拉取最新云端进度。

账户体系需要支持：

- 游客身份。
- 注册用户。
- 会员用户。
- 付费单项权益用户。
- 封禁或注销状态。

### 5.3 普通音符识别练习流程

1. 用户进入练习中心。
2. 选择音符识别。
3. 进入练习页。
4. 点击开始。
5. 系统按用户配置和等级推荐生成题目。
6. 用户根据五线谱点击或弹奏对应音符。
7. 答错停留当前题，答对进入下一题。
8. 完成后展示结果。
9. 练习记录同步到账户。
10. 如果表现满足等级要求，更新升级进度。

### 5.4 和弦练习流程

1. 用户进入练习中心。
2. 选择和弦练习。
3. 系统根据用户等级推荐和弦范围。
4. 页面展示目标和弦。
5. 用户通过屏幕键盘、MIDI 或拾音输入和弦。
6. 系统判断和弦是否正确。
7. 答对进入下一题。
8. 答错展示错误反馈和引导。
9. 完成后展示和弦练习结果。
10. 和弦能力影响歌曲推荐和歌曲解锁。

### 5.5 视奏挑战流程

1. 用户进入练习中心或首页推荐。
2. 选择视奏挑战。
3. 系统读取当前等级并生成下一等级挑战。
4. 用户完成挑战。
5. 系统根据准确率和平均反应时间判断是否通过。
6. 通过后升级。
7. 升级后解锁对应歌曲或歌曲难度。
8. 页面提示新解锁歌曲，引导用户去歌曲练习。

### 5.6 歌曲解锁流程

1. 用户完成音符练习或挑战升级。
2. 系统判断用户当前等级。
3. 如果达到歌曲解锁条件，解锁对应歌曲。
4. 首页歌曲专区展示“新解锁歌曲”。
5. 用户点击歌曲进入详情页。
6. 用户可先试听歌曲。
7. 用户选择手机练习或钢琴练习。
8. 系统进入对应的歌曲练习页面。
9. 完成歌曲练习后获得歌曲完成记录、评分和成就。

产品原则：

- 歌曲是奖励，不是初始压力。
- 用户需要先通过基础训练达到对应等级，再进入对应歌曲。
- 歌曲难度应与等级匹配，避免用户进入过难内容。
- 已解锁歌曲应持续可练。
- 未解锁歌曲可以预览封面、名称、难度和解锁条件。
- 歌曲支持试听。试听可以用于激励用户解锁或帮助已解锁用户决定是否开始练习。
- 歌曲入口固定在首页，不新增独立歌曲 Tab。

### 5.7 歌曲练习流程

1. 用户进入歌曲详情。
2. 查看歌曲名称、等级、难度、预计练习时长、解锁状态。
3. 用户可以试听歌曲。
4. 选择练习方式：
   - 手机版。
   - 钢琴版。
5. 进入对应练习页面。
6. 系统按小节或片段进行练习。
7. 用户完成片段后进入下一片段。
8. 如果错误较多，系统暂停歌曲并进入片段强化。
9. 完成整首歌后展示歌曲结果。
10. 结果包含完成度、准确率、节奏表现、错音、小节表现和奖励。

产品要求：

- 手机版歌曲练习页和钢琴版歌曲练习页是两个不同页面，不只是同一页面的模式切换。
- 两个页面可以共享歌曲、进度和结果数据，但页面布局、交互重点、输入方式和反馈方式需要分别设计。

### 5.8 AI 曲谱扩展流程（预留）

此能力不在 v2.0 开发，但 v2.0 需要为后续预留入口和权益结构。

未来流程：

1. 用户进入“创建曲谱”或“自定义歌曲”。
2. 用户选择：
   - AI 生成钢琴曲。
   - 上传曲谱。
   - 上传音频或旋律素材。
3. 系统提示版权与使用范围。
4. 用户选择目标难度、风格、长度、左右手复杂度。
5. 系统生成或解析曲谱。
6. 用户试听。
7. 用户确认后保存到“我的曲谱”。
8. 用户可进入练习。
9. 该能力按次付费或会员权益计费。

版权原则：

- 不鼓励用户生成或上传受版权保护的商业曲谱用于公开传播。
- 自定义曲谱仅用于用户个人学习。
- AI 生成内容应尽量生成原创旋律或公共领域风格作品。
- 对上传曲谱需要加入版权声明和用户确认。

## 6. 页面说明

### 6.1 首页 v2.0

页面目标：

- 让用户知道今天该练什么。
- 展示当前学习状态。
- 推荐下一步练习和歌曲奖励。

页面模块：

| 模块 | 内容 |
| --- | --- |
| 顶部用户区 | 用户昵称、当前等级、会员状态 |
| 今日目标 | 今日练习次数、歌曲练习目标、连续天数 |
| 下一步建议 | 推荐音符练习、和弦练习或挑战 |
| 歌曲专区 | 新解锁歌曲、推荐歌曲、继续练习、可试听歌曲 |
| 练习入口 | 音符识别、和弦练习、视奏挑战 |
| 数据卡片 | 练习次数、准确率、平均反应时间 |
| 广告或运营位 | 活动、订阅、曲库推荐 |

首页推荐逻辑：

- 如果用户今日未练习，优先推荐基础练习。
- 如果用户接近升级，推荐视奏挑战。
- 如果用户刚升级，推荐新解锁歌曲。
- 如果用户和弦能力薄弱，推荐和弦练习。
- 如果用户连续多天未练习，推荐短题量恢复练习。
- 歌曲入口固定在首页歌曲专区，不进入底部一级 Tab。
- 首页歌曲卡片可以支持试听、继续练习、查看详情等动作。

### 6.2 练习中心

页面目标：

- 承接所有能力训练。
- 让用户清楚不同练习类型的作用。

练习类型：

| 类型 | 状态 | 说明 |
| --- | --- | --- |
| 音符识别 | 已有基础 | 训练五线谱音符与琴键对应 |
| 和弦练习 | v2.0 新增 | 训练和弦识别与弹奏 |
| 视奏挑战 | 已有基础 | 用于等级晋升 |
| 音阶练习 | 后续 | 训练调性与指法 |
| 节奏训练 | 后续 | 训练节拍和节奏型 |
| 听力练习 | 后续 | 训练音高、音程、和弦听辨 |

### 6.3 音符识别练习页

保留基础版本能力：

- 横屏练习。
- 五线谱目标音符。
- 高音谱和低音谱。
- 中间键盘答题。
- 底部 88 键选择八度。
- 准确率、平均时间、练习进度。
- 屏幕、MIDI、拾音三种输入模式。
- 结果弹窗。

v2.0 增强点：

- 练习结果同步到账户。
- 结果页展示“是否推动歌曲解锁”。
- 完成练习后推荐下一首可解锁歌曲。
- 对薄弱音符给出更明确的复习建议。

布局说明：

- 练习界面布局将在后续迭代中调整。
- 新布局会参考 Simply Piano 的练习体验，但不复制其视觉资源。
- 后续以提供的参考图片为准更新页面结构、谱面区域、键盘区域和反馈区域。
- 当前文档先保留页面信息结构与业务规则，不锁定最终视觉布局。

### 6.4 和弦练习页

页面目标：

- 帮助用户从单音识别过渡到多音组合。
- 为歌曲练习中的伴奏、左手和弦、流行曲弹奏做准备。

和弦类型：

| 阶段 | 和弦内容 |
| --- | --- |
| 入门 | 大三和弦、小三和弦 |
| 基础 | 增三和弦、减三和弦 |
| 进阶 | 属七和弦、大七和弦、小七和弦 |
| 扩展 | 转位和弦、分解和弦 |

页面模块：

| 模块 | 内容 |
| --- | --- |
| 目标和弦 | 显示和弦名，如 C、Am、G7 |
| 谱面区 | 显示和弦在五线谱上的音符 |
| 键盘区 | 支持多键输入和高亮反馈 |
| 提示区 | 显示组成音、指法或根音提示 |
| 统计区 | 当前进度、准确率、平均反应时间 |
| 设置入口 | 和弦类型、根音范围、是否允许转位 |

判题规则：

- 默认要求和弦组成音全部正确。
- 可配置是否允许转位。
- 可配置是否要求低音为根音。
- 多按或漏按均视为错误。
- MIDI 模式下需识别同时或短时间窗口内按下的多个音。
- 拾音模式下和弦识别难度较高，v2.0 可先限制为屏幕键盘和 MIDI 模式。

练习结果：

- 完成和弦数。
- 正确和弦数。
- 错误和弦数。
- 和弦准确率。
- 平均反应时间。
- 薄弱和弦类型。
- 推荐复习。

### 6.5 和弦设置

| 设置项 | 说明 |
| --- | --- |
| 根音范围 | 选择 C 到 B，或限定某些调内根音 |
| 和弦类型 | 大三、小三、属七等 |
| 是否包含转位 | 是否练习第一转位、第二转位 |
| 是否要求根音低音 | 判断时是否要求最低音为根音 |

| 提示时机 | 立即、延迟、不提示 |
| 输入方式 | 屏幕键盘、MIDI、拾音限制说明 |

### 6.8 歌曲练习页：手机版

手机版定位：

- 适合没有真实钢琴时使用。
- 强调轻量练习、熟悉旋律、读谱训练。
- 可以使用屏幕键盘或简化交互。
- 这是独立页面，不复用钢琴版页面布局。

界面建议：

| 区域 | 内容 |
| --- | --- |
| 谱面滚动区 | 当前练习片段的谱面 |
| 进度条 | 当前歌曲进度 |
| 虚拟键盘 | 可点击弹奏 |
| 当前提示 | 当前应弹音符或和弦 |
| 控制区 | 播放、暂停、速度、重练片段 |

练习逻辑：

- 按片段练习。
- 错误较多时自动暂停并回到小节练习。
- 支持慢速练习。
- 支持试听标准旋律。
- 支持单手练习优先。
- 强调“手机上能练”的轻量交互，不要求用户连接真实钢琴。

适用场景：

- 碎片时间预习歌曲。
- 没有钢琴时熟悉谱面。
- 初学者用屏幕键盘练音符位置。

### 6.9 歌曲练习页：钢琴版

钢琴版定位：

- 适合真实钢琴、电钢琴或 MIDI 键盘。
- 强调完整演奏、实时反馈和歌曲完成感。
- 这是独立页面，不复用手机版页面布局。

界面建议：

| 区域 | 内容 |
| --- | --- |
| 横向谱面区 | 当前小节与即将到来的小节 |
| 实时判定区 | 正确、错误、漏弹提示 |
| 输入状态 | MIDI、麦克风或屏幕模式 |
| 速度控制 | 慢速、正常、分段 |
| 练习控制 | 开始、暂停、重来、片段循环 |
| 成绩区 | 准确率、节奏、完成度 |

练习逻辑：

- 优先支持 MIDI 输入。
- 原声钢琴可使用拾音，但复杂复音需逐步开放。
- 歌曲可分段练习。
- 可先右手、再左手、再双手。
- 如果用户连续错误，进入“片段修复模式”。
- 完成后展示歌曲结果和奖励。
- 页面重点应围绕真实弹奏：谱面可读性、提前量、实时反馈和输入状态要比手机版更突出。

## 8. 核心业务规则

### 8.1 音符练习规则

保留基础版本规则：

- 根据用户音域、调号、变音设置生成题目。
- 错得多的音符提高出现频率。
- 答错停留当前题。
- 答对进入下一题。
- 一道题只要曾经答错，本题最终不计为完全正确。
- 练习结果计算准确率和平均时间。

v2.0 增强：

- 练习结果进入云端学习档案。
- 练习结果影响等级进度。
- 练习结果影响歌曲解锁推荐。
- 薄弱音符用于生成复习任务。

### 8.2 和弦练习规则

- 和弦题目由根音、和弦类型、转位规则生成。
- 默认判断组成音是否完全匹配。
- 可设置是否允许转位。
- 可设置是否要求根音作为最低音。
- 多按、漏按、错按均视为错误。
- 和弦练习结果进入和弦能力档案。
- 和弦能力可作为部分歌曲解锁条件。

### 8.3 歌曲解锁规则

歌曲解锁可由以下条件组合决定：

- 用户等级达到要求。
- 完成指定音符练习数量。
- 完成指定和弦练习数量。
- 通过指定视奏挑战。
- 会员或付费权益。
- 活动解锁。

基础解锁规则建议：

| 歌曲等级 | 解锁条件 |
| --- | --- |
| Lv1 歌曲 | 达到 Lv1 |
| Lv2 歌曲 | 达到 Lv2 |
| Lv3 歌曲 | 达到 Lv3 |
| Lv4 歌曲 | 达到 Lv4，完成基础升号练习 |
| Lv5 歌曲 | 达到 Lv5，完成基础和弦练习 |
| Lv6+ 歌曲 | 达到对应等级，并完成相关挑战或和弦能力要求 |

### 8.4 歌曲练习规则

- 歌曲按等级和难度组织。
- 歌曲可拆分为片段或小节。
- 用户可整首练习，也可片段练习。
- 用户进入练习前可以试听歌曲。
- 歌曲练习结果包括完成度、准确率、节奏表现。
- 歌曲完成后可获得星级评分。
- 歌曲高分完成可解锁成就或下一首推荐。

### 8.5 歌曲奖励规则

歌曲作为用户能力成长的奖励，建议使用以下激励：

- 升级后弹窗提示“解锁新歌曲”。
- 首页展示新解锁歌曲。
- 首页歌曲专区和歌曲列表展示当前等级可弹歌曲。
- 完成歌曲后获得星星、徽章或经验。
- 高分完成歌曲后推荐下一首更高难度歌曲。

### 8.6 AI 曲谱付费规则预留

未来 AI 曲谱能力建议采用以下权益：

- 免费用户：可查看能力介绍和示例，不可生成完整曲谱。
- 会员用户：每月获得固定生成或解析次数。
- 单次付费用户：按次购买 AI 生成或上传解析。
- 曲谱生成后归入“我的曲谱”，仅用户个人可见。
- 试听可作为生成完成后的确认步骤。
- 练习功能可作为高级权益或按次权益。

### 8.7 版权与内容边界

- 官方曲库应使用授权曲目、公共领域曲目或原创练习曲。
- 用户上传曲谱仅用于个人学习，不开放公开传播。
- AI 生成应避免复刻明确版权歌曲。
- 需要在上传和生成前加入版权声明。
- 对疑似侵权内容，后台应保留删除和限制能力。

## 9. 等级体系 v2.0

### 9.1 等级设计原则

等级不只是挑战结果，还应成为内容解锁主线。每个等级对应：

- 音符能力。
- 和弦能力。
- 调号能力。
- 可练歌曲范围。
- 推荐练习任务。

### 9.2 等级表

| 等级 | 名称 | 训练重点 | 可解锁歌曲类型 |
| --- | --- | --- | --- |
| Lv1 | 五线谱入门 | 高音谱 C4-G4 白键 | 单手五音歌曲、极简儿歌 |
| Lv2 | 音域扩展 | 高音谱 C4-C5 | 单手八度歌曲、简单旋律 |
| Lv3 | 高音谱熟练 | 高音谱 A3-E5 | 简单双手入门歌曲 |
| Lv4 | 高音谱完整 | 升号加入 | 含少量黑键的简单歌曲 |
| Lv5 | 双谱入门 | 低音谱、升降号 | 左手低音或简单伴奏歌曲 |
| Lv6 | 双谱熟练 | 跨谱识读 | 简单双手完整歌曲 |
| Lv7 | 调号入门 | G、F、D 等调号 | 基础调号歌曲 |
| Lv8 | 调号扩展 | 3 个升降号以内 | 流行改编入门歌曲 |
| Lv9 | 复杂调号 | 5 个升降号以内，还原号 | 中高级歌曲片段 |
| Lv10 | 全调号 | 全音域、全调号 | 高阶视奏歌曲 |

### 9.3 等级与歌曲关系

- 每个等级配置一组推荐歌曲。
- 用户达到等级后自动解锁该等级基础歌曲。
- 部分高价值歌曲可要求会员或额外权益。
- 歌曲练习结果不直接替代等级挑战，但可作为能力证明或辅助升级条件。

## 14. 待确认问题

- v2.0 是否继续沿用当前底部导航：首页、进度、设置。
- 是否新增“练习”Tab；即使新增，“歌曲”也不作为一级 Tab，仍从首页进入。
- 游客模式允许保存多少本地数据。
- 登录方式优先使用手机号、邮箱还是第三方登录。
- 歌曲库初期采用原创练习曲、公共领域曲目，还是授权曲目。
- 歌曲练习首版是否必须支持双手。
- 歌曲练习是否以 MIDI 为最佳体验，屏幕键盘作为补充。
- 拾音模式是否进入歌曲练习首版范围。
- 和弦练习首版是否支持转位。
- 歌曲解锁是否只看等级，还是增加和弦能力要求。
- 会员权益首版是否上线，还是只做付费入口预留。
- AI 曲谱入口是否在 v2.0 露出“即将上线”。
- 上传曲谱能力是否需要提前设计版权声明和用户协议补充条款。
- 练习界面布局以后续提供的 Simply Piano 参考图片为准，目前文档不锁定最终布局。
