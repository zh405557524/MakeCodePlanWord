## 4. 状态与交互

| 状态 | 入口表现 | 点击结果 |
|------|----------|----------|
| 配置启用、已登录会员 | 正常 | 进入 P02 |
| 未登录 | 正常 | 先登录，成功后恢复进入 P02 |
| 非会员 | 可点击 | 进入 P02 查看能力，提交时按统一会员门禁；若 PRD 指定入口拦截则打开会员页并保留回跳 |
| 功能维护 | 禁用并显示维护提示 | 不进入业务页 |
| 配置加载失败 | 入口保留，点击触发配置重试 | 不影响首页案例/歌曲分区 |

返回 P01 时保留首页滚动位置；从登录/会员页回跳只能恢复一次，不重复 push。
