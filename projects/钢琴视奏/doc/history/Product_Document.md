# 钢琴视奏练习产品文档

## 1. 产品概述

### 1.1 产品名称

钢琴视奏练习。

### 1.2 产品定位

一款面向钢琴学习者的五线谱识读与视奏基础训练工具。产品围绕“看谱面音符，快速找到并弹出对应琴键”建立练习闭环，通过即时反馈、错题强化、等级挑战、成就激励和进度统计，帮助用户系统提升识谱准确率、反应速度和键盘位置感。

### 1.3 产品目标

- 帮助初学者建立五线谱音符与钢琴键盘的对应关系。
- 让用户通过短时高频练习提升识谱速度。
- 通过数据反馈让用户知道自己是否在进步。
- 通过等级、目标、提醒和成就提高持续练习动力。
- 支持无琴、电子琴、MIDI 键盘、原声钢琴等不同练习环境。

### 1.4 当前版本范围

当前版本以“音符识别练习”和“视奏挑战”为核心。已覆盖首页入口、横屏练习、练习设置、练习统计、等级挑战、成就展示、练习提醒、MIDI 连接、麦克风拾音、账户资料、本地化和帮助中心。

暂未完整实现的方向包括：和弦练习、节奏训练、听力练习、乐曲片段视奏、完整账号体系和云同步。

## 2. 目标用户

### 2.1 核心用户

- 钢琴初学者：正在学习五线谱，需要快速认识谱面音符和键盘位置。
- 自学用户：缺少老师监督，需要可量化的练习反馈。
- 视奏薄弱用户：能弹琴，但读谱速度慢，希望专项训练识谱反应。
- 电子琴/MIDI 用户：希望使用真实键盘完成答题。
- 原声钢琴用户：希望通过麦克风识别真实弹奏音符。

### 2.2 用户痛点

- 五线谱位置和琴键位置对应慢。
- 高低音谱、升降号、调号容易混淆。
- 不知道每天练多少、练得是否有效。
- 缺少持续练习的目标感和反馈。
- 只靠纸质谱训练时，错误无法被即时识别。

### 2.3 典型使用场景

- 每天用 3 次短练习完成今日目标。
- 用默认音域训练 C 大调白键识谱。
- 调整音域、调号、升降号，进行专项强化。
- 通过视奏挑战冲击更高等级。
- 连接 MIDI 键盘，用真实弹奏完成识谱练习。
- 使用原声钢琴时，通过麦克风拾音完成单音判断。

## 4. 核心业务流程

### 4.1 首次使用流程

1. 用户打开应用，看到启动页。
2. 自动进入主页。
3. 如果用户尚未同意协议，进入核心功能前弹出用户协议与隐私政策。
4. 用户同意后，可使用练习、统计、提醒、MIDI、拾音等能力。
5. 首次同意后，产品可引导用户完成一轮新手练习。

产品要求：

- 未同意协议时，用户仍可浏览基础页面。
- 涉及练习记录、设备连接、通知、麦克风、广告或统计能力时，应先完成协议确认。
- 新手引导练习建议题量为 20 题，降低首次门槛。

### 4.2 普通音符识别练习流程

1. 用户从首页点击“开始练习”或“音符识别”。
2. 进入横屏练习页。
3. 用户点击“开始”。
4. 系统生成本轮目标音符序列。
5. 页面显示一个五线谱目标音符。
6. 用户选择对应八度，并点击中间键盘上的音名。
7. 如果答错，停留当前题并给出错误反馈。
8. 如果答对，记录本题耗时并进入下一题。
9. 完成所有题后展示练习结果。
10. 用户可以结束、返回或再来一轮。

### 4.3 视奏挑战流程

1. 用户在首页点击“视奏挑战”。
2. 系统读取用户当前等级，确定下一等级挑战目标。
3. 按目标等级生成挑战题目。
4. 用户完成挑战。
5. 系统按准确率和平均反应时间判断是否达标。
6. 达标则升级并展示升级成功。
7. 未达标则展示失败结果和未达标项。
8. 用户可再次挑战或返回。

### 4.4 MIDI 输入流程

1. 用户进入 MIDI 设备页面。
2. 授权蓝牙或设备访问权限。
3. 扫描并连接 MIDI 键盘。
4. 进入练习页，在练习设置中选择 MIDI 模式。
5. 用户按下真实键盘。
6. 产品识别按键音高并完成判题。

### 4.5 麦克风拾音流程

1. 用户在练习设置中选择钢琴录音模式。
2. 开始练习前申请麦克风权限。
3. 用户弹奏真实钢琴或电钢琴。
4. 产品识别当前音高并完成判题。

产品限制：

- 拾音模式适合单音练习，不适合和弦或复杂复音。
- 当前建议识别音域为 C3 到 E6。
- 环境噪音、钢琴音色、设备麦克风质量会影响识别效果。

## 5. 页面说明

### 5.1 启动页

页面目标：

- 展示产品品牌感。
- 完成应用初始化。
- 在符合条件时展示启动广告。
- 自动进入主页。

主要内容：

- 应用图标。
- 产品名称。
- 副标题或品牌标语。
- 加载或进度视觉元素。

### 5.2 首页

页面目标：

- 让用户快速开始练习。
- 让用户看到近期学习状态。
- 强化每日目标。

页面模块：

| 模块 | 内容 |
| --- | --- |
| 顶部标题 | 产品名称与副标题 |
| 数据卡片 | 连续天数、练习次数、准确率 |
| 主按钮 | 开始练习 |
| 练习模式 | 音符识别、视奏挑战、和弦练习 |
| 今日目标 | 今日已完成次数、目标次数、完成进度 |
| 广告位 | 符合条件时展示横幅广告 |

交互规则：

- 点击“开始练习”进入普通音符识别练习。
- 点击“音符识别”进入普通音符识别练习。
- 点击“视奏挑战”进入挑战模式。
- 点击“和弦练习”提示即将上线。
- 未同意协议时，进入练习前弹出协议确认。

数据口径：

- 连续天数：从今天开始，向前连续有练习记录的自然日数量。
- 练习次数：累计完成的练习局数。
- 准确率：历史练习准确率均值。
- 今日目标：默认每天完成 3 次练习。

### 5.3 练习页

页面目标：

- 提供沉浸式识谱练习。
- 实时反馈答题结果。
- 展示当前练习进度和质量。

页面布局：

| 区域 | 内容 |
| --- | --- |
| 左侧信息区 | 练习组、当前题进度、准确率、平均时间 |
| 中央谱面区 | 当前音符、五线谱、谱号、调号 |
| 右侧操作区 | 返回、开始/停止、设置 |
| 中间键盘 | 当前八度的答题键盘 |
| 底部键盘 | 88 键缩略键盘，用于切换八度 |

练习状态：

| 状态 | 说明 |
| --- | --- |
| 未开始 | 可返回、可打开设置、可开始练习 |
| 进行中 | 不允许返回和切换设置，可停止练习 |
| 已完成 | 展示结果弹窗 |

判题规则：

- 默认要求音名和八度都正确。
- 如果开启“忽略八度”，只判断音级是否正确。
- 答错后不进入下一题。
- 答对后进入下一题。
- 一道题只要曾经答错，本题最终答对也不计为完全正确。

反馈规则：

- 答对：显示正确反馈，可播放对应音符，可触发轻微振动。
- 答错：显示错误反馈，可播放错误音效，可触发较强振动。
- 反馈持续短暂时间后恢复键盘状态。

提示规则：

- 可设置立即显示、延迟 3 秒、5 秒、10 秒、30 秒或不提示。
- 如果提示开启，先引导用户选择正确八度。
- 八度正确后，再引导用户点击正确音名。

结束弹窗内容：

- 完成题数。
- 总题数。
- 准确率。
- 平均时间。
- 正确数。
- 错误数。
- 练习评级。
- 鼓励语。
- 普通练习升级进度。
- 完成、再来一次。

### 5.4 练习设置弹窗

页面目标：

- 让用户在开始练习前选择输入方式和音符播放偏好。

可选输入方式：

| 模式 | 说明 |
| --- | --- |
| 默认模式 | 使用屏幕虚拟键盘 |
| MIDI 模式 | 使用已连接的 MIDI 键盘 |
| 钢琴录音模式 | 通过麦克风识别真实弹奏音符 |

交互规则：

- 练习进行中不能切换输入模式。
- MIDI 未连接时，点击 MIDI 模式应引导用户进入 MIDI 设备连接页。
- 钢琴录音模式需要展示音域与识别限制说明。

### 5.5 进度页

页面目标：

- 展示用户近期表现。
- 强化持续练习动机。
- 提供成就和下一个目标入口。

页面模块：

| 模块 | 内容 |
| --- | --- |
| 本周概览 | 平均准确率、练习次数、学习时长、连续天数 |
| 每日得分 | 周一到周日每日得分柱状图 |
| 成就激励 | 最近解锁或即将解锁的成就 |
| 下一个目标 | 距离下一练习次数里程碑还差几次 |

交互规则：

- 支持下拉刷新。
- 点击“查看全部”进入成就列表。
- 未同意协议时，进入成就列表前弹出协议确认。

数据口径：

- 本周从周一 0 点开始计算。
- 每日得分为当天练习准确率均值。
- 学习时长按题目数量和平均反应时间估算。
- 成就激励优先展示最近解锁成就，再展示即将解锁成就。

### 5.6 成就列表

页面目标：

- 展示所有成就。
- 给用户提供长期目标。

页面功能：

- 全部成就。
- 已解锁成就。
- 未解锁成就。
- 隐藏成就未解锁时不暴露真实内容。
- 已解锁成就展示解锁日期。

成就分类：

| 类别 | 数量 | 示例 |
| --- | --- | --- |
| 等级成就 | 10 | 达到 Lv1 到 Lv10 |
| 累计练习时间 | 10 | 累计 10 分钟到 500 小时 |
| 单日练习时间 | 6 | 单日 10 分钟到 5 小时 |
| 连续练习天数 | 8 | 连续 3 天到 365 天 |
| 挑战模式 | 10 | 挑战次数、连续答对、完美挑战 |
| 练习次数 | 7 | 累计 5 次到 1000 次 |
| 隐藏成就 | 6 | 夜间练习、清晨练习、久别重练等 |

当前产品状态：

- 成就展示体系已完整。
- 部分成就已经可以根据练习记录解锁。
- 与练习时间、挑战次数、连续答对、隐藏条件相关的成就还需要继续完善判定规则。

### 5.7 音符与练习设置

页面目标：

- 让用户自定义练习难度。
- 支持从入门到进阶的专项训练。

页面结构：

- 音符 Tab。
- 练习 Tab。
- 底部操作栏：默认、确定、取消。

音符 Tab：

| 设置项 | 说明 |
| --- | --- |
| 调号 | 选择练习调号 |
| 起止音符 | 设置 88 键范围内的练习音域 |
| 变音符号频率 | 选择降音符、还原符、升音符 |

练习 Tab：

| 设置项 | 说明 |
| --- | --- |
| 每次练习音符个数 | 1 到 200 |
| 音符练习顺序 | 随机、升序、降序 |
| 提示显示时机 | 立即、延迟、不提示 |
| 只练习白键 | 过滤黑键音符 |
| 忽略八度 | 只判断音级，不判断八度 |
| 隐藏音符名称 | 隐藏键盘上的音名 |

默认建议：

- 初学用户默认只练白键。
- 初学音域建议从 C4 到 G4 开始。
- 提示建议先使用 3 秒，熟练后改为更长延迟或不提示。

## 6. 业务规则

### 6.1 出题规则

普通练习出题受以下因素影响：

- 用户选择的音域范围。
- 用户选择的调号。
- 是否只练习白键。
- 是否增加升号、降号、还原号频率。
- 最近练习中的正确和错误记录。
- 用户选择的出题顺序。
- 用户选择的题目数量。

出题原则：

- 在用户设置范围内生成题目。
- 错得多的音符应更容易再次出现。
- 已经掌握较好的音符出现频率可适当降低。
- 仍需保留一定随机性，避免练习过于机械。

### 6.2 准确率规则

- 一轮练习的准确率 = 完全正确题数 / 已完成题数。
- 一道题如果第一次答错，之后答对也只推进进度，不计入完全正确。
- 答错但未答对的题目不会进入下一题。

### 6.3 平均时间规则

- 每题从目标音符出现开始计时。
- 用户答对时停止本题计时。
- 平均时间 = 已完成题目答对耗时总和 / 已完成题数。

### 6.4 今日目标规则

- 默认目标为每日完成 3 次练习。
- 今日目标按自然日统计。
- 完成一次完整练习后，今日进度增加。

### 6.5 连续天数规则

- 按自然日统计。
- 从今天开始向前计算连续有练习记录的天数。
- 如果昨天或更早出现断档，连续天数停止累加。

### 6.6 本周统计规则

- 本周从周一开始。
- 本周练习次数为周一到当前时间完成的练习局数。
- 本周准确率为本周所有练习准确率均值。
- 本周学习时长按题目数量和平均反应时间估算。

### 6.7 成就展示规则

- 成就分为已解锁和未解锁。
- 已解锁成就展示真实名称、描述、解锁日期。
- 隐藏成就未解锁时，应展示问号或隐藏信息，不暴露具体条件。
- 进度页成就激励最多展示 4 个，优先展示最近解锁，其次展示即将达成。

### 6.8 广告展示规则

广告不应影响核心练习体验。

当前广告规则建议：

- 用户同意隐私协议后才允许广告相关能力。
- 首页可展示横幅广告。
- 开屏广告需要设置等待上限，避免用户长时间停留。
- 新用户早期阶段应降低广告打扰。
- 开屏广告建议满足一定练习次数和安装天数后再展示。

## 7. 等级体系

### 7.1 等级设计原则

等级系统用于引导用户从基础识谱逐步进入复杂视奏。难度由以下维度共同决定：

- 音域范围。
- 高音谱与低音谱覆盖。
- 是否包含升号、降号、还原号。
- 调号复杂度。
- 目标准确率。
- 目标平均反应时间。
- 挑战题量。

### 7.2 等级表

| 等级 | 名称 | 训练重点 | 音域 | 准确率 | 平均时间 |
| --- | --- | --- | --- | --- | --- |
| Lv1 | 五线谱入门 | 高音谱基础五音 | C4-G4 | ≥70% | ≤2.5s |
| Lv2 | 音域扩展 | 高音谱一个八度 | C4-C5 | ≥75% | ≤2.2s |
| Lv3 | 高音谱熟练 | 高音谱宽音域白键 | A3-E5 | ≥80% | ≤2.0s |
| Lv4 | 高音谱完整 | 高音谱完整音域，升号加入 | F3-G5 | ≥82% | ≤1.8s |
| Lv5 | 双谱入门 | 低音谱加入，升降号出现 | C3-C6 | ≥85% | ≤1.6s |
| Lv6 | 双谱熟练 | 跨谱识读，升降号稳定 | A2-E6 | ≥87% | ≤1.5s |
| Lv7 | 调号入门 | G、F、D 等基础调号 | F2-G6 | ≥90% | ≤1.3s |
| Lv8 | 调号扩展 | 3 个升降号以内 | C2-C7 | ≥92% | ≤1.2s |
| Lv9 | 复杂调号 | 5 个升降号以内，还原号加入 | A1-D7 | ≥94% | ≤1.0s |
| Lv10 | 全调号 | 全调号、全 88 键音域 | A0-C8 | ≥95% | ≤0.9s |

### 7.3 升级规则

挑战升级：

- 用户挑战当前等级的下一等级。
- 达到目标准确率和平均时间后升级。
- 未达标时展示差距。

普通练习升级：

- 普通练习也可以累计升级进度。
- 只有练习配置符合目标等级要求，且本轮表现达标，才计入升级进度。
- 多轮普通练习可累计到升级门槛。

## 10. 后续迭代建议

### 10.1 第一阶段：完善当前核心闭环

目标：让音符识别练习和视奏挑战成为稳定、完整、可持续迭代的核心体验。

建议需求：

- 完善首次用户新手练习引导。
- 统一首页、帮助中心和练习中心的入口逻辑。
- 完善拾音模式音域限制和提示。
- 完善成就解锁规则，优先补齐等级、挑战、平均时间、练习时间相关成就。
- 统一“挑战等级”和“账户学习等级”的展示口径。
- 增加练习历史明细页。
- 增加错题或薄弱音符页。

### 10.2 第二阶段：扩展练习内容

目标：从单音识别扩展到更多视奏能力。

建议需求：

- 和弦练习：识别和弹奏常见和弦。
- 节奏训练：节奏型识别与节拍反馈。
- 听力练习：单音、音程、和弦听辨。
- 音阶练习：按调性练习音阶识别与弹奏。
- 连续谱例视奏：从单音题目升级到短句或小节。

### 10.3 第三阶段：账户与增长

目标：提升长期留存和多设备体验。

建议需求：

- 用户注册和登录。
- 练习数据云同步。
- 多设备恢复练习记录。
- 练习报告导出。
- 周报/月报。
- 个性化练习计划。
- 老师或家长查看学习进度。
