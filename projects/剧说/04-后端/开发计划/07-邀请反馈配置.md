## 3. 接口契约

### GET `/api/invite/overview`

鉴权：必须登录。

返回邀请码、邀请规则摘要、奖励统计。

### GET `/api/invite/records`

鉴权：必须登录。分页返回邀请记录。

### POST `/api/feedback`

鉴权：必须登录。

请求：

```json
{
  "type": "BUG",
  "content": "生成失败",
  "contact": "138****0000",
  "attachmentAssetIds": []
}
```

### GET `/api/config/presets`

返回风格、音色、背景音乐、积分计费等配置。

### GET `/api/config/static-page/{key}`

返回用户协议、隐私政策、会员协议、充值协议等静态内容。

## 5. 业务规则

### 邀请

- 用户注册时生成唯一邀请码。
- 邀请关系原则上只允许绑定一次。
- 邀请奖励发放需要通过 `PointsService` 写流水。
- 奖励规则未确认前，只记录关系，奖励发放可配置为关闭。

### 反馈

- 反馈内容必须限制长度。
- 附件上传真实能力后续可复用素材 / 对象存储能力。
- 反馈默认状态为 `PENDING`。

### 配置

- 风格、音色、背景音乐、协议文本先通过 `app_configs` 管理。
- 配置值使用 JSON，后续可迁移到管理后台。
- 客户端只读取配置，不直接决定积分计费最终值。
