## 交付与审查

- 工作台“查看资产”进入真实个人素材的图片历史，并携带个人图片版本 ID；作品来源额外核对原图版本 ID。原入口只打开个人详情，可能展示该素材原来的当前选图，现改为定位本次生成结果。
- 目标位于后续分页时继续读取；完整核对后才发布清单，目标置前并标明“本次查看的图片”。定位只改变展示顺序，不更改个人当前图或作品引用。
- 工作台保存提示显示实际作品名称和角色、场景、道具类型，来源保持作品稳定 ID。个人手改名称、描述和当前选图不被查看行为覆盖。
- 快速重复打开只进入一次，返回刷新并保留工作台选择。预览和取消不发生成、入库或应用写入。
- 跨素材、错来源、非法参数、重复页及空非末页拒绝；读取失败保旧清单、禁止应用并可明确重试，目标缺失明确提示，不把另一张图标为本次结果。过期未引用缓存不能扩大图片可用期。
- FINALIZING 继续查询原任务，未发布时不显示已保存。成功后仍保留等待期间的用户手选，明确选择新结果才查看对应个人副本。

沿既有工作台、历史页、路由、AssetService/ResourceService 实现。没有新后台 HTTP、表、依赖、缓存方案、轮询或原生媒体引擎；收费、冻结、结算、回退仍沿原实现。路由实例标识包含目标版本和来源，异步结果同时核对会话与代次。
