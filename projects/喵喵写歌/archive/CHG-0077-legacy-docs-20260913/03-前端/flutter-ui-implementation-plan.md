# 喵喵写歌前端 UI 实施说明

> 最近更新：2026-06-11 18:00  
> 设计稿目录：`../01-需求/references/images/v1.0/`  
> Flutter 基准：`375 x 812`  
> 目标：让后续编码按设计稿写 UI，而不是只按功能搭骨架。

## 1. 换算规则

- 设计稿 PNG 多为 `860 x 1626`，其中包含手机外壳和黑色背景。
- 实现时只看内层 App 屏幕内容，换算到 Flutter `375 x 812`。
- 原则上用相对布局和 `ScreenUtil`，不要机械套整图比例。
- 宽度基准：内容左右边距以设计稿内层屏幕为准，落到 Flutter 后通常约 `20.w - 24.w`。
- 高度基准：顶部状态栏、安全区、底部导航、迷你播放器必须用 `SafeArea` 和明确 padding 处理。

## 2. 全局视觉

- 背景：深紫黑，页面顶部可有轻微暗渐变
- 主按钮：绿色到青色渐变，胶囊圆角，文字黑色或深色加粗
- 激活态：绿色描边/绿色文字
- 非激活态：紫灰文字
- PRO：橙色胶囊按钮
- 卡片：深色面板、弱描边、圆角 18-24
- 图标：优先使用 Material/Cupertino 现有图标，必要时再补资源

## 3. 首页 UI 要点

- 顶部品牌不能只放文字，需有猫头像符号
- 输入卡片是首页最大视觉中心，开始创作按钮在卡片内部下方
- 快捷功能是 2x2 卡片，每个卡片有彩色图标块、标题、说明
- 热门案例横向滚动，底部要露出卡片，不被导航遮挡

## 4. 写歌 UI 要点

- 标题「AI 写歌」距离顶部按设计稿留白
- Tab 是整宽分段控件，激活项绿色描边和深绿色填充
- 输入框背景、边框、底部分割线和字数位置要按设计稿
- 灵感速递、AI帮写是文本按钮，不做普通圆角大按钮
- 曲风标签为小胶囊，多行 Wrap，选中态绿色
- 固定底部开始创作按钮宽度接近内容区宽度
- 迷你播放器存在时，按钮上移避让

## 5. 作品 UI 要点

- 歌曲/专辑 Tab 与写歌页分段控件风格一致
- 生成中卡片进度条使用绿色到青色渐变
- 已完成卡片右侧圆形播放按钮
- 列表底部必须给底部导航留空间

## 6. 我的 UI 要点

- 用户卡片是上半屏视觉中心，卡片内有头像、会员、积分、统计
- 四个快捷功能使用彩色图标块
- PRO 升级卡使用橙色暗渐变
- 菜单列表分隔线、右箭头和状态 badge 要完整

## 7. UI 验收清单

- [ ] 首页首屏结构与 `首页1.png` 一致
- [ ] 写歌页灵感/高级创作结构与 `Ai写歌/*.png` 一致
- [ ] 作品页歌曲/专辑结构与 `作品/*.png` 一致
- [ ] 我的页结构与 `我的.png` 一致
- [ ] 375x812 无遮挡
- [ ] 390x844、414x896 无明显变形
- [ ] 长文本不溢出按钮和卡片
- [ ] 所有页面有 loading/empty/error/submitting/disabled
