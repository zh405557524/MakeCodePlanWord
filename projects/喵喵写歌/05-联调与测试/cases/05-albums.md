# 专辑测试用例

> 代码依据：`lib/pages/song_works/album_detail/`、`lib/pages/song_works/work_detail/`、`lib/apis/song.dart`
> 当前作品页只显示“我的音乐”，专辑列表/创建入口没有暴露；先用接口或后台预置专辑执行详情链路。

| 用例 ID | 模块 | 标题 | 优先级 | 前置条件 | 测试步骤 | 预期结果 | 测试数据/备注 |
|---------|------|------|--------|----------|----------|----------|---------------|
| ALBUM-GAP-001 | 专辑入口 | 作品页可进入专辑列表并创建专辑 | P1 | U-NORMAL | 浏览作品页全部可见区域 | 按产品范围应有专辑入口和创建入口；当前 `visibleValues=[myMusic]` 时用例失败并登记代码差异 | Controller 有 createAlbum 但 UI 不可达 |
| ALBUM-001 | 创建专辑 | 合法名称创建专辑 | P0 | 通过接口/临时入口调用创建 | 输入专辑名并提交 | 创建成功、提示“专辑已创建”、列表首项出现；trim 后保存 | 名称：测试专辑001 |
| ALBUM-002 | 创建专辑 | 空名称和重复点击校验 | P1 | 创建入口可用 | 输入空格并提交；有效名称快速提交多次 | 空值提示“请输入专辑名”；有效请求只创建一个专辑 | - |
| ALBUM-003 | 专辑详情 | 空专辑展示空态 | P1 | 已有空专辑 | 打开专辑详情 | 显示专辑信息和“专辑暂无歌曲”；添加歌曲入口可用 | - |
| ALBUM-004 | 专辑详情 | 添加候选歌曲成功 | P0 | 有空专辑和两首作品 | 1. 点击添加歌曲；2. 选择一首 | 仅展示不在专辑内的候选；添加后详情和计数更新；作品仍在作品列表 | - |
| ALBUM-005 | 专辑详情 | 重复添加同一歌曲被阻止 | P1 | 歌曲已在专辑 | 再次打开候选列表或直接请求添加 | 已添加歌曲不在候选；后端重复请求不产生重复关系 | - |
| ALBUM-006 | 专辑详情 | 移出歌曲不删除作品 | P0 | 专辑含歌曲 | 点击移出，先取消再确认 | 取消无变化；确认后从专辑移除，作品列表仍存在且可播放 | - |
| ALBUM-007 | 作品详情 | 从作品详情加入专辑 | P0 | 至少一个专辑 | 作品详情→加入专辑→选择 | 提示“已加入专辑”；专辑详情出现该作品；无专辑时提示先创建 | - |
| ALBUM-008 | 删除专辑 | 删除专辑保留歌曲 | P0 | 专辑含歌曲 | 专辑详情→删除→确认 | 专辑软删除并返回；专辑内歌曲仍在作品列表且可播放 | - |
| ALBUM-009 | 异常 | 专辑不存在/加载失败可返回 | P1 | 无效 albumId 或模拟500 | 打开详情并重试/返回 | 显示“专辑不存在”或错误态；无崩溃；返回主页面可用 | - |
