# DEF-V21-001 翻唱整曲来源弹层误用音频参考提示

- 状态：`open`；严重度：`P1`；发现时间：2026-09-19；关联：CHG-0084。后续修复须单独登记修复 CHG，本轮不改业务代码。
- 触发版本：Android 真机和 iOS 375x812 模拟器，均为 `2.1.0(210)`。
- 2026-09-20 复测：当前源码 Debug 包 `1.3.0` 在 Android 真机/iOS 模拟器仍复现；[Android 自动化结果](/Users/soul/code/lxwx/test/catsinger/artifacts/v21-auto-20260920-190503/summary.json)、[iOS 自动化结果](/Users/soul/code/lxwx/test/catsinger/artifacts/v21-auto-20260920-191338/summary.json)，两端均为 `07-whole-song-source` FAIL。

## 复现

1. 在首页点击「AI 翻唱」，进入翻唱声音克隆主页。
2. 点击「选择一首歌来翻唱」。
3. 查看弹层标题和可上传文件说明。

**实际**：两端都显示「音频参考」及「可上传6~90s mp3、mp4文件」。

**预期**：这是整曲翻唱的歌曲来源选择。标题应表达整曲来源；格式、容量和时长提示应取当前模型与平台限制，不应固定为 6–90 秒/MP3/MP4。当前 PRD 的平台暂定整曲上限为 10 分钟，仍须与所选模型更严格限制取交集。

**影响**：用户会误以为完整歌曲不能上传，阻断主路径决策。当前仅证明 UI 提示错误，**未选择超过 90 秒的文件，不能据此断言实际上传校验也错误**。

## 定位与证据

- Flutter `lib/pages/song_voice_cover/view.dart` 约第 427 行和第 467 行分别写死弹层标题与提示；同模块 `controller.dart` 约第 129～138 行实际按服务端模型/平台配置计算大小、时长上限。UI 与控制器约束未同步。
- [Android 截图](</Users/soul/code/lxwx/test/catsinger/artifacts/v21-dual-20260919/android/14-source-options.png>)、[iOS 截图](</Users/soul/code/lxwx/test/catsinger/artifacts/v21-dual-20260919/ios/10-source-options.png>)；同目录有 UI XML。

## 回归要求

- 两端在不同翻唱模型下显示对应来源标题和真实限制；缺少能力声明时不得猜一个更窄的 90 秒限制。
- 选择合法的完整歌曲执行文件校验，分别覆盖 90 秒以上、当前模型上限内/外；本次未做这一步。
