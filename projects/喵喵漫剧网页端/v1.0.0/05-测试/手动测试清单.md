# 喵喵漫剧网页端 v1.0.0 手动测试清单

> 用途：给用户本人照着在浏览器里走一遍，检查功能是否正常。
> 来源：从同目录 `测试.md` 的用例里挑出“人能在界面上操作和看到”的部分，按实际使用顺序重排；括号里是对应的原用例编号，想看细节去 `测试.md` 查。
> 自动测试、查数据库、查接口返回的用例不在这份清单里，由 Codex 在 `测试.md` 里执行。

## 怎么用

1. 按顺序从上往下走，前面的步骤会给后面准备数据（先登录，再建作品，再整理资产……）。
2. 每一步在“结果”栏填：`过` / `不过` / `没测`。不过的，在“备注”栏写一句现象，最好截图放到 `evidence/手动/`，文件名用步骤编号（例如 `C-05.png`）。
3. 标了 💰 的步骤会花真钱或消耗积分，标了 📱 的步骤需要手机。可以先跳过，最后集中做。
4. 走完后把“不过”的编号发给 Claude，由 Claude 整理成问题清单。

## 开始前的准备

| 项 | 要求 |
|---|---|
| 后端 | 本机后端已启动（在后端工程里 `./gradlew bootRun`，端口 8080） |
| 网页端 | `lib/global.dart` 里 `currentServerAddressType = 1`（连本机后端），用 Chrome 打开 |
| 窗口 | 先用 1440×900 左右的窗口测；A 组里有换窗口大小的步骤 |
| 账号 1 | 一个从没在喵喵漫剧注册过的手机号（测注册） |
| 账号 2 | 一个只用验证码登录过、没设过密码的老账号（测“老账号设密码”） |
| 手机 📱 | 装了喵喵漫剧手机端，能登录账号 1（测两端数据一致、扫码） |
| 素材 | 一段 50 字以上的小说或剧本文字；一个 UTF-8 的 TXT、一个 GBK 的 TXT；一张图片；一张故意弄坏的图片文件（比如把 TXT 改名成 .png） |
