# 喵喵穿搭测试素材包（2026-09-28）

> 用途：导入测试手机或模拟器，验证个人档案、照片预检、衣橱识别/拆分，以及后续试衣、搭配、发型、妆容和形象报告输入链路。  
> 生成方式：Codex 内置图像生成工具；所有人物均为 AI 合成成年人，不对应真实人物。  
> 安全边界：无品牌、无水印、无真实用户数据；仅用于 QA，不作为产品展示、训练数据或审美验收基准。

## 2. 推荐测试顺序

1. 用 `person-a-face.png` + `person-a-full-body.png` 创建一个完整档案，记录照片检测结果和保存后的资源复用状态。
2. 分别用三张单品白底图新增衣物，确认分类、名称、颜色、材质和白底结果。
3. 用 `clothing-mixed-flatlay.png` 验证多单品拆分数量、鞋子配对、编辑和移除候选。
4. 用 `invalid-two-people.png` 上传到全身照入口，用 `invalid-face-obscured.png` 上传到正脸照入口，确认拦截/警告、错误文案和重新选择入口。
5. 用 person-a 与 person-b 分别检查全身卡片的裁切、缩放和换人后状态刷新。
6. 只有在确认测试账号、测试环境、积分消耗和 Provider 后，再使用这些素材执行真实生成；不要在个人付费账号上直接点生成。

## 3. 导入方式

### iOS 模拟器

模拟器已启动时，可在本目录执行：

```bash
xcrun simctl addmedia booted people/*.png clothing/*.png negative/*.png
```

导入后素材会出现在系统“照片”中。首次选择时仍需验证 App 的相册权限提示和有限访问状态。

### iPhone / Android 真机

- 优先使用本目录的 `catoutfit-test-materials-20260928.zip` 传到电脑或测试群，再解压并保存到系统相册。
- iPhone 可通过 AirDrop、文件 App 或测试资料链接导入；Android 可通过 USB、附近分享或文件管理器导入。
- 负向素材位于 `negative/`，建议单独建“喵喵穿搭-负向测试”相册，避免误用于正常生成。

## 4. 判定边界

- “图片成功选中/预览”不等于服务端照片校验通过。
- “白底图生成”不等于衣物分类、数量或积分扣减正确。
- AI 合成人物只能用于功能与异常验证，不能代表真实人像、肤色、体型或审美效果的完整覆盖。
- 本素材包没有专门制造超过20MB、损坏文件、HEIC、极暗、强逆光、侧脸、儿童或裸露内容；这些应作为后续安全专项单独准备。

- 9张素材已导入 Android 12 真机 `V1981A` 的 `Pictures/CatoutfitQA-20260928`，并完成媒体扫描；同时保留 iOS 模拟器导入副本。

- 白衬衫识别为1件上装；多单品平铺图准确拆分为毛衣、半身裙、一双鞋和斜挎包4件。
