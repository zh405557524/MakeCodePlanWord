# 工作台说明

> 用到时再读：要找某个文件或脚本、要改工作台的规则、要提交 git 时。每个对话自动读的只有 `/Users/soul/work/MakeCodePlanWord/AGENTS.md`。

## 目录

| 路径 | 用途 |
|---|---|
| `工作说明.md` | 给用户看的一页纸：每个阶段做什么、用哪个提示词、要确认什么 |
| `workflow/` | 流程细则：`00` 总纲，`01`～`08` 八个阶段，`09` 线上问题，`10` 新项目，`11` 旧项目迁移；另有三份正在用的规则：`工作台说明.md`（本文件）、`任务命令速查.md`、`规则出处表.md`；`参考/` 只放参考资料（开发计划示例、论文、首次上架清单），不放正在用的规则 |
| `prompts/提示词.md` | 每个阶段的提示词。只写填什么、按哪一节做、交什么、在哪停；交给别的 AI 的那几段保持详细 |
| `templates/` | `project/` 项目工作区、`version/` 版本文件夹（含模块计划、检验计划）、`patch/` 修复单、`repo/` 和 `repo-rules/` 新代码仓库用 |
| `看板/任务台账.json` | 所有任务的唯一出处，进 git，只用 `task.py` 读写 |
| `workspace-registry.json` | 项目登记：仓库路径、工作区、流程版本 |
| `projects/` | 各项目的工作区 |
| `变更记录/` | 工作流本身的调整计划和执行记录 |
| `legacy/v1/`、`_backup/` | 旧规则和 2026-10～11 的手动备份，只读，只供追溯 |

脚本（都在 `scripts/`，不带参数运行可以看用法）：

| 脚本 | 做什么 |
|---|---|
| `task.py` | 任务：建、改状态、登记计划、记工作空间、设等待、查漏登。三个角色改任务状态都只用它 |
| `set-status.py` | 改模块清单里某个模块的后端 / 前端 / 自审 / 检验等栏 |
| `plan-status.py` | 改给执行方的计划开头的状态，做完时移到 `待检验/` |
| `set-priority.py` | 改模块等级：紧急 / 日常 / 闲时 |
| `progress.py` | 以任务台账为准生成 `看板/进行中.md`、`看板/进行中.html`；用户双击 `看进度.command` 也是它 |
| `check-plan.py` | 检查一个版本的开发计划：行数、必填章节、固定用词 |
| `task-hook.py` | Claude Code 的钩子：开工自动改“执行中”，卡住答复后自动“继续” |
| `init-project.sh`、`new-version.sh` | 建项目工作区；开版本（`--patch` 开 patch） |
| `update-current-doc.sh` | 只兼容旧的全量格式；增量版本按 `workflow/08` 手动合并 |

## 改这个仓库本身时

- 用户问规则该怎么改：先出调整方案，确认后再改。改之前看 git 里有没有别的对话没提交的改动；调整计划和执行记录写进 `变更记录/`。
- **分层读**：每个对话自动读的只有工作台根目录的 `AGENTS.md`（`CLAUDE.md` 只有一行引用它），它保持在 800 字以内，只放入口和最要紧的几条；其余内容放在用到时才读的文件里。**要 AI 一定做到的事，写在它一定会读的地方**：计划本身、提示词、`AGENTS.md`。细则只有被点名（写绝对路径）时才会被读。
- **一条规则只在一个出处写完整**，别处引用。改规则时照 `workflow/规则出处表.md` 同步，改完搜关键词，确认没有旧说法。
- 新增规则前，先看能不能并进已有文件，或做成模板里的一栏、脚本里的一项检查。
- 模板改动不会同步到已有项目。
- 已归档的版本文件夹不改；`当前产品文档/` 只在归档时合入已上线的变化；不在 `projects/` 下新建 v1 风格的文件（`workflow.md`、`change-plan.md`、`change-log.md`）。
- 大批量删除前，先列明对象、范围、影响和恢复方式，用户明确确认后才做。替换设计稿时逐个换、核对新稿后再删对应旧稿。

## 不进 Git 的东西

- 测试证据（`evidence/` 整个目录，含里面的 `.md`）、截图、录屏、日志、安装包；设计稿和素材目录；图片、视频、压缩包、Figma、PDF / Office 等二进制文件。规则在 `.gitignore`，不用 `git add -f` 绕过。
- 进 Git 的：正式文档，以及测试阶段目录里 `evidence/` 以外的 Markdown 计划和报告。这条规则不授权删除本地文件。
