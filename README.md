# MakeCodePlanWord

一个人 + AI 做 App 的开发流程工作台：流程规则、模板、提示词、脚本，以及每个项目的工作区。

流程：产品 → 设计 → 技术规划 → 开发计划 → 开发 → 测试 → 上线 → 归档。

| 我要…… | 看这里 |

| 了解整个流程和文件放在哪 | `workflow/00-总流程.md` |
| 复制提示词 | `prompts/提示词.md` |
| 看有哪些项目、各用哪种流程 | `projects/README.md` |
| 开一个新版本 | `prompts/提示词.md` P1-1 |
| 修线上 bug | `prompts/提示词.md` P10 |
| 新建项目 | `workflow/10-新项目初始化.md` |
| 把 v1 旧项目迁移过来 | `workflow/11-旧项目迁移.md` |
| AI 开始工作先读什么；改规则要同步哪些文件 | `AGENTS.md` |
| 工作流以前怎么调整过 | `变更记录/` |
