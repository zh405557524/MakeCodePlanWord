## 5. 契约

### 5.1 K-27 把资产库的形象挂到本集角色 / 场景下（新增）

`POST /api/drama/episode-assets/{bindingId}/library-looks`，请求头 `Idempotency-Key`。

请求：

```json
{
  "expectedRevision": 3,
  "sourceAssetId": "9001",
  "lookIds": ["9002", "9003"]
}
```

| 字段 | 说明 |
|---|---|
| `expectedRevision` | 本集这条关联（`bindingId`）现在的版本 |
| `sourceAssetId` | 资产库里的角色 / 场景主体（本人个人素材或已发布系统素材），和本集这条同类型 |
| `lookIds` | 要带上的资产库形象，1～20 个，不重复，都必须是 `sourceAssetId` 下面的形象 |

规则：
1. `bindingId` 的素材必须是本作品的角色 / 场景**主体**（不是形象、不是道具），本集未归档；作品在分集制作。
2. 逐个形象（按 `lookIds` 顺序）：
   - 作品里这个主体下**有同名形象**：资产库形象有可用的已应用图 → 给作品形象固定一份图片版本并应用（原来的图留在历史；这个形象是整部作品共用的，其他集一起换）；没图 → 不动图。没关联本集的补上关联。
   - **没有同名形象**：照导入的写法新建形象（资料 + 有图时固定图片）挂到这个主体下，关联本集。
3. 全名“作品主名·形象名”超过 20 字 → `-400`，整个请求不写（用户先在资产库改短或不勾它）。
4. 这个主体或要换图的同名形象有进行中的生图任务 → `-560005`，整个请求不写。
5. 不扣积分；本集版本 +1；同键同内容重放返回原结果，同键换内容 `-560003`。

返回：

```json
{ "lookBindingIds": ["8402", "8403"] }
```

`lookBindingIds`：这些形象在本集的关联，按 `lookIds` 顺序。

失败：

| code | message | 什么时候 |
|---|---|---|
| `-400` | 请求参数错误（现有） | 字段缺、格式不对、`lookIds` 为空 / 超过 20 / 重复；本集这条不是角色 / 场景主体 |
| `-400` | 形象全名“…”超过 20 字，请改短 | 规则 3 |
| `-404` | （现有） | 关联、资产库主体不存在或不是自己的 |
| `-560001` | （现有：版本冲突） | `expectedRevision` 过期 |
| `-560003` | （现有：幂等冲突） | 同键换内容 |
| `-560005` | （现有：正在生成） | 规则 4 |
| `-560007` | 选择的形象不属于这个角色（场景写“这个场景”） | `lookIds` 里有不是 `sourceAssetId` 的形象 |

### 5.2 导入加可选 `lookIds`（修改，K-24）

`POST /api/drama/episodes/{episodeId}/assets/import` 请求加可选 `lookIds: string[]`：不传或 `null` = 和现在一样带上全部形象；`[]` = 一个都不带；有值 = 只带这些（每个都必须是 `sourceAssetId` 下的形象，否则 `-560007`“选择的形象不属于这个角色”）。返回不变（`lookBindingIds` 只含带上的）。

## 8. 模块验收路径

1. 【用户】网页资产库“角色”→ 江敏一行，后面排着婚纱、短发，名字下写“来源：项目《…》”（AC-01-9）→ §4 第 1 行。
2. 【用户】素材详情给“十五个字的主名”新增形象，名字框最多填 4 个字；资产库改主名让形象全名超 20 字 → 提示“形象全名“…”超过 20 字，请改短”→ 第 2 行。
3. 【用户】作品 B 第 1 集一个 AI 识别出来、还没图的“江敏”卡 →“从资产库”→ 选择器里江敏一行 → 选中 → 弹框：主形象“用作主形象”，婚纱、短发默认勾上 → 取消短发 → 确定 → 范围确认 → 卡片换上主图，本集形象一行多了婚纱（AC-01-11）→ 第 3、4 行。
4. 作品里已有“江敏·婚纱”（没图）时再做一次 → 弹框里婚纱写“已有同名形象，会换成这张图”→ 确定后婚纱有图、没有多出第二个婚纱 → 第 4 行。
5. 道具卡“从资产库”选一个道具 → 弹框只有一格“这张图用于这个道具”→ 确定 → 换图 → 第 4 行。
6. 【用户】手机端导入页新增导入江敏 → 弹框勾形象 → 只带勾选的；换图同第 3 步 → 第 5 行。

## 9. 风险与回滚

- 同名形象换图是整部作品共用的，其他集用这个形象的片段也会跟着换图（弹框小字已提示）。
- 网页 / 手机端“换主图”和“带形象”是两次请求：主图换好、带形象失败时，按 §4 第 6 行提示，用户可以再点一次（K-27 幂等，已挂上的不会重复）。
- 回滚：前端不调 K-27 即回到只换图；后端新接口不调用就没有影响。
