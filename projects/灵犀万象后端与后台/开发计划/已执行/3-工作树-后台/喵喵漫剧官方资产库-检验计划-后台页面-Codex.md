## 1. 启动页面

1. 在终端跑：
   ```bash
   bash /Users/soul/code/lxwx/worktrees/_official_assets_tools/run.sh
   ```
   它等于在工作树里执行 `flutter run -d web-server --web-port 8091 --dart-define=OFFICIAL_ASSET_FAKE_DATA=true`。看到 `is being served at http://localhost:8091` 就好了。你用的浏览器工具更适合 `-d chrome` 的话，可以改用：
   ```bash
   cd /Users/soul/code/lxwx/worktrees/lxwx_admin-official-assets
   flutter run -d chrome --web-port 8091 --dart-define=OFFICIAL_ASSET_FAKE_DATA=true
   ```
2. 在浏览器里打开 `http://localhost:8091/admin.html`。**登录要用户自己输入密码**：停下来请用户登录，不要保存、不要打印密码。官方资产库这一块用的是假数据，登录连哪个后端都行。
3. 右上角 App 切到“喵喵漫剧”，左侧“内容与资源”分组里点“官方资产库”（在“风格管理”后面）。
4. 浏览器窗口宽度先用 1440 以上（详情页三栏布局要宽度 ≥ 1080 才会并排），最后再看一次窄窗口（第 3 节 C10）。
5. 改了代码以后，在 `flutter run` 的终端里按 `r` 热重载，或按 `R` 重启。**注意：假数据存在内存里，按 `R` 或刷新浏览器以后会恢复成初始状态。**
6. 看运营账号的另外两种状态，要停掉再用参数重启：
   ```bash
   cd /Users/soul/code/lxwx/worktrees/lxwx_admin-official-assets
   flutter run -d web-server --web-port 8091 --dart-define=OFFICIAL_ASSET_FAKE_DATA=true --dart-define=OFFICIAL_ASSET_FAKE_OPERATOR=unset
   # 或 OFFICIAL_ASSET_FAKE_OPERATOR=unavailable
   ```
   每次重启都要用户重新登录的话，把 C1 的三种状态放到最后一起看。

## 2. 怎么判断“对”

- 颜色：主色紫色（设计稿里的按钮紫）、已上架绿、未上架灰、画风已删除/不能生成的原因橙、错误红。

- 浏览器控制台不能有 Flutter 报错（`RenderFlex overflowed`、`Exception`、`Assertion`）。
