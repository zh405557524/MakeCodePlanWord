## 1. 功能定位与边界

把录音、本地音频和相册视频统一转换为可上传的本地音频片段。该模块只负责客户端选择、录制、解码、截取和临时文件，不决定服务端审核或业务可用性。

## 2. 入口与页面文件

- P05 立即录音进入 P06。
- P05 本地上传或相册视频进入 P07。
- 建议目录：`lib/pages/song_voice_cover/media/`，包含 `source_picker/`、`recording/`、`trim/` 和共用 widgets。
- 复用 `lib/services/media_audio_converter.dart`、现有文件选择器、录音能力和 `AudioPlayClient`。

设计中的最低时长结合 PRD 统一为单段 1 分钟，单段最多 5 分钟。

## 4. 媒体规则

| 来源 | 客户端动作 | 输出 |
|------|------------|------|
| 录音 | 点击时申请麦克风权限，M4A 临时录制 | 1-5 分钟本地片段 |
| 本地音频 | 系统文件选择器，不申请整盘权限 | 原文件或截取后的 M4A |
| 相册视频 | 点击时申请相册权限，选视频后提取音轨 | 提取并截取后的 M4A |

客户端预检格式、可读性、大小和时长；最终以服务端文件签名、MIME、解码和探测结果为准。

## 5. 录音状态机

```text
idle -> permission -> recording -> paused/stopped -> preview -> saved
                  -> interrupted -> recoverable/error
```

- 小于 1 分钟不能保存，显示继续录制。
- 到 5 分钟自动停止并提示。
- 来电、切后台、权限撤回时停止录音；已落盘且可读片段可恢复预览。
- 重录需二次确认并清理旧临时文件。

## 6. 截取交互

- 展示文件名、真实大小/总时长、播放进度和选区。
- 选区 1-5 分钟，起止点不能越界。
- 拖动时只更新预览；确认后调用 `exportAudioSegmentM4a` 产生新文件。
- 导出失败保留原文件和选区，不让用户重新选择。
- M4A 是上传中间格式，不代表厂家最终输出格式。
