## 1. 功能定位与边界

本模块负责商业化页面和我的页二级功能页面：VIP 会员、积分充值、积分详情，以及用户确认缺失的邀请好友、更多设置、意见反馈三个页面。

本模块包含：

- VIP 会员页：权益、套餐、协议、立即充值。
- 积分充值页：积分套餐、支付方式、充值协议、立即充值。
- 积分详情页：积分收支流水。
- 邀请好友页：邀请码、复制、分享、规则、邀请记录 / 空态。
- 更多设置页：协议、隐私、版本、缓存、退出登录、注销账号占位。
- 意见反馈页：反馈类型、描述、附件占位、联系方式、提交状态。

本模块不包含：

- 真实支付 SDK。
- 真实订单创建、支付结果回调和到账。
- 真实邀请奖励结算。
- 真实反馈附件上传。
- 真实账号注销后端流程。
- 客服 IM 或在线客服系统；当前仅可预留入口。

## 6. 业务内容与数据流

### 6.1 会员购买数据流

```text

MembershipView
  -> MembershipController.loadPlans()
  -> 用户选择套餐
  -> 勾选协议
  -> submit()
  -> PaymentApi.createMembershipOrder(mock)
  -> mock 支付结果
  -> UserStore.refreshEntitlement(mock)

```

规则：

- 未勾选协议不可提交。
- 未选择套餐不可提交。
- 提交中按钮 disabled。
- 支付取消 / 失败 / 成功都要有提示，真实结果页待确认。

### 6.2 积分充值与流水数据流

```text

PointsRechargeView
  -> loadPackages()
  -> 选择套餐和支付方式
  -> 勾选协议
  -> mock 提交
  -> UserStore.refreshPoints()

PointsLedgerView
  -> PointsApi.fetchLedger(mock)
  -> loading / empty / error / success

```

### 6.3 邀请好友数据流

```text

InviteView
  -> InviteController.loadInviteInfo()
  -> UserStore.inviteCode
  -> InviteApi.fetchRecords(mock)
  -> 复制邀请码 / 分享邀请

```

规则：

- 邀请码沿用我的页邀请码。
- 分享失败有提示。
- 邀请记录支持空态。
- 邀请奖励规则文案不得写死最终奖励金额，使用 mock 配置。

### 6.4 更多设置数据流

```text

SettingsView
  -> SettingsController.loadAppInfo()
  -> 查看协议 / 隐私
  -> 清理缓存
  -> 退出登录二次确认
  -> 注销账号风险确认占位

```

规则：

- 退出登录后清理 token 和用户态，回到未登录状态。
- 注销账号必须二次确认，真实流程待后端确认。
- 清理缓存失败要提示。

### 6.5 意见反馈数据流

```text

FeedbackView
  -> 选择类型
  -> 输入描述
  -> 添加附件占位
  -> 输入联系方式
  -> FeedbackApi.submit(mock)
  -> 成功 / 失败提示

```

规则：

- 描述为空不可提交。
- 失败时保留已填内容。
- 附件数量、大小、类型待确认，MVP 可先文本反馈。
