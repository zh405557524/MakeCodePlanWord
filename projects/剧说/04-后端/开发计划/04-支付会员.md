## 3. 接口契约

### GET `/api/membership/plans`

返回会员套餐列表。

### GET `/api/membership/status`

鉴权：必须登录。返回当前会员状态、有效期、权益摘要。

### POST `/api/payments/orders`

鉴权：必须登录。关键写接口，必须支持 `Idempotency-Key`。

请求：

```json
{
  "productType": "POINTS",
  "productId": "points_100",
  "channel": "MOCK"
}
```

响应：

```json
{
  "orderNo": "P202605190001",
  "channel": "MOCK",
  "payParams": {}
}
```

### POST `/api/payments/callback/{channel}`

接收渠道原始回调。无需用户鉴权，但必须验签、幂等、保存原文。

## 5. 业务规则

- 创建订单只创建待支付订单，不发放权益。
- 支付成功以服务端验签回调或服务端查询为准。
- 重复回调必须幂等，不重复发放积分或会员。
- 积分充值通过 `PointsService.grantByPayment()` 到账。
- 会员购买更新 `user_memberships`，可按当前有效期顺延。
- iOS 虚拟商品是否必须 Apple IAP 待确认，当前保留渠道枚举位。

- 重复回调不重复到账。
- 订单过期后不能继续到账。
