# Flutter 模块开发文档：内容生成与编辑脚本

> 版本：`v1.0`｜状态：待评审｜任务：`T-F008 内容生成中`、`T-F009 编辑脚本`

## 1. 功能定位与边界

展示脚本与分镜图片统一生成过程，并实现脚本、镜头画面、可空口播、分镜图片历史、上传替换、重新生成和版本恢复。内容生成是一个主状态，脚本和图片是内部步骤。

## 2. 入口、路由与页面文件

- `/seller/works/:workId` 根据状态显示 `ContentRunningView` 或 `ScriptEditingView`。
- 新增 `pages/seller_work/content_running/`、`pages/seller_work/script_editing/` 和页面内 `EditShotSheet`、`ImageHistorySheet`。
- 编辑镜头、历史图片和重生成确认均为弹层，不新增一级页面。

## 3. 依赖前置

- Java：内容任务、作品详情、版本、脚本历史/恢复、镜头 PATCH、图片历史/生成/上传/选择、失败镜头重试接口。
- 图片上传复用公共资源服务；编辑保存携带 version。
- 开发依赖内容生成和编辑脚本页面 UI。

## 6. 业务内容与数据流

- 内容生成：进入立即查询 → 展示真实进度/步骤 → 按服务端间隔轮询 → 成功自动进入编辑脚本 → 失败显示失败镜头和最小恢复。
- 编辑镜头：打开弹层 → 修改画面/口播 → 校验画面非空 → PATCH 携带 version → 冲突则刷新后重新编辑。
- 重新生成单图：确认积分/规则 → 创建图片任务 → 当前镜头显示局部运行状态；其他镜头可继续查看。
- 上传替换：资源上传/审核 → 新建图片版本 → 用户明确选择为当前图片。
- 脚本历史：查看版本 → 预览 → 恢复生成新当前版本，不覆盖历史。
- 整体重生成：二次确认并创建新内容任务；任务开始后退出不取消。

## 7. 现有工程参考点

复用现有生成进度、`AppGradientProgressBar`、编辑弹层、资源上传和积分确认模式；不复用歌曲歌词、音频时间轴、封面生成或播放器。

## 8. 建议实现步骤

1. 完成内容运行状态和轮询生命周期。
2. 完成镜头列表、当前图片和问题状态。
3. 完成画面/口播编辑、乐观锁和冲突恢复。
4. 完成图片历史、选择、上传替换和单镜头重生成。
5. 完成脚本历史、版本恢复、整体重生成和失败镜头重试。
6. 增加部分失败、切后台和并发编辑测试。

## 10. 验收标准

- 内容任务同时产出脚本、镜头和分镜图片，页面不拆成两个主状态。
- 部分图片失败时保留成功内容，并能只重试失败镜头。
- 所有镜头画面非空且有可用当前图片后，才能进入视频报价。
- 口播为空时可保存并由视频模型按画面生成，不出现独立配音任务。
- 运行中不能取消/删除；重生成正确走积分确认和幂等。

## 11. 编码注意事项

不得展示假百分比或固定时间。不要在客户端拼接最终脚本 JSON。历史恢复必须生成新版本。AI 图片预览叠加水印。
