## 1. 模块定位与边界

### 1.1 定位

弹框是产品中**密度最高、最容易失控**的一类界面：它们分散在各个模块里，但结构、按钮语义和危险操作的分寸必须统一。本模块把全部弹框集中登记，便于统一设计与统一出图。

### 1.2 弹框通用规则

- 内容要短，按钮语义明确，不用"确定 / 取消"这类无信息量的组合承载危险操作。
- 权限类弹框统一"先在应用内解释用途，再请求系统权限"；被永久拒绝时提供前往系统设置的引导。
- 危险操作（退出登录、清除缓存、停止练习、取消导入、删除曲谱、放弃未保存修改、账号注销）必须二次确认，并说明影响范围。
- 结果类弹框用于反馈表现和下一步，不做夸张游戏化奖励。
- 协议弹框不可点击遮罩跳过。
- 额度与频率类提示**不是错误状态**：不用失败样式、不产生记录，且必须给出可执行的出路。

### 1.3 归属说明

每个弹框的触发逻辑写在其所属模块文档里，本文件只维护**清单、结构要点与关键规则**。修改某个弹框的触发条件时，请同时检查所属模块文档。

## 3. 弹框细则

| ID | 弹框 | 结构要点 | 关键规则 |
| --- | --- | --- | --- |
| D-01 | 用户协议与隐私 | 图标、说明、两个协议链接、不同意 / 同意并继续 | 不可点遮罩跳过；同意后记录版本与时间；见《账号与合规》A-04 |
| D-02 | 通知权限说明 | 标题、用途说明、取消 / 允许 | 先解释再请求系统权限 |
| D-03 | 蓝牙权限说明 | 标题、用途说明、取消 / 允许 | 仅 BLE MIDI 需要；USB 不需要 |
| D-04 | 麦克风权限说明 | 标题、用途说明、取消 / 允许 | 仅用于单音拾音识别，不用于和弦与歌曲 |
| D-05 | 权限失败 / 前往设置 | 失败说明、取消、去设置 | 永久拒绝时提供系统设置入口 |
| D-06 | 练习设置（练习中） | 默认 / MIDI / 钢琴录音、播放音开关、完成 | 只临时覆盖输入模式，不写回 N-05 |
| D-07 | 钢琴录音音域说明 | 标题、支持音域说明、知道了 | 从 D-06 二次弹出 |
| D-08 | 停止练习确认 | 标题、说明、取消、确认 | 挑战语义为"退出挑战"，普通为"结束练习" |
| D-09 | 普通练习完成 | 图标、准确率、平均时间、升级进度、完成 / 再来一次 | 反馈克制，有升级进度时展示轻量进度条 |
| D-10 | 视奏挑战结果 | 结果区、条件卡、准确率、平均时间、再挑战 / 完成 | 必须让用户看到"差在哪"，不只给成功 / 失败 |
| D-11 | 编辑昵称 / 邮箱 | 输入框、校验提示、取消 / 保存 | 保存失败保留输入内容 |
| D-12 | 退出登录确认 | 说明本地数据处理、取消 / 确认 | 二次确认 |
| D-13 | 钢琴音色包更新 | 版本说明、大小、稍后 / 更新 | 更新期间不阻断基础练习；失败可重试 |
| D-14 | 清除缓存确认 | 影响范围说明、取消 / 确认 | 二次确认；不清除已确认的曲谱与记录 |
| D-15 | 合法使用权确认 | 使用范围说明、取消 / 我已确认 | 未确认不得提交文件；首次展示完整说明 |

| D-18 | 未保存校对离开 | 保存草稿 / 放弃修改 / 取消 | 阻止静默丢失修改 |
| D-19 | 文件异常提示 | 具体原因（超限 / 加密 / 损坏 / 无可识别内容）、重新选择 | 显示当前值与上限 |
| D-20 | 无明显钢琴轨提示 | 说明不代表文件不可用、手动选择 | 不作为失败终止 |
| D-21 | 账号注销确认与回执 | 影响清单、确认勾选、提交；成功后展示回执 | 二次确认；提交后本地退出登录 |

## 5. 模块级验收要点

- 每个危险操作都有二次确认，且确认文案说明了影响范围而不只是"确定要删除吗"。
- 权限类弹框的顺序统一：应用内说明 → 系统权限 → 失败引导。
- 状态表达不只依赖颜色；文字缩放后不遮挡确认、保存、取消等关键动作。
- 额度（D-23）与频率（D-24）提示同时不满足时只展示 D-23。
- 弹框不出现倒计时、伪紧迫性或隐藏关闭按钮。
