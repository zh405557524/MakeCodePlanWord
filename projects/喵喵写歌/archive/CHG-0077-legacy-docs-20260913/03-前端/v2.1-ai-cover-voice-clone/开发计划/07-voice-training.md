## 1. 功能定位与边界

完成本人音色从审核通过素材到训练任务、平台持久化试听和 AVAILABLE 的用户闭环。训练与翻唱分别计费，训练成功不自动创建翻唱任务。

## 2. 前置条件

- 当前用户是会员。
- 音色资料和素材状态符合后端要求。
- 审核通过素材累计 1-10 分钟、<=100MB；低于 5 分钟需明确确认风险。
- 本次训练重新确认本人声音权利和风险授权。
- 训练模型 `sceneCode=song.voice.train` 有可用真实 provider/model 和未过期报价。

## 3. 页面结构与状态

P08：素材列表、累计时长/容量、质量提示、训练模型、实时报价、授权复选框和固定提交按钮。

P09 状态：平台排队、厂家排队、训练中、保存模型、保存配置、试听审核、可用、失败、提交结果不确定、暂不可用。

不提供取消。离开按钮只退出等待页，服务端任务继续。

## 4. 请求与恢复

创建请求包含 voiceId/profileVersion、素材 IDs、真实 provider/model/modelOptionId、pricingVersion、qualityWarningConfirmed、授权版本和 idempotencyKey。

创建成功后立即持久化平台 taskId，再跳 P09。App 通过该 ID 查询详情；本地 ID 丢失时重新打开音色详情获取关联训练状态，不调用不存在的 active 接口。

## 5. 成功定义

只有后端返回音色模型版本 AVAILABLE，且平台试听资源能够实际开始播放、播放进度增长，正向流程才通过。厂家返回成功、模型 ID 存在或试听 URL 200 均不能单独算成功。

## 6. Controller 行为

- 独立 submitBusy 和 poll epoch。
- 轮询间隔由 config 提供，失败有限退避；前后台切换暂停/恢复。
- 终态停止轮询并刷新音色、积分和资料详情。
- 报价过期刷新模型和价格，保留素材/授权输入但重新确认提交。
- 幂等重试返回原任务时直接恢复，不重复弹扣费成功。

## 7. 实现步骤

1. 实现素材汇总、风险告警和提交门禁。
2. 接入训练模型与报价、会员/积分回跳。
3. 创建幂等任务并保存 taskId。
4. 实现 P09 状态映射、阶段进度、错误和离页恢复。
5. 接入受控试听，验证可播放后刷新音色 AVAILABLE。
6. 实现失败重训入口，返回 P04/P08 并生成新任务/幂等键。

## 8. 定向测试

- 素材不足、超限、审核中/拒绝、质量阻断/告警。
- 非会员、积分不足、报价过期、模型停用。
- 双击提交、网络超时、幂等返回旧任务。
- App 切后台、杀进程、重新登录后恢复。
- 训练失败释放积分后的余额刷新。
- 试听无法播放时不显示完成验收。

## 9. 验收标准

- 每次训练都有独立授权确认和价格快照。
- 页面不自行把超时或厂家成功推断为 AVAILABLE。
- 试听来自平台持久化资源，厂家临时 URL 不进入持久状态。
- 训练完成、失败和重训的返回路径明确，草稿不串账号。

## 10. 编码注意事项

不要把音色资料状态、训练任务状态和模型版本状态压成同一枚举。`SUBMIT_UNKNOWN` 只显示运维处理中，不自动再次调用厂家。
