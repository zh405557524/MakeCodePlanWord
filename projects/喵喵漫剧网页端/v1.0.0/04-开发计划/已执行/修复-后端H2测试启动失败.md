## 1. 背景（为什么要改）

- 后端测试用内存数据库 H2（`src/test/resources/application-test.yml`，`MODE=PostgreSQL`），每个 `@SpringBootTest` 启动时先由 Flyway 把所有迁移执行一遍。
- 同事提交的 `src/main/resources/db/migration/platform/V4.20__ai_worker_execution.sql`（2026-11-09、11-11，作者 zh405557524）用了 PostgreSQL 专有写法：`TIMESTAMPTZ`、`JSONB`、`'{}'::jsonb`、带 `WHERE` 的部分索引。H2 执行到第 2 行报 `Unknown data type: "TIMESTAMPTZ"`，Spring 启动失败。
- 结果：所有不带环境变量开关的数据库测试都失败（包括和 M01 无关的 `CommonRequestHeaderIntegrationTests`）。线上和本机用真实 PostgreSQL，不受影响。
- 项目已有先例：`application-test.yml` 里 `catdrama: ""`，漫剧 schema 因为 PG 专有写法在公共 H2 回归里整块不创建，由真实 PG 夹具测试（`CATDRAMA_TEST_POSTGRES_URL`）验证。本次照同样思路处理 platform。
