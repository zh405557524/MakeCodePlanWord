## 1. 执行说明

### 1.1 优先级

- `P0`：主链路阻断、资金/积分、数据丢失、崩溃。
- `P1`：核心功能错误、入口不可用、状态不一致。
- `P2`：次要功能、视觉、容错和体验问题。

### 1.2 建议测试数据

| 数据 | 要求 |
|---|---|
| 游客设备 | 未登录、可重置隐私授权 |
| 普通账号 | 有手机号、积分小于一次生成价格 |
| 创作账号 | 积分大于 300，至少一首已完成作品 |
| 作品数据 | 生成中、生成失败、已完成各 1 条 |
| 歌词数据 | 有时间轴、无时间轴各 1 首 |
| 翻唱音色 | 至少 2 个启用、1 个禁用，1 个有试听音频 |
| 本地音频 | 合法 30 秒 MP3；小于 6 秒；大于 6 分钟；大于 50MB；不支持格式 |
| Provider | Mock 成功、Mock 失败、真实 MiniMax 各一套 |

### 1.3 当前差异判定

- 首页“AI写歌”进入专业模式，“改编歌曲”进入歌曲改编模式；用例据此执行。
- 场景写歌和简易模式代码存在但首页不可达，不伪造首页入口。
- AI 翻唱版权确认必须作为门禁。当前代码未正确实现时，该用例应失败并登记缺陷。
- 当前作品页只显示“我的音乐”，不要求出现专辑、草稿或喜欢 Tab。
