## 使用原则

- 后续 PRD、Figma 计划、Flutter 技术文档引用页面时，优先使用本目录中的文件名。
- 若页面功能描述与截图局部状态不一致，以需求文档中定义的主流程为准。
- 同一模块如存在顶部、中部、底部拆图，应理解为同一页面的滚动状态或局部区域，不视为独立页面。
- 移动端落地时需要重新处理导航、列表、操作区和左右分栏布局；现有宽屏里的左侧列表、中心预览、右侧参数区可拆为上下结构、底部面板、抽屉或分步页面。
