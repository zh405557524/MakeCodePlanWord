| 维度 | 本次覆盖 |

| 4090D 连本机后端 | 用户开的 ngrok 隧道（服务器上 `service/config/application.yml` 已指向它） |

公共约定：

- **后台接口登录**：
  - 先调 `POST http://127.0.0.1:8080/api/admin/auth/login`：
    - 请求头 `Content-Type: application/json`、`X-App-Code: narrate`；
    - 请求体 `{"username": $ADMIN_TEST_USER, "password": $ADMIN_TEST_PASSWORD}`。
  - token 在返回的 `data.accessToken`。
  - 之后的请求都带 `Authorization: Bearer <token>` 和 `X-App-Code: narrate`。
  - 返回的外层是 `{code, message, data}`。
- **建任务**：`POST /api/admin/ai-worker/tasks`。
  - 请求体和后台页面发的一样：`requestId`（每次新的唯一值）、`targetNodeId`、`targetGpuId`（可选）、`modelId`（逻辑模型名）、`kind`、`operation`、`prompt`、`systemPrompt`（可选）、`lyrics`（可选）、`parameters`（只放要测的参数）、`inputs`（`[{assetId, role}]`）。
  - **同一节点一次只能有一个任务**：上一个结束前不要提交下一个，否则会被“目标节点当前不可提交”挡住。拒绝用例也要在节点空闲时做。
- **查任务**：每 15 秒查一次 `GET /api/admin/ai-worker/tasks/{taskId}`，直到 `state` 为 `SUCCEEDED`、`FAILED` 或 `CANCELLED`。
  - 出现 `RECOVERY_REQUIRED` 时停止等待，按失败记录。
  - 单个任务最多等 45 分钟，超时记“超时”，**不取消、不重提**。
- **取产物**：`POST /api/admin/ai-worker/tasks/{taskId}/outputs/{artifactId}/access-url?download=true`，`data` 是下载地址，下载到 `evidence/`。
- **上传参考图**（三步）：
  1. `POST /api/admin/ai-worker/assets/upload-ticket`，请求体 `{"contentType":"image/png","sizeBytes":…,"sha256":"<十六进制>","contentMd5Base64":"<MD5 的 Base64>"}`，素材编号在 `data.assetId`；
  2. `POST /api/admin/ai-worker/assets/{assetId}/content`，multipart 字段名 `file`；
  3. `POST /api/admin/ai-worker/assets/{assetId}/complete`。
- **查库**：`psql -d lxwx_service`。
  - 节点表 `platform.ai_worker_nodes`：`node_id`、`protocol_version`、`capability_version`、`capabilities`（JSON，能力在 `models` 数组里）。
  - 任务表 `platform.ai_worker_tasks`：`task_id`、`model_id`、`request_payload`、`capability_snapshot`、`state`。
- **核对媒体**：
  - 图片用 `sips -g pixelWidth -g pixelHeight`；
  - 音频用 `afinfo`；
  - 视频用 `ffprobe`，没有就用 `mdls -name kMDItemPixelHeight -name kMDItemPixelWidth -name kMDItemDurationSeconds`，都不行就记“未核对”。
- 调接口可以写临时脚本放 `evidence/scripts/`，文件名带用例号。脚本里不写账号和 token，只从环境变量读。
