# CHG-0026 Web/Admin 首页列表开发计划

> 路径恢复：2026-07-31 从错误工作区别名 `catsinger` 迁入；本文 CHG 已按 `旧编号 + 14` 重编号，原文保存在 `archive/path-recovery-20260731/`。

## 页面改动

- 模块标签表格和表单移除展示模式，持久化标签的 tagCode 只读。
- 新增首页列表区，展示标签、状态、展示数量、已选数量、来源与配置操作。
- 配置弹窗仅列出同标签歌曲，支持加入、移除、上下排序和 1-100 数量校验；允许空列表。
- 歌曲配置增加“全部 + 标签”切换，当前筛选标签作为新增歌曲默认标签。

## 分层

- `AdminApiClient` 封装 GET/PUT 首页列表接口。
- `AdminRepository` 保存列表状态、操作日志、App 切换清理和通知。
- `AdminSongHomeListConfig` 负责解析与请求载荷。
- `SongConfigPage` 只维护筛选、弹窗和提交反馈。

## 测试

- Repository：加载、覆盖保存、请求路径/载荷、App 状态清理。
- Widget：展示模式消失、标签筛选、候选限定、排序、空列表、数量校验、保存失败和新增歌曲预选标签。
