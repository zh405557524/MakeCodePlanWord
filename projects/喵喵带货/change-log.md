# 喵喵带货 研发变更日志

> 本文件按研发版本累计记录已完成的 CHG。当前为初版需求评审阶段。

## 版本号规则

- `patch++`：局部修改、缺陷修复、文案或资源调整。
- `minor++`：新增功能或模块，且无破坏性。
- `major++`：架构调整、不兼容改动或推翻重做。

## v1.1.0 AI 流程与提示词后台改造 - 2026-08-24

> 关联变更：CHG-0055

### Added

- 图片/视频理解单次调用直接返回可见事实、结构信息和候选卖点，分析缓存升级为 v2。
- 用户确认卖点后，`/api/catseller/works/{workId}/script-tasks` 单次文本模型直接生成标题、时长和完整分镜。
- 新增探店内部视频类型 `store_visit`、Catseller 业务配置 v7 及 v6→v7 迁移。
- 新增 `/api/admin/ai-prompts/**` 目录、草稿、预览、发布、版本恢复、真实输入、调试、执行记录和轮询接口；Admin 展示图片、视频和分镜结构化调试结果。
- 新增通用迁移 `V3.12__ai_prompt_management.sql`，保存提示词状态/版本、正式执行快照、调试任务与视频分段记录；`V3.11` 已被既有迁移占用。

### Changed

- 分镜工作流改为“检查资源 → 输入审核 → 直接生成分镜 → 保存草稿 → 发布结果”；`scriptText` 由镜头口播确定性拼接。
- 商品只使用原 8 种类型；探店服务端固定 `store_visit` 且公共接口严格隐藏；爆款复刻不使用视频类型。
- 代码默认提示词作为兜底，数据库发布版本仅影响新任务；草稿只在后台预览和显式调试中生效。
- Admin 移除“生成卖点”“生成内容脚本”阶段，把“规划视频分镜”改为“直接生成分镜”，并从商品默认类型下拉排除 `store_visit`、禁止停用该内部类型。

### Removed

- 移除 `seller.selling-points.generate.*`、`seller.content-script.generate.*` 及对应业务类型、AI 场景和模型绑定。
- 移除原 8 种商品类型对应的探店视频类型规则，只保留 8 个 `product_video` 规则和一个 `store_visit.store_video` 规则。

### Preserved

- 不修改 Catseller 既有业务表、Entity 字段或历史作品数据；现有脚本版本、镜头、人物、分镜图片和视频生成能力继续使用。
- 调试不创建正式作品、不修改正式缓存、不产生用户积分订单；Flutter 用户端本次不修改。

### Verified

- 后端业务与提示词接口测试、OpenAPI 契约、Admin 结构化结果和 8+1 类型测试已覆盖；正式真实 Provider、双端用户链路仍按 QA 计划执行。

## v1.0.1+102 iOS 游客账号与订阅恢复 - 2026-08-12

> 关联变更：CHG-0045

### Added

- iOS 登录页增加“游客继续（无需手机号）”“手机号登录”和主动“恢复购买”；`catseller` Keychain 游客凭证恢复同一正式 `userId + JWT`。
- 新增游客会话、可选绑定未注册手机号和 Apple 自动续订订阅恢复；所有新用户创建时统一获得一次 30 积分，游客绑定手机号不重复发放；游客可填写商品、生成脚本、购买积分/会员、合成视频并查看自己的作品和记录。
- “我的”、设置和会员页增加游客身份、可选绑定和恢复入口。

### Changed

- 恢复页面真实登录拦截并移除 `LoginService.ensureLoggedIn` 固定成功逻辑；路由拆分为 sessionRequired 与 registeredRequired。
- Apple 待确认订单增加 `ownerUserId`，主动恢复先处理当前账号本地订单，未匹配有效订阅才恢复原购买游客；消耗型积分不可由 App Store 恢复。
- Android 继续使用现有手机号登录，不展示游客入口；沿用现有视觉组件，未新建独立设计体系。

### Preserved

- 保留 CHG-0044 尚未提交的作品详情、分镜编辑、视觉 QA、测试资源及 `lib/apis/catseller.dart` 重叠改动。

### Verified

- 后端游客专项、Apple 恢复验真、限流、手机号状态和 OpenAPI 契约测试通过；Flutter `flutter analyze`、游客专项与两条真实路由门禁定向测试通过。
- 新用户积分规则已统一为创建 `userId` 时一次性发放 30 积分；游客恢复及绑定手机号均不新增积分流水。
- catseller iOS Simulator Debug 构建通过。
- 全量套件仍保留已登记的既有页面文案/路由断言基线，本次新增游客专项无失败。
