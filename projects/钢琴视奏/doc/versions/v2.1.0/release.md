## 2. 本版内容（相对 v2.0）

完整需求见 `doc/product/`。主要变化：

- 产品文档合并为一份总纲 + 九份模块分册（v2.0.0 基线 + v2.0.1 智能曲谱导入 + 工程现有能力补全）
- 付费模型调整：内容等级和会员分离；会员只解锁非免费歌曲的 MIDI 钢琴练习；手机歌曲练习（含 MIDI）、音符、视奏、和弦、导入都免费；免费体验歌曲
- 智能曲谱导入与个人曲谱（MIDI / 图片 / PDF，本地 Worker 识别，校对，统一资源保护）
- 账号绑定模型：独立本地账号、用户名注册、Google、游客及游客升级，按账号隔离数据
- 练习完成后的应用商店评价邀请
- 订单记录、曲目收藏、预设头像
- 会员商品统一为 VIP 编码（月 / 季 / 年卡，预付）；Google Play 支付与退款
- 练习音效、MIDI 默认输入、横屏适配、和弦与歌曲练习判定统一

处理规则：

- 被拒原因暴露出的检查项，补进 `doc/testing/risk-checklist.md` 和 `workflow/参考/首次上架清单.md`。
