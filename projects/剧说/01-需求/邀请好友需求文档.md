## 1. 需求目标

新增完整的邀请好友业务闭环，让用户可以通过邀请链接或 App 内邀请码建立邀请关系，并围绕邀请关系获得注册积分、会员返佣、收益查询和提现能力。

本轮需求覆盖：

- 邀请链接注册，注册成功后展示 App 下载地址。
- App 内绑定邀请人，一个账号只能绑定一次。
- 好友注册后给直接邀请人发放积分。
- 好友首次开通会员后给直接邀请人产生现金收益；符合后台特殊配置的上级可获得一层间接收益。
- 用户可查看邀请列表、我的收益、收益明细、提现和提现记录。
- 后台可配置邀请规则、查看提现申请并处理审核 / 驳回 / 打款状态。
- 后端提供简单公开邀请落地页。

本轮不覆盖：

- 新 Figma UI 生成。
- 工时评估。
- 真实支付宝打款 SDK 接入。
- 编码、迁移脚本、构建或测试。

## 2. 用户角色

| 角色 | 诉求 |
|------|------|
| 邀请人 | 获取邀请码、推广链接和推广素材，查看好友注册、会员开通收益并提现 |
| 被邀请人 | 通过邀请链接注册，或在 App 内手动绑定邀请人 |
| 后台管理员 | 配置邀请奖励规则，审核提现申请，记录打款状态 |

## 4. 核心流程

### 4.1 邀请链接注册

1. 邀请人复制或分享邀请链接。
2. 被邀请人打开 `/invite/{inviteCode}` 公开落地页。
3. 落地页展示邀请信息和手机号注册 / 登录入口。
4. 被邀请人完成登录或注册。
5. 后端自动绑定邀请关系。
6. 注册成功后展示后台配置的 App 下载地址。
7. 后端按配置给直接邀请人发放注册送积分，默认 `10` 积分。

### 4.2 App 内绑定邀请人

1. 登录用户进入“绑定邀请人”页面。
2. 用户输入邀请码并提交。
3. 后端校验邀请码是否存在、是否自邀、当前账号是否已绑定。
4. 校验通过后绑定邀请关系。
5. 绑定成功后页面展示已绑定状态，入口不可重复绑定。

### 4.3 会员返佣

1. 被邀请人首次购买会员商品并支付成功。
2. 支付回调确认订单到账。
3. 后端判断订单是否为会员商品，且是否为该被邀请人的第一次开通会员。
4. 后端为直接邀请人生成直接返佣，返佣比例取决于直接邀请人的个人代理等级。
5. 如存在上一级邀请人，且该上一级用户已由后台开启“间接收益资格”，后端额外生成一层间接返佣。
6. 收益写入收益明细，并增加可提现收益。

会员返佣只针对被邀请人的首次开通会员订单；以后续费 / 再次开通会员、充值积分都不再产生返佣。

### 4.4 代理等级与关系层级

为避免概念混淆，本文档固定使用以下两个概念：

| 概念 | 含义 | 影响 |
|------|------|------|
| 个人代理等级 | 用户自己的代理等级，分为 1 级、2 级、3 级 | 只影响“直接邀请收益”的返佣比例 |
| 关系层级 | 用户之间的邀请链路距离，例如 A->B 是直接关系，A->B->C 中 A 对 C 是间接关系 | 只影响是否可以拿直接收益或间接收益 |

直接邀请示例：A->B。

- B 注册后，A 获得 `10` 积分。
- B 第一次开通会员后，A 获得直接邀请收益。
- A 的个人代理等级为 1 级时返 `10%`，2 级时返 `20%`，3 级时返 `30%`。
- B 以后续费会员、再次开通会员或充值积分，A 都不再获得返佣。

间接邀请示例：A->B->C。

- C 注册时，A 没有注册送积分。
- C 第一次开通会员时，如果 A 已由后台开启“间接收益资格”，A 获得 `10%` 间接收益。
- 间接收益固定 `10%`，不受 A 的个人代理等级影响。

一层限制示例：A->B->C->D。

- D 第一次开通会员时，C 可获得直接邀请收益。
- B 如已开启“间接收益资格”，可获得 `10%` 间接收益。
- A 超过一层间接关系，没有收益。

### 4.5 提现

1. 邀请人进入“我的收益”查看可提现金额。
2. 用户进入提现页，填写支付宝账号和提现金额。
3. 用户勾选合作伙伴协议并提交提现申请。
4. 提现金额从可提现收益中冻结。
5. 后台管理员审核提现申请。
6. 驳回或打款失败时，冻结金额退回可提现收益。
7. 打款成功后，提现记录展示成功状态。

## 5. 业务规则

| 规则 | 需求口径 |
|------|----------|
| 邀请码生成 | 用户注册时生成唯一邀请码；推广链接使用该邀请码作为参数 |
| 绑定次数 | 一个账号只能绑定一个邀请人，绑定后不可修改 |
| 禁止自邀 | 用户不能绑定自己的邀请码 |
| 重复绑定 | 已绑定用户再次绑定时明确提示，不创建新关系 |
| 邀请链接注册 | 邀请码自动带入登录 / 注册请求，注册成功后自动绑定 |
| 注册积分 | 好友完成首次注册并绑定邀请关系后，按后台配置给直接邀请人发积分，默认 `10` 积分 |
| 直接会员返佣 | 被邀请人首次开通会员并支付成功后，按直接邀请人的个人代理等级生成现金收益 |
| 间接会员返佣 | 后台可为特殊用户开启间接收益资格；仅对一层间接关系生效，固定 `10%` |
| 返佣次数 | 每个被邀请人只在第一次开通会员时产生返佣，续费会员、再次开通会员、充值积分都不返 |
| 返佣范围 | 默认只处理直接邀请关系；间接关系需后台单独开启；积分商品不产生现金返佣 |
| 提现渠道 | 本轮按支付宝账号提现 |
| 提现最低金额 | 后台配置，默认 `1` 元 |
| 资金追踪 | 收益明细、提现记录、后台审核记录都必须保留状态和时间 |

## 6. 默认运营配置

| 配置 | 默认值 | 后台是否可改 |
|------|--------|--------------|
| 注册奖励积分 | `10` 积分 | 是 |
| 个人代理 1 级直接返佣 | `10%` | 是 |
| 个人代理 2 级直接返佣 | `20%` | 是 |
| 个人代理 3 级直接返佣 | `30%` | 是 |
| 升级个人代理 2 级条件 | 直邀人数达到 `10` 人；第 `11` 个被邀请人的首次会员佣金按 2 级计算 | 是 |
| 升级个人代理 3 级条件 | 直邀人数达到 `30` 人；第 `31` 个被邀请人的首次会员佣金按 3 级计算 | 是 |
| 间接收益资格 | 默认关闭，由后台按用户开启 | 是 |
| 间接收益比例 | `10%`，仅一层 | 是 |
| 最低提现金额 | `1` 元 | 是 |
| 落地页下载地址 | 占位 URL | 是 |

## 7. 验收标准

- 通过邀请链接注册时，邀请码能自动带入并绑定邀请关系。
- App 内绑定邀请码时，能覆盖无效码、自邀、重复绑定、已绑定状态。
- 好友首次注册后，直接邀请人能获得 `10` 积分，且重复请求不重复发放。
- 好友第一次开通会员并支付成功后，直接邀请人按个人代理等级获得 `10% / 20% / 30%` 现金收益。
- 后台开启间接收益资格的用户，可对下一层间接用户首次开通会员获得固定 `10%` 收益；超过一层没有收益。
- 续费会员、再次开通会员和充值积分不产生返佣。
- 邀请人能查看推广素材、邀请列表、我的收益、收益明细、提现和提现记录。
- 提现申请提交后，App 能展示提现中、提现成功、提现失败状态。
- 后台管理员能配置邀请规则，并处理提现审核通过、驳回、打款成功、打款失败。
- 邀请落地页能完成注册 / 登录，并在成功后展示下载地址。
