# 05 歌曲改编、AI 翻唱与源音频

## 歌曲改编生成通过硬门禁

- 适用于 `ADAPT-009`、`ADAPT-012` 以及后续所有歌曲改编正向生成用例。
- 任务提交成功、进入生成页、作品列表出现生成中条目或后端任务状态变为成功，都不能单独判定 PASS。
- 必须在产品承诺的生成等待时间内取得本次任务对应的目标作品，打开播放器并确认目标音频开始播放、播放进度连续增长至少 5 秒且没有加载或资源错误，才可判定 PASS。
- 任务进入失败/取消、等待超时、目标作品未生成、音频资源字段缺失、资源过期或访问失败、播放器无法开始、播放进度不增长，任一情况均直接判定 FAIL，不得改记为 PASS。
- 执行人员必须记录任务号、作品号、最终任务状态、播放开始和进度增长证据；仅有生成页截图不满足验收要求。
