# V1.2 到 V2.1 用例差异

旧目录只用于追溯，V2.1 不继承旧执行结果。新版统一使用 `V21-模块-序号` 编号；下表是内容映射，不是一对一重命名。

| V1.2 范围 | V2.1 处理 | 新入口 |
|---|---|---|
| `APP/PRIV/UPDATE/AUTH` | 保留用户路径，重新记录实际安装包与 iOS 门禁 | `V21-START-*`、`V21-AUTH-*` |
| `NAV/HOME` | 按新首页海报、三业务卡、新人礼和新用户赠额重写 | `V21-HOME-*`、`V21-GIFT-*` |
| `CREATE/SIMPLE/PROFESSIONAL/AUDIOREF/MODEL` | 保留写歌核心，加入逐模型动态参数、查重、程序化换模静默与指定音色延期 | `V21-SONG-*`、`V21-MODEL-*`、`V21-RESOURCE-*` |
| `ADAPT-*` | 按当前改编页面、保留歌词/新歌词及无权利勾选重写；5 秒可播放门禁保留 | `V21-ADAPT-*`、`V21-GEN-*` |
| `COVER-*` | 旧三步“AI 翻唱”与固定 6 分钟/50MB、版权勾选预期作废；现有业务归“改编”，新业务独立覆盖 | `V21-VOICE-COVER-*`、`V21-VOICE-TRAIN-*` |
| `GEN/WORK/PLAYER` | 三业务任务和作品分离，成功以持久资源可播放判定 | `V21-GEN-*`、`V21-WORK-*` |
| `COMMERCE/GROWTH/PROFILE/NETWORK` | 保留可达用户能力，并补后台配置在 App 的可见效果 | `V21-PAY-*`、`V21-GROW-*`、`V21-PROFILE-*`、`V21-ENV-*` |
| 旧版 P03/P04 指定音色正向场景 | 本期禁止作为正向用例；只验入口未开放、请求无该参数 | `V21-SONG-013`、`V21-ADAPT-011` |

代码中存在但当前用户无入口的历史场景四步、旧专辑主 Tab、独立指定音色路由、旧视频创作等只记为“不可达”，不编造正常用户点击路径。未来版本开启指定音色时再单独建立需求、测试数据与正向用例。
