## 1. 功能定位

后台管理需要让运营配置翻唱模型、音色和查看翻唱作品。本模块属于 Web/Admin 前端，不改用户端 App 页面。

## 2. App 切换

- 后台继续支持 App 切换。
- 选择 `catsinger` 后展示 AI 翻唱配置。
- 非 `catsinger` App 默认隐藏翻唱配置菜单，后续可配置化开放。

## 3. 翻唱模型配置页

字段：

| 字段 | 说明 |
| --- | --- |
| 模型名称 | 例如 `MiniMax music-cover` |
| provider | `minimax` |
| model | `music-cover` |
| 消耗积分 | 默认 `150` |
| 是否启用 | 控制用户端是否可选择/提交 |
| 排序 | 多模型预留 |

操作：

- 新增。
- 编辑。
- 启用/停用。
- 删除前二次确认。

## 4. 翻唱音色配置页

字段：

| 字段 | 说明 |
| --- | --- |
| 名称 | 用户端音色卡标题 |
| 分组 | 男声、女声、二次元、特色 |
| 标签 | 展示在卡片上的短标签 |
| 头像/图标 | 音色卡视觉 |
| 试听音频 | 用户端试听 |
| 提示词模板 | Provider 调用时使用 |
| 启用状态 | 停用后用户端不展示 |
| 排序 | 分组内排序 |

操作：

- 上传试听音频。
- 新增/编辑/删除。
- 启用/停用。
- 拖拽或数字排序。

## 5. 作品管理扩展

- 筛选条件增加 `作品类型`：全部、原创、翻唱、纯音乐。
- 翻唱作品列表显示：

  - 目标音色。
  - 消耗积分。
  - 任务状态。
- 详情页显示翻唱参数和资源持久化地址。
