# 高风险领域必测清单（钢琴视奏）

> 用法：版本 `scope.md` 勾选本版碰到的领域，测试时把对应领域的每一条转成用例或检查项，结果写进 `test.md`。
> 维护：每个线上 bug 修完，想一想它属于哪一类，把"当时没测到的维度"加到对应领域，并在文末「项目历史问题」登记来源。
> 2026-10-07 迁移时由工作台模板生成，并补入本项目 v2.1.0 开发和上线期间出过的问题。

## 支付与订阅
- [ ] 至少两个不同币种的地区各完整购买一次（例如美区 + 欧元区 / 巴西区）
- [ ] 价格显示使用商店返回的本地化价格，不是写死的示例价
- [ ] **订单记录的币种、金额与商店实际扣款一致**（App 展示、接口、数据库、后台逐环核对）
- [ ] 商品加载失败、商店不可用时，不会用默认价格下单
- [ ] 购买成功但回调失败 / 网络中断：权益最终到账，订单不重复
- [ ] 恢复购买、换设备、重装后权益正确
- [ ] 续订、到期、取消、退款后的权益变化
- [ ] 沙盒与正式环境的差异（收据校验地址、商品 ID）
- [ ] 订单时间的时区
- [ ] 商店查询失败（例如 Google BillingClient 网络错误）时提示网络问题，不误报"商店未配置"
- [ ] 在商店付款界面取消后，App 很快恢复可操作，不长时间停在等待状态
- [ ] Apple 真机购买、Google 各档方案、退款生命周期各走一遍（沙盒 / 许可测试）

## 账号与身份
- [ ] 游客、注册、第三方登录三种身份的进入和切换
- [ ] 游客升级为正式账号时数据的归属与合并
- [ ] 切换账号后，上一个账号的本地数据、会员状态、订单不残留
- [ ] 删除账号：二次确认、服务端数据处理、重新注册同一邮箱
- [ ] Token 过期、被踢下线、多设备同时登录
- [ ] 迟到的接口响应不会写进已切换的账号

## 会员与权益
- [ ] 免费 / 付费边界逐个入口验证（包括直达链接、续练、深层入口）
- [ ] 会员到期瞬间正在使用付费功能时的表现
- [ ] 离线时的权益判断（使用缓存时长、过期策略）
- [ ] 服务端也做权益校验，不只依赖客户端判断

## 时间与时区
- [ ] "每日限制""自然日"在不同时区的边界（午夜前后）
- [ ] 手机时间被手动修改
- [ ] 夏令时切换

## 多语言与本地化
- [ ] 每种支持语言下的长文案不溢出、不截断关键信息
- [ ] 数字、日期、货币格式随地区变化
- [ ] 系统语言不在支持列表时的回退语言

## 数据同步与离线
- [ ] 离线操作后恢复网络，数据正确上传、不重复
- [ ] 两台设备同时修改同一数据
- [ ] 本地数据库升级（老版本升级到新版本后数据还在）
- [ ] 大数据量下的列表和同步

## 权限与隐私
- [ ] 首次启动先展示隐私协议，同意前不初始化收集数据的 SDK
- [ ] 每个系统权限：拒绝、永久拒绝、之后在系统设置里开启
- [ ] 日志和崩溃上报里没有个人信息

## 升级与兼容
- [ ] 旧版本 App 访问新版本后端接口不出错
- [ ] 服务端数据库迁移对存量数据的处理
- [ ] 强制升级 / 提示升级的逻辑

## 设备与界面
- [ ] 小屏、大屏、平板（如果支持）、横竖屏切换
- [ ] 系统大字体、深色模式
- [ ] 应用切到后台、来电、锁屏后回来，状态正确
- [ ] 外接设备（蓝牙 / USB）连接、断开、重连（如果有）

## 练习、判定与进度（本项目）
- [ ] 中途停止、零题停止、切后台中断：不计为完成，不计入每日目标和成绩
- [ ] 每日目标为空或为 0 时的显示（不出现 0/0 这类无意义进度）
- [ ] 首页、"我的"、进度页显示的等级一致（未通过显示 Lv0）
- [ ] 手机、钢琴、和弦三种练习的判定口径一致（见 `doc/product/09-练习方式统一规范.md`）
- [ ] 同一安装重启后，进度、等级、断点保持

## MIDI 与音频设备（本项目）
- [ ] 进入练习前已连接设备可以直接弹奏；练习中断开、重连
- [ ] USB 与蓝牙 MIDI 各测一遍；拒绝蓝牙权限后 USB MIDI 仍可用
- [ ] 只在用户主动扫描蓝牙设备时申请蓝牙权限，进入页面不主动申请
- [ ] 外接 MIDI 键盘时 App 发声与键盘本身发声不重复
- [ ] **必须用实体 MIDI 琴验收**，模拟器结果不能代替

## 曲谱导入（本项目）
- [ ] 导入完成后返回列表，列表立即刷新出新曲谱
- [ ] 统一资源保护的边界：并发 2、每小时 10、每自然日 30（以后端 `app-configs.json` 为准），自然日按用户时区
- [ ] 识别失败、取消、重试、删除后释放名额
- [ ] 大文件、多页 PDF、模糊图片、非曲谱图片

## 后端多 App 共用（本项目适用：service 同时服务多个 App）
- [ ] 改动不影响其他 App：按 App Code 隔离的配置、数据、接口
- [ ] 跑其他 App 的相关测试
