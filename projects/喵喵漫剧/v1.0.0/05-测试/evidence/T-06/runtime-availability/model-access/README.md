创作入口先要求前三个文本场景。每个模型需明确 `sceneCode/capabilityType/providerCode/modelCode/modelName/paramsJson/chargeItemCode/enabled`；Provider须启用，模型必须为该通道真实可调用型号。三个创作文本计费项初始均为零积分。描述帮写有独立场景，但默认计费文件没有同名计费项，须核对现有零积分项或通过管理端补齐独立免费项，不能凭场景名直接提交不存在的计费编号。

图片/视频还需要 `drama.production` 的真实能力组合、规格、参考图数量、版本和默认参数；视频必须含声音，并有同组合的样片验收依据。字幕需要可恢复识别的 AUDIO 模型和 `drama.subtitles`，不以普通同步识别模型冒充可恢复任务。当前没有自行选定或启用任何型号。
