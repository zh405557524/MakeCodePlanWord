## 9. CHG-0056 生成同款风格映射

- 写歌路由通过 `extra` 接收完整 `SongWorkDetail`，专业模式先写入基础字段，风格等待 `SongGenerationOptions.styleCategories` 加载完成后一次性映射。
- 快照风格优先；快照为空时，仅从结构化“音乐风格”引导词与详情 `styleTags` 降级。映射目标始终是当前启用选项的 `value`，不得直接展示 Provider 英文结果标签。
- 匹配顺序为 `code/label/value` 精确匹配、英文词组与配置 code 匹配、固定旧标签别名；`Male/Female Vocal` 转为人声参数。未知或禁用项丢弃并复用一次性降级提示，不调用 AI。
- 通用标签解析不得以空格分词；普通专业入口仍可手动添加自定义标签，过滤规则只用于自动“生成同款”回填。
