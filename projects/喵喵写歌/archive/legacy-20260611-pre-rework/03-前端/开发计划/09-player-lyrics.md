# 播放与歌词模块开发文档

> 关联任务：T-F013

## 1. 功能定位

播放歌曲、展示歌词、下载和分享作品。播放器 UI 需保持深色音乐感，并与新设计稿的底部 Tab/迷你播放器风格一致。

## 2. Song 模式

- 顶部返回、Song/Lyrics 切换、PRO 入口
- 大唱片封面，播放时旋转
- 歌曲名称、曲风、创作者
- 进度条和时间
- 上一首、播放暂停、下一首
- 下载、分享、收藏、重新生成

## 3. Lyrics 模式

- 背景为封面高斯模糊
- 当前歌词高亮加粗
- 已播放歌词降低透明度
- 未播放歌词灰色
- 支持复制歌词

## 4. 数据

- `audioUrl` 必须为后端自有资源地址
- `lyricTimeline` 存在时逐句高亮
- 时间轴缺失时静态歌词展示

## 5. 验收

- [ ] 音频可播放/暂停
- [ ] 进度条和时间同步
- [ ] 歌词逐句高亮
- [ ] 下载请求后端 download-url
- [ ] 分享入口是真链路或明确接后端分享接口
