## 1. 厂家契约对账

厂家文档：`https://docs.qq.com/doc/DSUhISlNOWFNrQ1Bw`。

- 音色训练任务使用真实厂家类型 `sovits_train`，提交 `input_urls`、`model_name`，并按能力选送 `description`、`avatar_url`、`train_mode`。
- 翻唱声音克隆任务使用真实厂家类型 `sovits_cover`，必填 `input_url`、`model_id`、`model_url`、`config_url`，按模型能力选送 `pitch`、`output_format`、`vocal_volume`、`accompaniment_volume`。
- 任务查询路径与代码一致：`GET /api/midjourney/drawInfo4?id={providerTaskId}`。
- 厂家结果包含 `download_url`、`download_expires_at`、`retention_days`、`download_expired`、`media_type`、`output_format` 等字段。平台不得把厂家临时地址直接当成最终作品。
- 当前 Java 适配器与上述字段一致；平台下载结果后按实际文件头纠正扩展名和 MIME，作品音轨快照也以转存后的真实格式为准，再使用 `ffprobe` 校验音频可解码与真实时长。只有转存、审核和可播放检查完成后才可形成成功作品。

## 5. 未通过与发布门禁

- 当前运行环境没有可用的算道 Token / Provider Account，`song.voice.train` 与 `song.voice.cover.generate` 也没有形成可用场景模型映射和计费项。
- 因此真实音色训练、厂家接单、十分钟处理截止、结果下载、资源持久化、成品审核、积分结算和最终播放进度递增均未执行，状态为 BLOCKED/NOT_RUN，不能记为 PASS。
- Java 旧 15 条回归失败已完成修复并由本轮全量 1956 项回归覆盖，不再是发布阻塞项。
- Flutter 历史 Widget 测试文件的损坏中文断言仍需独立清理；这不影响本轮 22 项定向测试结论，但发布回归不能因此标为全量通过。
- 发布前必须用真实测试配置完成：训练成功并得到可用音色版本；整曲翻唱成功；厂家临时 URL 已转存；Android/iOS 播放器可打开；播放位置持续递增；失败链路释放积分。
- 后台普通账号、角色与管理块分配代码及定向测试已经存在；仍需在真实 Admin 运行环境切换账号验证菜单可见性和接口授权。

## 6. UI 审计结论

- 页面结构和跳转满足当前要求：创建音色说明 -> 音色资料 -> 本人验证/素材 -> 训练；翻唱主页支持作品来源、音色库、模型设置、歌曲授权和提交。
- 375x812 首页、登录、翻唱主页、系统文件选择器和创建音色结构可用；Android 长屏固定提交区无覆盖。
- 当前实现不是像素级复刻。创建音色头图使用现有圆形麦克风视觉，Figma 为点阵声波；此差异不影响结构和交互，但如后续要求视觉 1:1，应另开纯视觉返工项。
- 当前 Figma 通道 `otj95h0j` 已成功加入，但读取文档和选择节点连续超时；本轮只用项目内已归档的当前 V2.1 导出图作视觉对照，不能宣称完成了在线 Figma 像素级比对。
