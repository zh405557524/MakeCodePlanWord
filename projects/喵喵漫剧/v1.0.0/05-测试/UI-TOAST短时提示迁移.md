## 实现结果

- 操作回执、选择超限和提交校验通过现有 CustomToast 反馈；输入过程中不创建校验错误行，提交时只提示首个错误，不丢输入。
- 表单仅因字段非法而禁用的入口可点击校验；忙碌、权限、任务锁、冲突和模型不可用等业务禁用条件保留。
- 作品/资产/素材/镜头的持续状态与普通操作错误分开。草稿写盘失败、版本冲突、候选到期、生成/审核失败、原键待核实及恢复入口保留。
- 图片保存明确结果和缓存清理结果移到浮层；相册写入未知、缓存读取失败、支付待确认和到账刷新异常继续显示真实状态。订单操作错误不再覆盖列表读取错误。
- 签到/领取已有专属回执，清除重复成功行；报价反馈由报价/确认动作收尾触发，不再监听混合状态字段重播提示。
- 接口、数据结构、计费和幂等契约未修改；未部署、未执行真实生成或真实支付。
