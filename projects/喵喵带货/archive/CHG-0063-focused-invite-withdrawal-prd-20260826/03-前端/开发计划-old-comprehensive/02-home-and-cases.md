# Flutter 模块开发文档：首页与更多案例

> 版本：`v1.0`｜状态：待评审｜任务：`T-F002 首页`、`T-F003 更多案例`

## 1. 功能定位与边界

实现首页主入口、四个“敬请期待”入口、案例展示、无筛选更多案例和案例视频预览。首页游客可看；更多案例和案例详情属于二级业务，进入前登录。“生成同款”本版只提示下版本，不创建作品。

## 2. 入口、路由与页面文件

- `/`：首页 Tab，`lib/pages/home/{index,controller,view}.dart`。
- `/seller/cases`：更多案例，新增 `lib/pages/home/cases/`。
- `/seller/cases/:caseId` 或页面内详情：案例预览，按最终 UI 选一种，路由名保持唯一。
- 使用 `SellerHomeController`、`SellerCasesController`、`SellerCaseDetailController`。

## 3. 依赖前置

- 依赖主页面框架、SellerAPI/Model。
- Java：`GET /api/catseller/home`、`GET /api/catseller/cases`、`GET /api/catseller/cases/{caseId}`、`GET /api/catseller/config`。
- 首页 UI 已完成；更多案例作为最后一个新增页面实现。

## 4. 视觉参考与设计稿分析

![首页参考图](../../01-需求/references/images/01-首页.png)

从上到下：品牌/头像 → 营销标题 → 一键生成卡片 → 四个扩展入口 → AI 案例与更多案例。目标版本增加三个 Tab；删除独立配音/字幕业务暗示；案例分类标签不作为筛选功能。更多案例是与作品列表相似的无筛选列表。

## 5. 涉及模块与类

| 类 | 职责 |
|----|------|
| `SellerHomeController` | 首页聚合、配置、刷新和入口点击 |
| `SellerCasesController` | 无筛选游标分页、下拉刷新 |
| `SellerCaseDetailController` | 案例详情、视频播放和下线处理 |
| `SellerHomeData/CaseSummary/CaseDetail` | 首页与案例模型 |

## 6. 业务内容与数据流

- 首页启动并行加载公开配置和首页聚合；失败时主创作入口仍显示，案例区提供重试。
- “立即生成/上传商品图”先走隐私和登录，再进入填写信息。
- 四个扩展入口统一展示“敬请期待”，不请求接口。
- “更多案例”登录后请求无筛选分页；重复进入复用缓存并后台刷新。
- 案例下线返回可理解空态；AI 案例根据 `aiGenerated` 显示前端水印。
- “生成同款”展示“下版本开放”，不复制参数、不建草稿、不扣积分。

## 7. 现有工程参考点

## 12. 2026-08-14 案例预览播放增量

- 首页案例展示项把接口 `caseId / videoResourceId / videoUrl` 传入预览页；有资源 ID 时通过现有 `ResourceService` 调用临时地址接口并写入统一视频缓存，不新增后端接口或依赖。
- 视频首次点击时先换签、下载缓存，再使用本地文件播放器播放；播放中点击暂停，播完再次点击从头播放，加载失败保留封面并提供点击重试。
- 有视频来源时复用作品详情 `AppAiGeneratedWatermark(compact: true)`，固定在视频内容区右下角 8px；播放、暂停、加载和失败状态均保持可见，无视频占位不显示。
- 旧案例缺少资源 ID 时使用按 `HttpService` 基址补全后的 `videoUrl`，以 `home-case-{caseId}` 作为稳定缓存键；资源 ID 存在时不得使用可能失效的旧 URL。
- App 进入后台时暂停，离开页面时移除监听并释放播放器；无视频地址的占位案例只展示封面，不提供无效播放入口。
- 案例预览与资源服务合计 16 项测试、`flutter analyze` 与差异检查已通过；任务保留 `in_progress`，等待 Android/iOS 真机验证首次下载、画面、声音、弱网重试与前后台切换。

## 13. 2026-08-21 iOS 首次联网授权后首页恢复增量

- `HomeController` 监听 App 生命周期并在关闭时注销；只在 iOS 观察到 `inactive → resumed`、首次首页请求失败、分类与案例均无可用数据、当前无请求且重试名额未消费时调度恢复。
- 首页仍在 `onInit` 启动即请求；iOS 首次失败先维持 loading 并进入 500ms 宽限期，不立即展示错误区或 Toast。系统授权进入 `inactive` 后不受宽限期时长影响，弹窗停留期间持续隐藏错误。
- 自动恢复延迟 300ms，复用原 `/api/catseller/home` 加载链路并最多执行一次；同时兼容系统弹窗先关闭、首次请求稍后才返回失败的竞态。
- 自动重试成功后沿用现有 loading 与数据赋值并清除错误；再次失败保留现有错误区和手动重试入口，但不重复 Toast。未发生授权生命周期时，500ms 后恢复原错误和 Toast，避免真实断网永久 loading；手动重试、切回首页刷新及后续加载不变。
- 不监听 App 内隐私协议同意，不修改 Android、catsinger、本地案例兜底、Java、Admin、数据库、接口或请求字段。
- 新增可注入首页加载函数的 App 内测试入口；8 项生命周期与错误显隐测试、首页案例 9 项、隐私流程 5 项与 `flutter analyze` 通过。全量 178 项通过、11 项既有无关失败；`HOME-011` 待 iOS 真机 QA。

## 14. 2026-08-25 公开案例播放与基础媒体缓存增量

- `ResourceService` 随 `Global.init()` 基础启动直接初始化，只读取缓存配置与账本并准备缓存管理器，不读取设备审计信息，也不主动下载资源。
- 未同意、拒绝或撤回隐私协议后仍保留基础媒体缓存；用户主动点击公开案例时可以继续换签、下载并播放。客户端审计请求头、登录、支付、分享、号码认证和埋点仍在隐私同意后初始化或恢复。
- 撤回隐私授权不自动删除既有媒体缓存；设置页“清理缓存”和缓存上限继续由同一个 `ResourceService` 管理。
- 不修改资源服务公共接口、缓存键、换签与下载规则，不修改 Java、Admin、数据库、接口或原生配置。
