## 1. 功能定位

写歌页是核心创作入口。前端 UI 必须按新设计稿实现，重点是灵感创作、高级创作、固定底部按钮和迷你播放器避让。

## 2. 灵感创作

字段：

- 音乐描述：最大 200 字，底部左侧「灵感速递」，右侧字数
- 音乐名称：选填，最大 80 字
- 曲风描述：最大 200 字
- 曲风标签：流行、民谣、摇滚、电子、国风、说唱、爵士、R&B、动漫、钢琴、探戈、迪斯科、轻音乐、新世纪、电影配乐
- 纯音乐：从纯音乐入口进入时默认开启

交互：

- 灵感速递调用后端 inspiration 接口并覆盖音乐描述
- 标签多选后同步到曲风描述
- 开始创作提交 `mode=simple`

## 3. 高级创作

字段：

- 歌词输入：最大 3000 字，底部左侧「AI帮写」
- 音乐名称：最大 80 字
- 曲风描述和标签：最大 200 字
- 歌手类型：默认、男声、女声
- 歌曲语言：中文、英文、日文、韩文、粤语
- 歌曲时长：1/2/3/5 分钟
- 参考音频：现场录制、导入音频
- AI 模型：后端模型列表

真实功能：

- AI帮写：根据主题、情绪、风格生成歌词
- 参考音频：支持录音、试听、删除、导入；格式 MP3/WAV/M4A/AAC；最大 20MB；最长 5 分钟
- 图片写歌：从首页入口进入时携带图片并参与生成

## 4. API 和参数

需要扩展 `CreateSongGenerationParams`：

- `imageAssetId` 或图片上传资源 ID
- `referenceAudioAssetId`
- `vocalGender`
- `language`
- `durationSeconds`
- `styleDescription`

新增 API：

- AI帮写歌词
- 图片上传/图片写歌资源
