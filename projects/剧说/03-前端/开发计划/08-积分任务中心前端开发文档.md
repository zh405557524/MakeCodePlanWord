# 剧说 Flutter 模块开发文档：08-积分任务中心

> 版本：v0.8.0
> 创建日期：2026-06-08
> 当前状态：done

## 1. 功能范围

- 新增「我的」页任务中心入口。
- 新增任务中心页面，展示总积分、连续签到、邀请任务。
- 新增任务中心 API adapter、model、controller 和 mock。
- 不展示广告任务，不接广告 SDK。

## 2. 路由与文件

- `RouteName.taskCenter`：`/task-center`
- `lib/apis/tasks.dart`
- `lib/models/data/task_center_overview.dart`
- `lib/models/data/task_check_in_result.dart`
- `lib/pages/task_center/index.dart`
- `lib/pages/task_center/controller.dart`
- `lib/pages/task_center/view.dart`

## 3. 页面规则

- 未登录点击入口跳登录。
- 已登录进入页面后加载 `GET /api/tasks/center`。
- 点击签到调用 `POST /api/tasks/check-in`，成功后刷新积分和任务中心状态。
- 邀请任务按钮跳转现有 `RouteName.invite`。
- 页面状态覆盖 loading、error、success、已签到、邀请任务完成 / 未完成。

## 4. 视觉规则

- 使用剧说暗色背景、暗色卡片、荧光黄绿主按钮。
- 参考截图布局，但不复用蓝橙配色。
- 卡片圆角、间距和字体与当前「我的」「积分充值」「邀请」页面保持一致。
