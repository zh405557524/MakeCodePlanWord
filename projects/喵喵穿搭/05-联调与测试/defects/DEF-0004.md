# DEF-0004 AI 解析衣物保存后衣橱图片不会自动加载

| 字段 | 内容 |
|------|------|
| 严重度 | P1 |
| 当前状态 | open |
| 发现版本 | `catoutfit 1.0.0+1 / dev@fd77afd` |
| 平台 | Android 12 真机 `V1981A`；TEST 环境 |
| 关联用例 | WARDROBE-MAT-001～003、WARDROBE-005 |
| 关联 CHG | CHG-0007 |

## 复现步骤

1. 使用 TEST 测试用户登录。
2. 在空衣橱中选择“AI解析上传”。
3. 分别上传单件白衬衫图和包含4组单品的平铺图。
4. 等待解析成功并将 5 件候选加入衣橱。
5. 返回衣橱，等待数秒；切换到其他页面后再返回。
6. 点击任意一张卡片的“重新加载”。

## 实际结果

- 衣橱数量、名称和分类均已保存，但 5 张卡片图片全部显示“重新加载图片”。
- 等待和重新进入衣橱不会自动恢复。
- 手动点击某一张的“重新加载”后，该张可恢复；其余卡片仍保持失败状态。
- 同一批资源在搭配生成结果页及结果单品列表中能够显示，说明资源并非全部不可用。

## 期望结果

AI 解析成功并加入衣橱后，单品缩略图应自动加载。首次请求暂时失败时应自动进行有限重试或在页面刷新时恢复，不应要求用户逐张手动重试。

## 风险

用户无法直观看到刚添加的衣物，衣橱主路径的可用性和信任感下降；多单品导入时需要逐张恢复，数量越多影响越明显。

## 本轮处理

仅登记缺陷并验证单张手动重试可恢复；未修改客户端、后端、对象存储配置或数据库。
