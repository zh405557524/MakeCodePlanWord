# 代码模板使用边界

- `feature/`：页面三件套（`index.dart` / `controller.dart` / `view.dart`）结构示例。把 `your_project`、示例模型、文案与接口换成项目自己的，遵守当前规则及实际公共组件签名；不是可直接交付的功能。
- `scaffold/`：旧版通用脚手架，只作新建工程时目录和文件清单的参考。其中的旧依赖、提示库、主题 / 语言、状态写法和凭证保存方式没有按 01–07 更新，与规则不一致的地方以规则为准，不照抄。
- 项目专属信息填在上一级的 `90-项目专属规则.mdc`，只写稳定的项目约定与入口。

已有工程直接复用实际 `lib/`，不重新铺脚手架。
