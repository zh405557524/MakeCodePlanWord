## 使用原则

1. **主色 #6366f1**：所有主按钮、激活状态、进度条起点
2. **深色背景**：仅用于 Hero 区、专注模式、开屏等沉浸场景
3. **渐变方向**：按钮统一 135deg，进度条统一 90deg
4. **阴影颜色**：彩色元素用品牌色半透明阴影，白卡用灰色阴影
5. **主线配色**：各主线独立渐变对，不与全局 UI 混用
