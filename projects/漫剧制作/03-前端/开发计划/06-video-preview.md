# 06 - 视频预览开发计划

> 覆盖任务：F-024 ~ F-025  
> 状态：`pending`  
> 依赖：F-023  
> Figma：`AI漫剧 / 06-视频预览`

## 目标

实现视频预览页、播放控制、视频生成任务轮询和分享链接。视频生成是异步任务，生成中不能重复提交。

## 任务拆分

| ID | 任务 | 输出 | 接口 |
| --- | --- | --- | --- |
| F-024 | 视频预览页 | 播放器、字幕、分镜胶片、返回编辑 | `GET /api/v1/works/{workId}/video` |
| F-025 | 视频生成与分享 | 视频任务、轮询、成功播放、分享链接 | `POST /video/generate`、`GET /tasks/{taskId}`、`POST /share` |

## 页面状态

| 状态 | UI |
| --- | --- |
| 未生成 | 显示预览信息和「生成视频」 |
| 生成中 | 显示进度，禁用重复生成 |
| 已生成 | 播放视频，显示分享入口 |
| 失败 | 显示失败原因和重试 |

## 播放能力

- 播放 / 暂停。
- 进度条。
- 上一幕 / 下一幕。
- 分镜胶片列表。
- 字幕展示。
- 返回编辑时定位当前分镜。

## 验收

- 视频任务走轮询，不阻塞 UI。
- 生成中重复点击不会创建多个任务。
- 视频成功后刷新 `videoUrl`。
- 分享链接弹层按 Figma 视觉实现。
