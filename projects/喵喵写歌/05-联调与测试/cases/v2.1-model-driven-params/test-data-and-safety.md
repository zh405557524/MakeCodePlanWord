# 测试数据、环境与安全门禁

## 账号与配置

- 准备：未登录设备、普通账号、低积分账号、有效会员、已过期会员、两个互相隔离的普通账号、iOS 游客、游客绑定手机号、邀请关系、Apple Sandbox、一次性注销账号。所有账号仅使用测试环境；记录 App Code `catsinger`。
- 后台预置至少两套能力不同的写歌模型、两套改编模型、一套算道声音训练模型和两套能力不同的翻唱模型；有支持、不支持、`NOT_DECLARED`、下架、价格变更和无价格配置。预置本人已验证/训练中/失败/不可用音色与官方启用/下架音色，且能区分模型兼容性。
- 首页预置至少两张海报（一张有目标、一张静态），再测单张、失效图与运营切换；新人礼配置覆盖启停、会员人群、首次/每日/每次打开及领取前后。新账号赠额用配置 A/B 与无效值，不触碰历史账号余额。
- 作品预置原创、纯音乐、旧改编、声音克隆翻唱、生成中、失败、静态歌词、时间轴歌词、无封面和失效音频；站内作品仅给当前用户可访问的资源 ID。

## 资源样本

- 分别准备当前模型硬限制边界内外的 MP3/WAV/M4A/AAC/FLAC/OGG、损坏文件、伪扩展名、无时长文件和相册视频。**不固定用 6 分钟/50MB 判断新翻唱**：记录平台暂定整曲 10 分钟与所选模型更严格的返回限制；训练仅按供应商硬限制，效果建议不是拒绝条件。
- 为查重准备同一最终字节重复选择、相同原文件但裁剪/转码后字节不同、同摘要不同用户、同摘要不同用途、审核中、审核拒绝和查询失败。留存 `resourceId`、摘要/大小的脱敏核对记录；不要在报告中泄露原始私有文件或临时签名 URL。
- 选择文件只是本地草稿；记录实际点击提交后发生的查重、上传、审核与任务创建时序。既有“我的作品”引用走归属校验，不要求本地文件摘要。

## 执行与证据

- 每例保留设备平台、机型/模拟器、系统版本、App 安装包版本与构建号、三端部署版本、账号代号、后台配置快照、时间戳、截图与任务/作品/订单号。Android 自动执行补 UI XML 和失败 logcat，iOS 补 XCUITest/Appium 证据；录屏适用于播放进度和录音场景。
- `paid` 仅测试环境和测试积分或支付宝测试链路/Apple Sandbox；`delete` 只删本次专用作品；`account_delete` 只用一次性账号；`withdrawal` 只用专用测试账号。未明确启用相应门禁时为 `BLOCKED`，不得自动付款、提现或注销。分享可验证系统分享入口，不能以外部应用未安装判为 App 通过。
- 正向歌曲生成必须记录任务 ID、最终作品 ID、自有持久化资源状态、播放开始与至少 5 秒进度增长；失败、超时、音频无效或审核未过均 `FAIL`。训练成功需音色可见且对兼容翻唱模型可选，不能只以训练任务状态成功为准。
- Android 真机与 iOS 真机/模拟器分别执行；两类 iOS 设备都无则 `IOS-DEVICE-GATE=FAIL`。未运行的例子是 `NOT_RUN`；厂商或配置缺失标 `BLOCKED` 并写明缺口。文档编制本身不产生任何 PASS。
