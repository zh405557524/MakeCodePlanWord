## 已确认产品口径

- 等级：1～9 人 10%，10～19 人 20%，20 人及以上 30%；升级仅影响后续订单。
- 每名受邀用户仅首笔有效会员订单产生一次直接奖励，不发放二级或团队佣金。
- 首笔会员订单付款成功后等待 N 天才可提现；后台按 App 配置、默认 0 天，订单保存原 N 和预计结算时间，修改不追溯。待结算退款扣减净额/全额取消；已结算退款按累计比例差额冲正，不足分向下取整、全额补齐尾差；负余额禁止提现。
- 本期仅支持银行卡；不接入银行卡短信验证码步骤。
- 用户需完成资料提交、协议确认、工猫 H5 核身电签和银行卡校验后才可提现。
- 每个自然日最多成功创建一次提现申请；最低提现额后台按 App 动态配置，默认 1 元；新申请按后端最新值校验，不追溯已有申请。
- 提现先人工审核，再异步提交工猫。用户侧统一展示处理中，并提示“审核通过并提交银行后预计 1～3 个工作日到账”。
- 工猫请求使用服务端持久化的稳定 `requestId`；结果不明确时使用原 ID 查单，禁止换 ID 重发。
- 明确失败或银行退票后返还可提现余额；已到账后发生会员退款时形成负余额，不追回已到账资金。
- 本功能是多 App 共用能力；业务规则集中复用，每个 App 通过标准 App Code 独立启用和隔离，禁止 Catseller 条件硬编码。
- 任一启用 App 使用统一直邀首单、BANK 和提现状态机；尚未启用的 App 保持既有模式，不发生隐式迁移。
- 邀请等级颜色按有效人数真实填充：10 人到达 20% 节点、20 人到达 30% 节点；活动规则、立即邀请、立即提现和三个记录入口均跳转到 PRD 指定页面。
- 同一环境所有启用 App 共用一套工猫商户、BANK、合同、服务主体、密钥和回调域名；requestId 持久化映射决定回调所属 App。
- 工猫传输敏感字段使用 RSA-2048；数据库保存可逆密文。Admin 仅可通过专用权限、查看密码和原因受控解密，普通接口继续只返回脱敏值。
