# 喵喵写歌模型选择开发交付说明

> 关联变更：CHG-0068  
> 状态：`waiting_review`  
> 日期：2026-09-04  
> 适用工程：Java 后端、Web/Admin、catsinger Flutter、Figma 模型选择界面

## 1. 本轮结论

- 保留现有 `ai_model_configs` 和 `(app_code, scene_code)` 单模型唯一约束。后台仍负责保存一个 App、一个业务场景当前使用的默认模型，原模型路由逻辑不改。
- 新增公共关系表 `ai_scene_model_mappings`，将“业务场景、真实商家模型、移动端公开展示、真实计费项”关联起来。
- 一个场景可配置多个可选模型；同一真实商家模型可分别配置到多个场景。完全相同的 App、场景、商家、模型组合不可重复。
- 移动端只提交不透明 UUID `modelOptionId`。本次选择仅影响本次任务，不修改 `ai_model_configs`，也不写入本地存储或保存用户上一次选择。
- 移动端不接收、不展示、不提交真实 `providerCode`、`modelCode` 或 `chargeItemCode`。
- 价格不在映射表重复保存，而是实时读取真实计费项；任务创建成功后固化实际积分、计费单位和价格版本。
- 模型选择不增加会员限制，也不存在“会员模型”概念。

## 2. 场景约定

| 前端入口 | 模型场景编码 | 说明 |
|---|---|---|
| 简易模式 | `song.generate` | 与专业模式共用同一组选项 |
| 专业模式 | `song.generate` | 与简易模式共用同一组选项 |
| AI 翻唱 | `song.cover.generate` | 只能提交翻唱场景返回的 `modelOptionId` |

请求中的既有 `sceneCode` 继续表示“情景写歌”的内容场景，不复用为模型场景。

## 3. 数据库

### 3.1 `ai_scene_model_mappings`

公共 schema 新增字段：

| 字段 | 用途 |
|---|---|
| `id` | 内部主键 |
| `public_id` | 不可修改的 UUID；对外作为 `modelOptionId` |
| `app_code` | App 隔离 |
| `scene_code` | 业务模型场景编码 |
| `provider_code` | 真实商家编码 |
| `model_code` | 真实模型编码 |
| `display_name` | 移动端展示名称 |
| `icon_url` | 移动端展示图标 |
| `charge_item_code` | 真实积分计费项 |
| `metadata_json` | 可公开的展示扩展 JSON 对象字符串，默认 `{}` |
| `enabled` | 是否允许查询和创建任务使用 |
| `sort_order` | 前端排序，数值小的优先 |
| `created_at` / `updated_at` | 创建、更新时间 |

约束：

- `public_id` 唯一。
- `(app_code, scene_code, provider_code, model_code)` 唯一。
- `(app_code, charge_item_code)` 外键关联 `point_billing_items(app_code, item_code)`。
- `scene_code`、`provider_code`、`model_code` 均不单独唯一。
- 首期通过 `enabled=false` 下线，不提供物理删除接口。

迁移文件：

- 后端 `common/V4.7__ai_scene_model_mappings.sql`
- 后端 `catsinger/V4.8__song_generation_model_option_snapshot.sql`

### 3.2 任务快照

`catsinger_song_generation_tasks` 新增：

- `model_option_id`
- `charge_item_code`
- `charge_unit_type`
- `pricing_version`

任务原有的真实 `provider`、`model` 和 `price_points` 与上述字段一起构成本次任务快照。后续修改映射或计费项不会改写已创建任务。

### 3.3 `metadata_json` 边界

- 根节点必须是 JSON 对象；空值统一为 `{}`，数组、字符串、数字不能作为根节点。
- 后台保存前校验并格式化。
- 可用于 `subtitle`、`badge`、`theme`、`recommendationText` 等不影响路由的展示扩展。
- 不允许覆盖商家、模型、场景、价格、排序和启停等核心字段。
- 禁止保存密钥、Token、厂商请求参数和其他敏感数据；后端对敏感键递归拦截。
- 公共接口解析为 `metadata` 对象返回；客户端只消费已支持的键并忽略未知键。

## 4. 接口契约

### 4.1 移动端公开查询

```http
GET /api/ai-model-options?sceneCode=song.generate
X-App-Code: catsinger
```

每个选项只返回：

```json
{
  "modelOptionId": "uuid",
  "displayName": "公开名称",
  "iconUrl": "https://...",
  "pricePoints": 100,
  "unitType": "PER_REQUEST",
  "pricingVersion": 1,
  "isDefault": true,
  "metadata": {
    "badge": "推荐"
  }
}
```

公共响应不包含真实商家、模型和计费项编码。`isDefault` 通过映射与现有 `ai_model_configs` 当前场景配置匹配计算，不在映射表重复保存。

若当前后台默认模型没有有效映射，服务端记录配置错误并返回空列表；移动端隐藏选择器，创建请求不提交 `modelOptionId`，继续使用原后台默认模型。服务端不会根据排序猜测另一个默认模型。

### 4.2 任务创建

歌曲创建请求新增可选字段：

```json
{
  "modelOptionId": "uuid"
}
```

- 新客户端选择模型后只提交 `modelOptionId`。
- 服务端按任务类型确定预期模型场景，再按当前 App、场景和 UUID 解析真实商家、模型及计费项。
- 错误 App、错误场景、停用映射、无效商家模型或失效计费项直接拒绝创建，不静默换模型。
- 未提交 `modelOptionId` 时保持原 `ai_model_configs` 选择流程，兼容旧客户端。
- 成功创建只写任务快照，不修改 `ai_model_configs`。

### 4.3 管理后台

- `GET /api/admin/ai-scene-model-mappings`
- `POST /api/admin/ai-scene-model-mappings`
- `PUT /api/admin/ai-scene-model-mappings/{id}`
- `POST /api/admin/ai-scene-model-mappings/{id}/icon`

列表支持按场景、商家、模型和启停状态筛选。编辑时从当前模型目录选择商家模型、从真实计费目录选择计费项，并只读显示当前积分、计费单位和价格版本。更新不会改变公开 UUID。

## 5. Web/Admin 交付

后台 AI 配置页新增“场景模型映射”：

- 配置场景、真实商家模型、公开名称、公开图标、计费项、扩展 JSON、排序和启停状态。
- 图标通过现有 OSS 上传能力保存；启用映射时必须具备有效图标、有效商家模型和启用中的计费项。
- 列表实时展示计费项当前积分、单位和价格版本，不在映射保存价格副本。
- 当场景当前后台默认模型没有有效映射时显示明确告警。
- 首期只允许停用，不提供删除操作；本页不负责修改后台当前默认模型。

## 6. Flutter 交付

入口位置：

- 简易模式：纯音乐配置之后。
- 专业模式：歌词之后、人声之前。
- AI 翻唱：歌曲名称之后。

交互规则：

- 底部选择器按接口结果动态渲染，不固定两个模型。
- 展示后台配置的图标、名称、实时积分，以及客户端已支持的 `metadata` 可选内容。
- 点击选项只修改弹层草稿；点击“确认”后才更新当前创建页面。
- 关闭、点遮罩或下滑均取消未确认修改。
- 重新打开弹层保留当前页面已确认项；创建失败也保留。
- 创建成功或重新进入创建流程后恢复接口返回的后台默认项。
- 页面状态不写本地存储；简易与专业共享场景但各自只维护当前页面状态。
- 新任务创建不再提交真实厂商/模型编码，不再使用翻唱模型别名判断或硬编码价格。

1. 发布公共表迁移、任务快照迁移、映射接口和管理后台。
2. 在后台配置 `song.generate`、`song.cover.generate` 映射；两个场景的当前后台默认模型都必须具备启用映射、图标和有效计费项。

## 10. 明确排除

- 不删除或放宽 `ai_model_configs` 的 `(app_code, scene_code)` 唯一约束。
- 不修改后台保存当前场景默认模型的业务。
- 不把移动端本次选择写回数据库配置或本地偏好。
- 不在 `ai-billing.json` 硬编码公开名称、图标或选择器映射。
- 不增加 `capability_type`、`default_flag`、简易/专业/翻唱布尔字段。
- 不增加会员专属模型、保存上次选择、按排序自动替代默认模型等行为。
