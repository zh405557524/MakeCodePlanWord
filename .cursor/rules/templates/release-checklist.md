## 5. 提交前自检

- [ ] 应用包在干净设备上可正常启动
- [ ] 网络异常 / 离线场景优雅降级
- [ ] 首次启动隐私弹窗合规（未同意前不收集信息）
- [ ] 不含调试日志、TODO、测试账号
- [ ] 应用内无第三方支付绕过商店内购的引导（AppStore 重点）
- [ ] 已通过 TestFlight / 内部测试组确认包可安装

---

## 6. 审核常见拒绝项防御清单

### AppStore

- [ ] 基本功能不依赖外部登录 / 网络
- [ ] 含订阅披露完整（费用、续订、取消方式）
- [ ] 隐私政策与 App 行为一致
- [ ] 提供 Sign in with Apple（如使用第三方登录）
- [ ] 通知仅事务性

### Google Play

- [ ] 数据安全表单已填写
- [ ] 敏感权限有合理用途说明
- [ ] 目标 SDK 版本满足 Google 当年要求
- [ ] 提交 AAB 而非 APK
- [ ] 64-bit 支持

### 国内商店

- [ ] ICP/MIIT 备案号已展示
- [ ] 软著证书已上传
- [ ] 个人信息保护展示页
- [ ] 第三方 SDK 清单
- [ ] 青少年模式入口（特定品类）
