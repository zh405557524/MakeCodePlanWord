接口卡片（字段见 `api.md` §7）：

```text
名称：素材多几项信息（K-15）
一句话：读素材时多告诉你它属于哪个主体、形象叫什么、角色有哪些别名、形象图是不是按旧主图做的
谁来调用：所有读素材、读片段出场素材的地方（网页端、手机端）
输入：无（随现有接口返回）
输出：所属主体、形象名称、别名、“主图已更新”标记；形象的名字显示成“江敏·婚纱”
失败时：无新增
推进方式：随现有接口直接返回
变化：只加字段；旧 App 忽略新字段，形象显示成单独一条“江敏·婚纱”
```

```text
名称：资产库按角色归组（K-17）
一句话：给资产库列表加“按主体归组”，得到一行一个角色、后面带它的形象
谁来调用：网页端资产库角色 / 场景页签
输入：按主体归组 — 是 / 否（默认否，和现在一样）
输出：主体列表，每个带形象列表
失败时：和现在一样
推进方式：直接返回
变化：加一个可选参数；不传和现在一样
```

```text
名称：作品素材总览（K-16）
一句话：给作品和类型（角色 / 场景 / 道具），得到这部作品全部主体和它们的形象，以及各自出现在哪几集
谁来调用：网页端整理项目资产页“总览”
输入：作品 — 哪部作品；类型 — 角色 / 场景 / 道具；关键词 — 可选，按主名、别名、形象名搜
输出：主体列表（每个带形象列表和出现集数）、全剧缺图数
失败时：作品不存在 → “内容不存在或已删除”；参数不对 → 提示
推进方式：直接返回
变化：新增；旧 App 不调用，不受影响
```

```text
名称：改别名 / 改形象名称（K-18）
一句话：给素材和新的别名（或新的形象名称），保存后返回最新素材
谁来调用：角色详情页别名行、形象名称输入框（网页端、手机端）
输入：别名 — 角色的全部别名（整组替换）；形象名称 — 形象自己的名字
输出：保存后的素材
失败时：别名和本作品别的角色冲突 → 红字“「周叔」已经是「老周」的名字或别名”，不保存；形象重名 → 红字；版本过期 → 提示刷新
推进方式：直接返回
变化：现有两个修改接口各加两个可选字段；旧 App 不传就和现在一样；旧 App 改形象的名字会被拒绝并提示用新版本
```

```text
名称：新增形象 / 子场景（K-19）
一句话：给主体、形象名称、外观特征和出现集数，得到一条还没有图的新形象
谁来调用：详情页“＋ 新增形象 / 新增子场景”弹框
输入：形象名称 — 如“婚纱”；外观特征 — 和主图不一样的地方；出现集数 — 哪几集用它（可不选）
输出：新形象，和它在各集的关联
失败时：重名、道具、在形象下再建形象 → 弹框红字，内容保留
推进方式：直接返回（不出图、不扣积分；出图另点“生成”）
变化：新增
```

```text
名称：删除形象（K-20）
一句话：给要删的形象，删掉它，用到它的片段改用主体
谁来调用：详情页形象上的 ✕ → 确认
输入：形象 — 要删哪个；版本 — 防止删到别人刚改过的
输出：删了哪个、改了哪些片段
失败时：主形象 → “主形象不能单独删除”；有片段正在生成视频 → “请完成后再删除”；版本过期 → 刷新
推进方式：直接返回
变化：新增；删除后不能恢复（片段里的描述会被改回主名）
```

```text
名称：片段里切换形象（K-21）
一句话：给片段、现在用的形象和要换成的形象，得到换好的片段（可连同本场后面的片段）
谁来调用：分镜创作页参考栏“江敏 · 主形象 ▾”

失败时：换成别的角色 / 已经在用 / 还没出图 → 提示并不改；正在生成视频 → 提示稍后
推进方式：直接返回（不调 AI、不扣积分）
变化：新增
```

```text
名称：片段提醒（K-22）
一句话：读片段时顺带告诉你“原文提到婚纱，用的却是主形象”这类提醒
谁来调用：分镜创作页片段卡“N 个提醒”、片段上方提醒条
输入：无（随片段一起返回）
输出：提醒列表（文字、现在用的、建议换成的）
失败时：无（只是提醒，不挡生成）

```

```text
名称：生成视频本次只带部分参考图（K-23）
一句话：给片段和这次要带的参考图，得到这次生成的报价
谁来调用：点“生成视频”时参考图超上限的勾选弹框
输入：这次带哪些出场素材的图（只对单个片段的视频）
```

```text
名称：导入整个角色（K-24，行为变化）
一句话：从资产库导入一个角色到本集时，它的形象一起进来
谁来调用：资产库导入、一键匹配已有素材
```

| 网页端本地存储 | 无 | — | — | — |

为什么非改表不可（后端规则“非必要不改库”）：
- “形象属于哪个角色”没有现成字段能放：`source_asset_id` 已经用来记“从哪条素材导入 / 入库”，混用会把导入和资产库弄乱；现在场景靠描述里写“关联主场景：××”来串，是文字解析，改个名就断，角色也没法这样用。
- 别名没有现成字段：塞进描述会被当成外观交给图片模型，也没法查重。
- 只加两列，不新建表、不动别的表。

### 后端方案（原 §7）

- **B-02 片段拆分（R-02，M01）**（`app/catdrama/analysis`、`shot`、`generation`）：
  - “生成提示词”（K-09）：快照的制作设置改用片段生效的设置；结果超长时用 `DramaSegmentComposer.composeSegments` 试拆，能拆（≥2 部分、每部分都不超长、没有被跳过的镜头）就由片段模块新方法 `splitShot` 写回：原片段换成第 1 部分，其余插在后面，后面片段序号顺延（版本号不变），本集版本 +1；分镜头表用新重载把一个片段的镜头换成几部分。写回在任务置成功的同一事务里，先加作品锁。
  - “片段拆分”（K-10）：受理时把当前生效的一批镜头按本集第一个片段的生效设置重新组合；和现在一样就直接返回 `unchanged`；不一样就建 `EPISODE_ANALYSIS` 任务（快照 `mode = SEGMENT_RECOMPOSE`，跳过模型三步，把算好的候选放进检查点），复用现有处理器建 `CANDIDATE` 和差异。差异的“保留”按镜头组成判断（传给 `buildDiff` 新重载），新增片段的制作设置由 `applyAnalysisDiff` 新重载写入。
  - 本集设置（K-12，D-20）：“批量生成提示词”本集已有片段时，`shotSnapshot` 用本集序号最小的有效片段生效的设置（和“片段拆分”同一个取法）拼提示词和组合片段，快照存 `newShotOverride`，差异应用时新增片段带上它；第一次生成、修复、重试不变。
  - 镜头的素材标记：短标记按“本集当前素材”编号，跨任务会对错；从本版起“生成提示词”写回的存 `[素材:素材ID]`，重新组合时两种都换成素材 ID 再对本集素材。
  - 只改 `app/catdrama`，不改表，不影响其他 App。
