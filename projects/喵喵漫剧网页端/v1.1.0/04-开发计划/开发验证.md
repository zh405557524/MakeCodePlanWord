# 喵喵漫剧网页端 v1.1.0 开发验证

> 用途：每个模块写完代码后，照着在浏览器里走一遍，确认功能能用。按模块分节，做完一个模块补一节（现在有 M02）。
> 来源：模块计划的 §8 验收路径、`05-测试/测试.md` 的用例（括号里是对应编号），和 `design-assets/v1.1.0/` 的设计图。
> 写法照 `v1.0.0/05-测试/手动测试清单.md`：只写人能在界面上操作和看到的；接口、数据库的细节由后端测试覆盖，第 0 组列出要跑的命令。

## 怎么用

1. 先跑第 0 组的自动检查，全部通过再走界面。
2. 按顺序从上往下走，前面的步骤会给后面准备数据。
3. 每一步在“结果”栏填：`过` / `不过` / `没测`。不过的在“备注”写一句现象，截图放 `05-测试/evidence/{模块}/`，文件名用模块加步骤编号（例如 `M02-B-03.png`）。
4. 标了 💰 的步骤会消耗本机积分，标了 📱 的需要手机端。可以先跳过，最后集中做。
5. 走完把“不过”的编号发给 Claude，由 Claude 判断归属（后端 / 网页端）并修复；同一个问题最多修 3 次，修不好记进总计划 §5 问题清单。

# M02 形象与别名

> 模块计划：`04-开发计划/模块/M02-形象与别名.md`（§8 验收路径）。设计图：`design-assets/v1.1.0/W-13-角色详情-主形象-r1.png`、`W-13-角色详情-衍生形象-r1.png`、`W-13-角色详情-别名编辑-r1.png`、`W-13-新增形象与删除确认-r2.png`、`W-13-场景详情-r1.png`。
> 一句话：角色 / 场景的详情页右栏“全部造型”变成形象列表（主形象 + 衍生形象 / 子场景），可以新增、删除、切换；角色可以加别名；形象出图自动拿主图当第一张参考图。

## 开始前的准备

| 项 | 要求 |
|---|---|
| 后端 | 原目录 `lxwxservice`（`dev`）用这次的代码重启：`./gradlew bootRun`，端口 8080。启动日志里能看到迁移到 `5.6`（`catdrama_assets` 多了 `parent_asset_id`、`aliases` 两列） |
| 网页端 | 原目录 `catdrama-studio`，分支 `catdrama-studio-v1.1.0`；`lib/global.dart` 里 `currentServerAddressType = 1`；`flutter run -d chrome --web-port 5173` |
| 窗口 | 1440×900 左右 |
| 作品 | 一部已经进入**分集制作**（能进分镜页）的作品，至少 2 集，记为“测试作品” |
| 角色 | 测试作品里一个**有图**的角色（下面叫“江敏”），至少一集的分镜里有片段用到她；同一作品里**另一个角色**（下面叫“老周”），用来测别名重名 |
| 场景、道具 | 测试作品里一个有图的场景（下面叫“江敏家”）、一个道具 |
| 资产库 | 资产库“通用资产”里一个自己的角色素材 |
| 积分 | 💰 步骤最多生成 **2 张图**（1 张形象图、1 张换主图），失败不重试 |
