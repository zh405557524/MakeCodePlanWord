# Flutter 模块开发文档：我的与公共页面复用

> 版本：`v1.10`｜状态：进行中｜任务：`T-F012 我的/复用页面`

## 1. 功能定位与边界

在“我的”一级页复用登录、账号安全、积分、充值、VIP、任务中心、订单、兑换码、静态内容、意见反馈、更多设置和推广素材。首页可见区按最新 Figma 展示头像/登录态、积分、VIP、积分福利/充值，以及“订单列表、积分明细、邀请好友、意见反馈、联系客服、更多设置”六项菜单。

## 2. 入口、路由与页面文件

- “我的”Tab：`pages/account/`，游客可进入。
- 复用现有 `/login`、`/membership`、积分、充值、任务、订单、兑换码、设置、反馈、WebView、推广素材等路由。
- 入口点击统一走二级登录门禁并支持登录后回原目标。

## 3. 依赖前置

- 复用 catseller 当前 Auth、User、Points、Payment、Task、Redeem、Invite、Settings 页面和 Java 公共接口。
- 唯一业务差异是带货生成积分场景；本模块不修改公共支付结算规则。
- 我的页面以 catseller 现有代码和最新 UI 为实现依据。

## 4. 视觉参考与设计稿分析

本轮视觉以 Figma `12:313`（登录/一键登录）、`21:67`（我的）、`23:232`（开通会员）、`23:356`（积分充值）、`12:791/847`（成功/失败）、`17:1681`（积分详情）、`17:1758/1815`（会员/积分订单样本）、`17:1874`（意见反馈）和 `25:612`（推广素材）及相关弹框为真源。页面不显示作品数、视频数、资产价值等资产统计；可见菜单以最新 Figma 为准。

## 5. 涉及模块与类

`AccountPage/Controller`、`UserStore`、`MembershipPage`、`PointsLedgerPage`、`PointsRechargePage`、`TaskCenterPage`、`PaymentOrdersPage`、`RedeemCodePage`、`SettingsPage`、`FeedbackPage`、WebView 和邀请推广素材页面。

## 6. 业务内容与数据流

- 游客进入显示登录引导和可公开服务项；点击私有项记录目标并登录。
- 登录后加载用户资料、会员状态和积分余额；不请求作品统计。
- 充值/会员支付返回后重新刷新余额、权益和相关报价，不使用进入支付前缓存。
- 退出登录清除私有缓存并返回游客态，不影响一级 Tab。
- 静态协议、客服、反馈和版本更新沿用现有配置；文案替换为喵喵带货。

## 7. 现有工程参考点

直接审阅并复用 `pages/account`、`pages/payment`、`pages/points`、`pages/settings`、`pages/invite` 和对应 API/Store。移除写歌会员文案、歌曲播放器入口和资产统计；保护现有 Apple IAP 交易监听、未完成订单自动补单和底层恢复服务。
