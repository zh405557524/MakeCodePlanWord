## 1. 项目概述

喵喵写歌是一款面向普通用户的 AI 音乐创作 App。用户可以通过一句话描述、场景问答、图片、歌词、参考音频等方式生成歌曲，并在作品页管理歌曲、生成中任务和专辑。

固定信息：

- App 展示名：喵喵写歌
- appCode：`catsinger`
- Bundle / applicationId：`com.lxwx.catsinger`
- 端形态：iOS / Android Flutter App，配套 Java 后端和 Web/Admin 后台
- Flutter 设计基准：`375 x 812`
- 新设计稿尺寸：主要为 `860 x 1626` PNG，但实现时按内层手机屏幕内容换算，不按整张黑底图缩放

## 2. 目标用户

- 想快速生成表白、生日、毕业、旅行、动漫、游戏 BGM 等歌曲的普通用户
- 短视频创作者、自媒体博主、小说作者、游戏开发者
- 需要管理 AI 歌曲、下载、分享和创建专辑的创作者
- 运营管理员，需要配置模型、价格、案例、示例歌曲和作品数据

## 3. MVP 核心功能

本轮按用户确认，产品文档中的 MVP 项全部纳入真实功能范围：

- AI 写歌：一句话/灵感创作生成完整歌曲
- AI 作词：只生成歌词文本，并可进入高级创作使用
- 场景写歌：4 步问答生成 prompt
- 图片写歌：上传照片生成歌曲
- 纯音乐生成：生成 BGM / 无人声音乐
- 高级创作：歌词、音乐名称、曲风、歌手类型、语言、时长、模型
- AI 帮写：根据主题、情绪、风格生成歌词
- 参考音频：现场录制或导入音频作为旋律/风格参考
- 作品管理：生成中、已完成、失败、详情、删除、下载、分享、加入专辑
- 播放器：歌曲播放、歌词模式、逐句时间轴高亮
- 专辑管理：创建专辑、专辑列表、专辑详情、添加歌曲
- 会员支付：免费/VIP/PRO 权益展示、支付入口
- 积分系统：积分余额、积分明细、积分充值、生成扣费

## 5. 首页需求

首页按设计稿从上到下：

1. 顶部品牌区：猫头像、喵喵写歌、副标题「一句话生成你的专属歌曲」、PRO 会员按钮
2. AI 写歌输入卡片：200 字输入、推荐标签、开始创作按钮
3. 快捷功能四宫格：场景写歌、图片写歌、纯音乐、AI作词
4. 热门案例：横向卡片，支持更多和案例详情
5. 最近作品：展示最近创作歌曲，点击进入作品详情或播放器

验收重点：

- 第一屏必须像设计稿一样突出输入卡和快捷功能，不做营销落地页
- 点击首页开始创作要带入 prompt 到写歌 Tab
- 热门案例详情支持复制 prompt、试听示例、使用模板创作

## 6. 写歌页需求

写歌页按设计稿实现，不按旧 Sonus 参考图实现。

### 灵感创作

- 顶部标题：AI 写歌
- Tab：灵感创作 / 高级创作
- 音乐描述：最大 200 字，底部左侧「灵感速递」，右侧字数
- 音乐名称：选填，最大 80 字
- 曲风描述：最大 200 字
- 曲风标签：流行、民谣、摇滚、电子、国风、说唱、爵士、R&B、动漫、钢琴、探戈、迪斯科、轻音乐、新世纪、电影配乐，支持多选回填
- 纯音乐能力：从首页快捷入口进入时默认开启
- 底部固定「开始创作」按钮，需避让迷你播放器和底部导航

### 高级创作

- 歌词输入：最大 3000 字，底部左侧「AI 帮写」
- 音乐名称：选填，最大 80 字
- 曲风描述与标签：同灵感创作
- 歌手类型：默认、男声、女声
- 歌曲语言：中文、英文、日文、韩文、粤语
- 歌曲时长：1 分钟、2 分钟、3 分钟、5 分钟
- 参考音频：现场录制、导入音频
- AI 模型：从后端模型列表获取

参考音频限制：

- 支持 MP3、WAV、M4A、AAC
- 最大 20MB
- 最长 5 分钟

## 7. 场景写歌需求

场景写歌为 4 步问答：

1. 这首歌送给谁：恋人、朋友、父母、孩子、自己
2. 什么场景：表白、求婚、订婚、结婚、纪念日、复合、生日、毕业
3. 想表达什么：爱意、感谢、思念、遗憾、祝福、陪伴
4. 喜欢什么风格：流行、民谣、摇滚、国风、钢琴、电子

交互：

- 顶部显示返回、标题「场景写歌」、4 段进度条和「第 N 步，共 4 步」
- 下一步按钮在未选择时置灰
- 完成后生成 prompt 并跳到写歌 Tab，填入灵感创作输入框

## 8. 生成中需求

生成中包含两种形态：

- 全屏生成中页：显示 Logo、计时、状态文案、预计耗时、允许退出等待
- 作品页生成中列表：显示封面占位、歌曲名、进度、模型、剩余时间

生成详情页：

- 当前状态，如「正在编写歌词」
- 进度百分比
- 流程：理解 Prompt、编写歌词、生成旋律、人声生成、混音处理
- 预计剩余时间
- 支持后台生成说明

## 9. 作品与专辑需求

歌曲 Tab：

- 分组展示「生成中 · N 首」和「已完成 · N 首」
- 生成中项显示进度条、百分比、模型、剩余时间
- 已完成项显示封面、标题、风格/模型/时长、创建时间、播放按钮
- 点击生成中进入生成详情，点击已完成进入播放器或作品详情

作品详情：

- 封面、歌曲名称、创建时间、模型名称、时长、积分消耗
- 创作 Prompt，支持复制
- 歌词内容
- 操作：播放、下载、分享、重新生成、删除、加入专辑

专辑 Tab：

- 空态：暂无专辑、创建专辑
- 有数据：封面、名称、歌曲数量、创建时间
- 创建专辑：专辑名称、简介、封面
- 专辑详情：封面、名称、简介、歌曲数量、创建时间、歌曲列表、添加歌曲

## 10. 播放器与歌词需求

播放器：

- 顶部返回、Song / Lyrics 切换、PRO 入口
- 中间超大唱片封面，播放时旋转
- 歌曲名称、风格、创作者
- 进度条和播放时间
- 控制区：上一首、播放/暂停、下一首
- 功能：下载、分享、收藏、重新生成

歌词模式：

- 背景使用封面高斯模糊
- 当前歌词加粗高亮
- 已播放歌词透明度降低
- 未播放歌词灰色展示
- 逐句时间轴优先；时间轴缺失时静态歌词降级

## 11. 我的页需求

我的页按设计稿从上到下：

1. 标题「我的」
2. 用户信息卡：头像、昵称、会员等级、积分余额、续费按钮、创作歌曲/今日剩余/已下载统计
3. 快捷功能：邀请好友、积分明细、积分充值、联系客服
4. PRO 升级卡：无限创作、商业授权、WAV 下载
5. 功能菜单：我的会员、任务中心、支付订单、兑换码、意见反馈、联系客服、系统设置

未登录状态：

- 展示立即登录按钮
- 登录后再展示积分、会员和统计数据

## 12. 后端与 Admin 数据要求

用户端接口继续使用 `X-App-Code: catsinger`。

前端新增或补强的后端能力：

- 热门案例列表与详情
- 最近作品列表与作品详情
- AI 帮写歌词
- 图片写歌上传与生成
- 参考音频上传/录音资源提交
- 生成进度百分比、剩余时间、阶段状态
- 作品下载、分享、重新生成、加入专辑
- 专辑详情和添加歌曲
- 会员信息、积分信息、积分明细、积分充值

Web/Admin 需要能配置或查看：

- 模型和价格
- 热门案例
- 示例歌曲
- 情景模板
- 用户作品
- 生成任务
- 专辑
- 会员/积分商品

## 13. 非功能要求

- 设计稿还原是前端重点，页面结构、视觉层级、间距、圆角、底部固定区必须按设计稿实现
- Flutter 统一使用 `flutter_screenutil`，禁止大量裸尺寸
- 文本不跟随系统字体缩放导致溢出；长文案要省略或换行
- 375x812、390x844、414x896、小屏高度场景必须无明显遮挡
- 固定底部按钮、迷你播放器、底部导航必须互相避让
- 所有页面必须覆盖 loading、empty、error、disabled、submitting
