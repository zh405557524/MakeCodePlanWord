## 四处修复

| 缺陷 | 原因与修复 | 证据 |
|---|---|---|
| T38-REFRESH-01 | 保留旧邀请材料时 AppStateBuilder 仍为成功态，原页未展示读取错误。沿 Controller 原错误显示固定提示，放在滚动区外，保留原码/链接并沿原刷新重试。 | 旧代码新增用例失败；实际页面从中部刷新失败、保数据、重试清错。 |
| T38-POSTER-01 | 用途说明取消和权限拒绝都返回 false，原文案一律声称系统拒绝。改为只说明尚未保存、可重试，不改变权限申请。 | 取消不捕获图片、不调相册；双端实际用途说明取消。 |

| T38-REACTIVE-01 | 成功区 builder 在外层 Obx 返回后执行，没有订阅保存/分享及反馈状态。增加局部 Obx，并将操作反馈放在滚动区外。 | 早期双端虽完成相册写入，系统图仍显示“正在保存”；补强复制反馈用例确定复现。最终原生断言同时检查成功文案、按钮 onPressed 恢复及无旧保存文案，系统图复核通过。 |
