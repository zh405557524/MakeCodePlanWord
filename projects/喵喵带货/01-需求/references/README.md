## 使用原则

- 喵喵带货移动端当前设计真源是 Figma 页面 `39:95` 的上述节点；旧通道 `wq8ye5qf` 和旧 `39:*` 节点只保留在归档中。
- PRD 每个页面小节必须直接嵌入对应图片，并同时标注节点 ID。
- Figma 示例金额、人数、手机号、银行卡尾号、日期、域名和二维码均为演示数据，不可写死。
- 邀请等级节点间的颜色必须按服务端有效人数逐人推进；图片中的 10%/20%/30% 是示例状态，不能实现为整段跳满。
- `04-realname-policy-dialog.png` 的法规和税务文案属于待法务确认内容，PRD 只确认弹框结构、触发时机和实名规则。
- Figma 未覆盖加载、网络错误、重复通知、退款冲正、负余额、工猫查单、银行退票和敏感信息保护状态，由 PRD 文字补齐。
- 提现提交页中央文案“申请已提交”是业务状态真源；页面顶部“提现成功”不得用于把尚未到账的申请误判为到账成功。
