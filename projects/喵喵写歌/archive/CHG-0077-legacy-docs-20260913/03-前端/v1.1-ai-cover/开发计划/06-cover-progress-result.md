# 06 翻唱生成中与结果页模块

- 版本：v1.1-ai-cover
- 对应任务：F-COVER-06
- 状态：done
- 影响工程：`/Users/soul/code/lxwx/catsinger`

## 1. 功能定位

结果页承接提交后的生成中状态，并在成功后展示原版/翻唱版 AB 播放、下载、分享、收藏、重新翻唱、删除等操作。

## 2. 页面状态

| 状态 | 展示 |
| --- | --- |
| 生成中 | 进度条、阶段文案、预计剩余时间、可退出提示 |
| 成功 | 按任务返回的 `workId` 展示对应作品封面、标题、AB 切换播放器、操作按钮 |
| 失败 | 失败原因、退回积分提示、重新翻唱按钮 |
| 已删除 | 返回作品页，不停留空详情 |

## 3. AB 播放

- Tab：`原版` / `翻唱版`。
- 默认播放翻唱版。
- 切换时保留播放进度策略：v1 允许重置进度，后续再优化。
- 如果原版 URL 缺失，只展示翻唱版。

## 4. 操作按钮

| 按钮 | 行为 |
| --- | --- |
| 下载 | 调 `download-url` 后下载或打开系统保存 |
| 分享 | 复用现有占位分享 |
| 收藏 | 调现有作品收藏接口 |
| 重新翻唱 | 带当前作品进入上传页 |
| 删除 | 二次确认后隐藏作品 |

## 5. 轮询规则

- 进入页面时如果有 `taskId`，每 3 秒查一次。
- 成功后停止轮询，并以任务返回的 `workId` 拉取对应作品详情。
- 自动进入共享播放器时，显式 `workId` 在目标作品开始播放前优先于全局已有播放歌曲；目标作品进入播放会话后恢复队列切歌联动。
- 失败后停止轮询。
- 页面离开时停止轮询。

## 6. 实现步骤

1. 新增 `pages/song_cover_result/`。
2. Controller 支持 `taskId` 和 `workId` 两种入口。
3. 生成中使用 `fetchCoverTask()` 轮询。
4. 成功后调用作品详情接口。
5. 复用现有音频播放器，增加 AB 音源切换。

## 7. 验收标准

- 任务生成中能展示进度，不白屏。
- 生成成功后能播放翻唱版。
- 生成成功自动跳转时，即使另一首歌仍在播放，也必须展示本次生成作品，不能串用旧歌详情或歌词。
- 失败时能看到失败原因和重新翻唱。
- 返回作品页后列表能看到新翻唱作品。

## 8. CHG-0070 修复记录

- 根因：生成页传入的 `workId` 正确，但播放器初始化时立即采纳了进入页面前的全局当前歌曲，覆盖了路由目标和新作品详情。
- 修复：普通作品播放器先锁定显式路由目标；只有该作品真正进入播放会话后，才继续接收队列切歌事件。
- 验证：生成成功跳转、旧歌仍在播放、同曲缓存刷新、播放队列切歌共 4 条 Widget 回归通过，`flutter analyze` 通过；未执行全量测试。
