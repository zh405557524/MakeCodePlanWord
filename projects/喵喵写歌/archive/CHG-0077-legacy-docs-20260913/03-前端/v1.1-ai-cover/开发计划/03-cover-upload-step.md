# 03 上传歌曲步骤模块

- 版本：v1.1-ai-cover
- 对应任务：F-COVER-03、F-COVER-13
- 状态：done
- 影响工程：`/Users/soul/code/lxwx/catsinger`

## 1. 功能定位

上传歌曲页是 AI 翻唱第 1 步，负责选择翻唱源音频。来源包括“我的作品库”和本地音频文件。

## 2. 页面入口

- 首页 `AI 翻唱`。
- 作品页 `重新翻唱`。
- 结果页 `重新翻唱`。

## 3. 页面结构

- 顶部：返回按钮 + 标题 `上传歌曲`。
- 进度：第 1 步，共 3 步。
- 来源卡 1：`从我的作品选择`。
- 来源卡 2：`上传本地歌曲`。
- 版权确认：复选框 + 文案。
- 底部按钮：`下一步`。

## 4. 交互规则

| 操作 | 规则 |
| --- | --- |
| 选择我的作品 | 打开作品选择面板，只展示已完成且有音频的作品 |
| 选择本地文件 | 打开文件选择器，支持音频文件和包含 AAC 音轨的 MP4 |
| 勾选版权确认 | 只有勾选后才允许下一步 |
| 点击下一步 | 校验通过后进入选择音色页 |
| 返回 | 回到来源页面，保留已选源音频 |

## 5. 校验规则

- 格式：`MP3/WAV/M4A/AAC/FLAC/MP4`；MP4 必须包含可提取的 AAC 音轨。
- 大小：不超过 `50MB`。
- 时长：`6秒 - 6分钟`。
- 本地 Flutter 先做能做的大小/扩展名校验；时长以后端返回为最终准则。
- MP4 在 App 端优先无损封装为 M4A；Android 厂商 Muxer 不兼容时无损回退为 ADTS AAC，并使用实际文件扩展名与 MIME 上传。
- 后端拒绝后要展示具体错误，例如“音频超过 6 分钟，请重新选择”。

## 6. 状态设计

| 状态 | 展示 |
| --- | --- |
| 空状态 | 上传引导与作品库入口 |
| 已选作品 | 展示封面、标题、时长、类型标签 |
| 已选本地音频 | 展示文件名、大小、时长、删除按钮 |
| 上传中 | 卡片内进度条，底部按钮禁用 |
| 上传失败 | 错误文案 + 重新上传 |

## 7. 实现步骤

1. 新增 `pages/song_cover_upload/`。
2. Controller 管理 `selectedSource`、`copyrightConfirmed`、`uploading`。
3. 文件选择后调用 `uploadCoverSourceAudio()`。
   - MP4 先调用原生音轨转换；Android 依次尝试 M4A 无损封装、ADTS AAC 无损兜底，最后才尝试转码。
4. 作品库来源直接生成草稿，不重复上传。
5. `下一步` 把 source 信息写入 `SongCoverStore` 并跳 `/song-cover/voice`。

## 8. 验收标准

- 未选音频或未勾版权时按钮置灰。
- 选中作品后页面能继续到音色页。
- 上传超过限制的文件能看到明确提示。
- 包含 AAC 音轨的 MP4 在厂商 M4A Muxer 不兼容时仍能转换并上传，返回文件名与 MIME 必须匹配实际 AAC 文件。
- 375x812 下底部按钮不遮挡版权确认。
