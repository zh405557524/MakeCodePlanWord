# 故事草案

## 故事梗概

这段一分钟内的厨房小意外节奏集中，按因果推进可拆为3集。会说话的小猫在厨房台面上好奇地凑近水杯，尾巴不小心扫倒杯子，水洒了一桌。它先是惊慌地小声说“糟了”，随即叼来纸巾，用爪子按住擦拭，手忙脚乱地把水吸干，又把杯子扶正，把湿纸团推到垃圾桶旁。主人回到厨房时，正看见小猫压着纸巾认真收拾，台面已恢复整洁。主人没有责怪它，而是从便签盒里取出一朵小红花贴纸，贴在小猫额前。小猫努力装作镇定，尾巴却悄悄翘了起来，短短一分钟的厨房风波以一朵小红花收尾。

## 第1集：水杯倒了

厨房台面上放着一只盛着水的水杯。会说话的小猫跳上料理台，好奇地凑近杯口嗅了嗅，嘴里嘟囔着“就闻一下”。它刚抬起爪子，尾巴便扫到杯身，水杯“哐”地倒下，水沿着桌面淌开。小猫僵在原地，瞪圆眼睛小声惊呼：“糟了，纸呢？”

## 第2集：慌忙擦桌

小猫急忙从纸巾架旁扯下几张纸，用前爪按住，在桌面上来回擦拭。水迹被抹开时，它更慌了，一边换纸一边念叨“不能留印子”，还踮脚把桌沿的水吸干。它扶正水杯，把湿纸团推到垃圾桶边，刚喘口气，就听见门外传来脚步声，立刻又低头装出认真收拾的样子。

## 第3集：一朵小红花

主人回到厨房，看见小猫正压着纸巾擦拭台面，水杯已经扶正，桌面也干净了。主人没有责备，只是弯下腰看了看小猫，从便签盒里取出一朵小红花贴纸，贴在它额前。小猫故作镇定地“喵”了一声，心里却小声说“下次一定看尾巴”，尾巴尖已经高兴地翘了起来。
