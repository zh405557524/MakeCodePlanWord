## 3. 流程验收

| 流程 | 预期 |
| --- | --- |
| 首页进入翻唱 | 进入上传页 |
| 本地音频上传 | 校验格式、大小、时长 |
| 作品库来源 | 能进入音色页 |
| 选择音色 | 能试听、能选中 |
| 高级设置提交 | 生成任务并进入结果页 |
| 生成成功 | 作品列表出现翻唱作品 |
| 重新翻唱 | 当前作品带入上传页 |

## 4. 异常验收

- 未登录点击入口。
- 未勾版权确认。
- 未选择音色。
- 积分不足。
- 接口返回翻唱功能关闭。
- Provider 生成失败。
- 下载地址获取失败。
