## 1. 功能定位

主 Tab 是 App 的基础导航。底部区域需要同时处理底部 Tab、迷你播放器和页面固定按钮的避让。

## 2. Tab

固定 4 个：

- 首页
- 写歌
- 作品
- 我的

图标按设计稿语义：

- 首页：Home
- 写歌：魔法棒/创作
- 作品：音乐符号
- 我的：用户

## 3. UI 要求

- 底部 Tab 为深色固定栏，不使用旧玻璃胶囊导航
- 激活态为绿色图标和文字，下方有绿色短线
- 未激活态为灰紫色
- 页面内容底部必须预留 Tab 高度
- 写歌页存在迷你播放器时，固定按钮要继续上移避让

## 4. 验收

- [ ] 四个 Tab 可切换并保持状态
- [ ] 底部栏样式与设计稿一致
- [ ] 固定按钮、迷你播放器、Tab 不重叠
- [ ] iPhone 375x812 下安全区正确
