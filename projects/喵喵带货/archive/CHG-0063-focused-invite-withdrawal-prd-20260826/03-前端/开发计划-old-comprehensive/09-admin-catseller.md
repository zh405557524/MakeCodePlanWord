# Flutter Web 模块开发文档：喵喵带货运营后台

> 版本：`v1.1`｜状态：已完成｜工程：`/Users/soul/code/lxwx/lxwx_admin`

## 1. 完成内容

现有 Flutter Web 后台已经增加“喵喵带货”App 和四个独立业务页面：

| 页面名称 | 已实现业务 |
|----------|------------|
| 案例管理 | 新增、编辑、作品类型、封面上传、视频上传、排序、上下线、AI 标记和删除 |
| 业务与视频计费配置 | 商品图片与描述限制、视频类型、比例、时长、清晰度、默认视频参数、保留期限、轮询、前端 AI 水印、单图积分、计费版本、报价期限和失败策略 |
| 作品查询 | 按作品编号、标题和阶段查询；只读查看填写信息、商品图片、脚本分镜、审核状态和视频 |
| 生成任务查询 | 按任务编号、作品编号、任务类型和状态查询；只读查看进度、步骤、失败原因和脱敏 trace |

AI 模型配置继续使用后台现有公共页面，不新增重复页面。

## 2. 页面入口与文件

- 后台 App 选择器显示“喵喵带货”。
- 切换到喵喵带货时显示四个业务菜单；作品和任务使用“查询”名称，明确只读边界。
- 页面文件位于 `lib/pages/app/catseller/`：`cases_page.dart`、`config_page.dart`、`works_page.dart`、`tasks_page.dart`。
- 页面内的筛选条件、编辑抽屉和确认弹框属于该页面，不拆成额外页面。

## 3. 数据与隔离

- `AdminRepository.selectedAppCode` 与 `ApiClient.appCode` 同步为 `catseller`。
- 所有喵喵带货请求统一携带 `X-App-Code: catseller`。
- 切换 App 时清空案例、配置、作品和任务缓存，避免读取其他 App 的数据。
- 本次沿用现有管理员登录能力，不改造角色和菜单权限体系。

## 4. 关键规则

- 案例封面直接上传图片，视频直接上传常见视频格式；保存时绑定上传返回的资源 ID。
- 案例列表展示作品类型；来源案例的类型由来源作品自动带入并只读，手工案例可选择商品视频、探店视频或爆款复刻。上传手工素材清除来源时保留当前类型并重新开放修改。
- 已上架案例必须同时具备封面和视频，删除前二次确认。
- 视频类型、比例、时长、清晰度和默认参数在同一业务配置区域维护，默认值必须位于启用选项中。
- 修改每张分镜图片积分时，前端自动把计费版本增加 1；未改积分单价时保持原版本。
- 积分单价或失败策略发生变化时，保存前二次确认。
- 作品查询不提供删除、改状态、改脚本或改积分操作。
- 任务查询不提供取消、重跑或修改任务状态操作。
- 后台不展示完整手机号、Prompt、Provider 原始数据、密钥、Token 或积分订单信息。
