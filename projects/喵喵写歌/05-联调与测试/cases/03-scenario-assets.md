# 场景写歌与参考音频测试用例

> 代码依据：`lib/pages/song_home/scenario/`、`lib/pages/song_create/audio_reference/`
> 当前无图片写歌页面/入口；该 PRD 差异在 `ASSET-GAP-001` 单独记录，不编造不存在的按钮步骤。

| 用例 ID | 模块 | 标题 | 优先级 | 前置条件 | 测试步骤 | 预期结果 | 测试数据/备注 |
|---------|------|------|--------|----------|----------|----------|---------------|
| SCENE-001 | 场景写歌 | 默认四步完整创建歌曲 | P0 | U-NORMAL，通过路由进入场景页 | 1. 依次选择收歌人、场景、表达、风格；2. 每步点下一步；3. 最后确认积分 | 每步进度和题目正确；最终直接请求 `mode=scenario`，携带 sceneCode、四个 sceneAnswers 和 styleTags；进入生成中 | 当前代码不是回填写歌 Tab |
| SCENE-002 | 场景写歌 | 未选择答案时下一步不可用 | P0 | 任一步未选择 | 点击底部按钮 | 按钮置灰或保持当前步；不跳题、不创建任务 | - |
| SCENE-003 | 场景写歌 | 选择答案后 UI 即时更新 | P1 | 任一步 | 1. 点击一个选项；2. 改选另一个 | 选中态立即显示；同题只保留一个答案；已选标签和底部按钮同步 | 重点回归第3步“想表达什么” |
| SCENE-004 | 场景写歌 | 返回逐步后退并保留答案 | P1 | 已到第3或第4步 | 1. 点击返回；2. 再前进 | 回到上一题；原答案保留；第1步返回退出页面 | - |
| SCENE-005 | 场景写歌 | 后台配置问题替代默认问题 | P1 | Admin 配置同 sceneCode 的问题 | 1. 从该场景进入；2. 完成问答 | 使用后台题目/选项/required；提交 key 与配置 questionCode 对应 | 无配置时回退默认四步 |
| SCENE-006 | 场景写歌 | 配置缺失仍有默认兜底 | P1 | scenarios 为空或找不到 code | 进入 `/song/scenario/default` | 正常展示默认四步；无空白页或数组越界 | - |
| SCENE-007 | 场景写歌 | 场景积分不足不创建任务 | P0 | U-LOW，四步完成 | 点击开始创作 | 显示权益/充值引导；不创建任务、不冻结积分 | - |
| SCENE-008 | 场景写歌 | 重复点击最后按钮只创建一次 | P0 | 四步完成、积分充足 | 快速点击 5 次并确认 | `submitting/pointsConfirming` 防重；只产生一个任务和一条冻结流水 | - |
| REF-001 | 参考音频 | 导入合法参考音频并预览 | P0 | 大师创作，后台启用 audioReference | 1. 打开音频参考；2. 选择合法文件；3. 预览；4. 应用 | 显示名称/时长/大小；可播放/暂停；摘要更新；提交前可用 | 当前默认 MP3/WAV/M4A/AAC/MP4 |
| REF-002 | 参考音频 | 文件格式与大小校验 | P1 | 大师创作 | 依次选择不支持格式、20MB、20MB以上文件 | 不支持格式明确拒绝；20MB 边界按后台配置处理；超限不上传 | 最大值优先使用 generation-options |
| REF-003 | 参考音频 | 时长超过5分钟时校验或裁剪 | P1 | 选择超过5分钟音频 | 导入并进入裁剪 | 最终可提交片段不超过后台 maxSeconds/默认5分钟；超限不能悄悄原样上传 | - |
| REF-004 | 参考音频 | 裁剪后导出范围正确 | P1 | 合法长音频 | 1. 调整起止点；2. 试听；3. 应用；4. 提交抓包 | 上传的是裁剪后 M4A/支持格式；durationMs 与裁剪区间一致；原文件不被误删 | MP4 全范围也走导出 |
| REF-005 | 参考音频 | 麦克风录音、试听和应用 | P1 | 真机，允许麦克风 | 1. 开始录音；2. 录制10秒；3. 停止；4. 试听；5. 应用 | 计时更新；生成 m4a/wav；可试听；上传成功后成为参考音频 | - |
| REF-006 | 权限 | 拒绝麦克风/媒体权限有引导 | P1 | 首次权限未授予 | 分别拒绝录音和媒体访问 | 不崩溃、不死循环；显示权限说明/系统设置入口；返回后表单可继续 | Android/iOS 真机 |
| REF-007 | 状态 | 上传失败可重试且不丢本地草稿 | P0 | 模拟上传超时/500 | 1. 选择文件；2. 触发上传失败；3. 点击重试 | 显示错误和重试；重试成功后 asset/url 更新；不重复创建多个资源 | - |
| REF-008 | 状态 | 清除参考音频后提交不带资源字段 | P1 | 已设置参考音频 | 1. 点击清除；2. 提交大师歌曲并抓包 | 摘要恢复“未设置”；停止预览；请求不带旧 url/duration/filename | - |
| REF-009 | 防重 | 上传/裁剪/录音过程中阻止冲突操作 | P1 | 正在上传或裁剪或录音 | 连续点击导入、预览、提交、返回 | 给出“请稍候/先结束录音”反馈；不会并发上传或损坏状态 | - |
| ASSET-GAP-001 | 图片写歌 | 当前代码无图片写歌入口与页面 | P2 | 浏览所有主入口并搜索可见功能 | 检查首页/探索/创作模式 | 当前代码不可达图片写歌；不能记为已测试通过；若仍属发布范围需回需求/编码补齐 | 环境 Provider 未定也不等于 UI 已完成 |
